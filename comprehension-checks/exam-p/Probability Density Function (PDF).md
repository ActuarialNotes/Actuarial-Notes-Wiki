A continuous random variable has $f(x) = 4$ on the interval $(0 < x < 0.25)$ and zero elsewhere. Is this a valid density?

- A) No, because a probability can never exceed 1
- B) No, because a density must be at most 1 at every point
- C) Yes, but only because the interval is shorter than one unit; density values above 1 are otherwise invalid
- D) Yes, because $f$ is non-negative and the area beneath it equals 1
