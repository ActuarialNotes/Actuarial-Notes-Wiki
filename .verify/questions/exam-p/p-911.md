## [F-001] Explanation defines mu as 100, then uses mu - c = 100
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-27T19:59Z/bfa2
- date: 2026-09-28
- severity: minor
- status: open
- locus: Explanation, first sentence and the stated formula
- claim: For $Y = X - 200 \sim N(100, 100^2)$ with $\mu = 100$, $\sigma = 100$, $z = \mu/\sigma = 1$: $E[(X-c)_+] = (\mu-c)\Phi(...)+\sigma\phi(...)$ ... With $\mu-c = 100$
- evidence: The Explanation sets mu = 100 (the mean of Y = X - 200), then states E[(X-c)+] = (mu-c)Phi((mu-c)/sigma) + sigma phi((mu-c)/sigma) and substitutes "mu - c = 100". With the mu = 100 it just defined and c = 200, mu - c = -100; the substitution is right only for mu = E[X] = 300. The numbers that follow are correct: E[(X-200)+] = 100 E[(Z+1)+] = 100[Phi(1) + phi(1)] = 100(0.8413 + 0.24197) = 108.33, with Phi(1.00) = 0.8413 from the SOA normal table (PDF p.2, row 1.0, column 0.00) and phi(1) = e^(-1/2)/sqrt(2 pi) from the normal density in Grinstead & Snell (PDF p.220).
- source_rank: 5
- proposed_action: Define mu = E[X] = 300 and c = 200 so that (mu - c)/sigma = 1, or keep the Y substitution and write the formula with c = 0.
