- claim: Redington immunization is a **first-order** approximation technique. It matches the present value and duration of assets and liabilities, with the asset convexity exceeding the liability convexity.
- evidence: Finan §55 (PDF p.479-480): Redington immunization requires P(i) = 0, P'(i) = 0 (equal modified durations) and P''(i) > 0 (asset convexity greater than liability convexity), i.e. a local minimum of the net present value - a second-order condition, obtained from a Taylor expansion 'as far as second derivatives'. The vault's own next clause states the convexity condition, so the 'first-order' label contradicts it. SOA solution 229 (solutions PDF p.57) says only that the position is protected from sufficiently small changes in yield in either direction, and does not characterise the order. Answer C and the rest of the explanation are unaffected.
