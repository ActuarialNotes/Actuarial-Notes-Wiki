Reading packet for the MAS-II publication campaign (docs/content-plan.md §3.1 row 5, C4). It covers the twelve unverified credibility concept pages behind tasks A1–A2. The assigned reading is Tse, *Nonlife Actuarial Models* (2009), Chs 6.1–6.3, 7.1–7.4, 8.1–8.2 and 9.1–9.2, which is commercial. ## Findings by severity
- critical: 1
  - Limited Fluctuation Credibility F-001 (resolved): the aggregate-loss bullet read CV²_S = CV²_N + CV²_X·E[N]/E[N]. The E[N] cancels, so it gave CV²_N + CV²_X. It now reads CV²_X/E[N], which follows from LDA §9.2.2's μ_S and σ²_S.
- major: 2
  - Full Credibility Standard F-001 (resolved): the page defines the standard in expected claims, but its headline formula (z/k)²·σ²_S/μ²_S counts observations. It is now LDA eq. (9.5), (z/k)²[σ²_N/μ_N + CV²_X], and the frequency bullet was restated to match.
  - Bühlmann-Straub Credibility F-001 (resolved): v was given "same definitions as Bühlmann", with no per-exposure condition. It now states Var(X_i|θ) = σ²(θ)/m_i (LDA §9.4).
- minor: 7
  - Full Credibility Standard F-002 (resolved): the tolerance was "±k" and is now "within 100k%".
  - Partial Credibility F-001 (resolved): "halving the variance gap takes four times the data" was wrong and has been deleted.
  - Bayesian Credibility F-001 (resolved): exactness was claimed for every conjugate pair. It is now restated to a linear-exponential-family likelihood with its conjugate prior (LDA §9.5.3).
  - Bayesian Credibility F-002 (resolved): the table's gamma prior is now labelled as a rate (the example uses a scale).
  - Conjugate Prior F-001 (resolved): the table was headed "on the syllabus", which Tse §8.2 does not match. It is now headed "Common conjugate pairs".
  - Conjugate Prior F-002 (open): the beta–geometric pair (Tse §8.2.2, assigned) is missing. A writer needs to add it.
  - Empirical Bayes Credibility F-001 (open): the open sources do not state that a negative VHM-hat is "set to 0". LDA §9.6.2 says only that the method cannot be used. Check Tse §9.2.
- nit: 1
  - Bühlmann-Straub F-002 (resolved): a garbled "k = 2,500/m scaling" clause in the example stem was reduced to k = v/a = 250.
