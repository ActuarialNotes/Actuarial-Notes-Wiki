Given the following information as of December 31, 2015:

Case Outstanding ($) as of (months):

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 3,970 | 4,115 | 2,730 | 1,347 |
| 2013 | 3,680 | 3,760 | 4,560 | |
| 2014 | 3,690 | 7,380 | | |
| 2015 | 6,230 | | | |

Paid Claims ($) as of (months):

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 3,680 | 7,360 | 11,040 | 13,800 |
| 2013 | 3,520 | 7,040 | 10,560 | |
| 2014 | 3,360 | 6,720 | | |
| 2015 | 3,520 | | | |

Open Claim Counts as of (months):

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 238 | 245 | 171 | 63 |
| 2013 | 222 | 230 | 179 | |
| 2014 | 220 | 255 | | |
| 2015 | 270 | | | |

| Calendar Year | Written Premium |
|---|---|
| 2014 | $34,500 |
| 2015 | $37,500 |

- Annual severity trend = 10.0%.
- Claims are fully developed by 48 months.
- Accident year 2015 initial expected claim ratio = 65.0%.
- Policies are annual, and are written uniformly throughout the year.
- There have been no rate changes since 2013.
- There is no premium trend.

Calculate the unpaid claims for accident year 2015 using the reported Bornhuetter-Ferguson technique adjusting for the change in case reserve adequacy.

## Explanation

Because case reserve adequacy has changed, the reported triangle is first restated with a Berquist-Sherman adjustment, and only then developed.

**Average case outstanding** (case outstanding ÷ open claim counts) on the latest diagonal:

| Accident year | Age | Average case |
|---|---|---|
| 2012 | 48 | 1,347 / 63 = 21.38 |
| 2013 | 36 | 4,560 / 179 = 25.47 |
| 2014 | 24 | 7,380 / 255 = 28.94 |
| 2015 | 12 | 6,230 / 270 = 23.07 |

**Adjusted average case outstanding** — detrend that diagonal back at the 10% severity trend, so every cell reflects today's reserve adequacy:

| Accident year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 17.34 | 23.92 | 23.16 | 21.38 |
| 2013 | 19.07 | 26.31 | 25.47 | |
| 2014 | 20.98 | 28.94 | | |
| 2015 | 23.07 | | | |

**Adjusted reported claims** = adjusted average case × open claim counts + paid claims:

| Accident year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 7,806 | 13,220 | 15,000 | 15,147 |
| 2013 | 7,753 | 13,091 | 15,120 | |
| 2014 | 7,975 | 14,100 | | |
| 2015 | 9,750 | | | |

**Development on the adjusted triangle**, straight averages:

| | 12–24 | 24–36 | 36–48 | Tail |
|---|---|---|---|---|
| 2012 | 1.694 | 1.135 | 1.010 | |
| 2013 | 1.688 | 1.155 | | |
| 2014 | 1.768 | | | |
| Selected | 1.717 | 1.145 | 1.010 | 1.000 |
| CDF | 1.985 | 1.156 | 1.010 | |

**Earned premium.** Policies are annual and written uniformly, so half of each year's writings is earned in the year written:

$$\text{UEPR}_{1/1/2015} = 0.5 \times 34{,}500 = 17{,}250, \qquad \text{UEPR}_{1/1/2016} = 0.5 \times 37{,}500 = 18{,}750$$

$$\text{CY 2015 EP} = 37{,}500 - (18{,}750 - 17{,}250) = 36{,}000$$

**Bornhuetter-Ferguson ultimate** for accident year 2015:

$$\%\text{ reported} = \frac{1}{1.985} = 0.504, \qquad \%\text{ unreported} = 1 - 0.504 = 0.496$$

$$\text{Development ultimate} = (3{,}520 + 6{,}230) \times 1.985 = 19{,}354$$

$$\text{Expected ultimate} = 0.65 \times 36{,}000 = 23{,}400$$

$$\text{BF ultimate} = 19{,}354 \times 0.504 + 23{,}400 \times 0.496 = 21{,}361$$

**Unpaid claims:**

$$21{,}361 - 3{,}520 = 17{,}841$$
