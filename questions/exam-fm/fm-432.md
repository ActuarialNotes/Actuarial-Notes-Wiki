Determine which of the following statements about Redington immunization is true.

- A) A difference between Redington immunization and full immunization is that the duration condition does not need to be satisfied for Redington immunization.
- B) A portfolio that satisfies the Redington immunization conditions requires less rebalancing than a cash-flow matched portfolio.
- C) Redington immunization requires that the convexity of the liabilities is greater than the convexity of the assets.
- D) A Redington-immunized portfolio has a duration of zero and a convexity smaller than zero.
- E) Redington immunization is designed to provide surplus protection for small, parallel changes in interest rates.

## Explanation

Redington immunization protects the surplus (the present value of the assets minus the present value of the liabilities) against small, parallel changes in a flat yield curve. It requires the present values of the assets and the liabilities to be equal, their durations to be equal, and the convexity of the assets to be greater than the convexity of the liabilities. Checking each statement against these conditions:

- (A) is false: the duration condition does need to be satisfied for Redington immunization.
- (B) is false: a Redington-immunized portfolio requires more rebalancing than a cash-flow matched portfolio, not less.
- (C) is false: the convexity of the assets must be greater than the convexity of the liabilities, not the other way round.
- (D) is false: the convexity of a Redington-immunized portfolio is greater than zero.
- (E) is true.

So the true statement is (E): Redington immunization is designed to provide surplus protection for small, parallel changes in interest rates.
