An insured is subject to experience rating under the National Council on Compensation Insurance (NCCI)'s Experience Rating Plan Manual for Workers Compensation and Employers Liability Insurance. The following information about the insured is given:

| Payroll (Experience Period) | \$5,000,000 |
|---|---|
| State | Alabama |
| Class | 7705 |

The following claims apply to the experience period. Each claim involves only one person, and none are disease claims:

| Claim Number | Type | Loss |
|---|---|---|
| 1 | Indemnity | 29,000 |
| 2 | Medical | 30,500 |
| 3 | Indemnity | 90,000 |
| 4 | Indemnity | 1,500 |
| 5 | Medical | 45,000 |

Calculate the experience modification for this insured.

### Explanation
Using the 2011 NCCI tables (the report accepted the 2010 or the 2011 tables, provided one set was used throughout). For Class 7705 the tables give ELR = 2.02 and D-ratio = 0.17, so

$$E = \frac{5{,}000{,}000}{100} \times 2.02 = 101{,}000 \qquad E_e = 101{,}000 \times (1 - 0.17) = 83{,}830$$

Looking up $E$: $W = 0.14$ and $B = 28{,}000$.

Each loss is split at \$5,000 into primary and excess; the medical-only claims enter at 30%:

| Claim | $A_p$ | $A_e$ |
|---|---|---|
| 1 | 5,000 | 24,000 = 29,000 - 5,000 |
| 2 | 1,500 = 5,000 × 0.3 | 7,650 = (30,500 - 5,000) × 0.3 |
| 3 | 5,000 | 85,000 |
| 4 | 1,500 | 0 |
| 5 | 1,500 | 12,000 = (45,000 - 5,000) × 0.3 |
| Total | 14,500 | 128,650 |

$$\text{Mod} = \frac{A_p + wA_e + (1 - w)E_e + B}{E + B} = \frac{14{,}500 + 0.14 \times 128{,}650 + (1 - 0.14) \times 83{,}830 + 28{,}000}{101{,}000 + 28{,}000} = 1.03$$

Alternatively, with the 2010 tables: ELR = 1.84 and D-ratio = 0.2 give $E = 92{,}000$ and $E_e = 92{,}000 \times (1 - 0.2) = 73{,}600$, with $W = 0.14$ and $B = 26{,}800$. The same actual losses give

$$\text{Mod} = \frac{14{,}500 + 0.14 \times 128{,}650 + (1 - 0.14) \times 73{,}600 + 26{,}800}{92{,}000 + 26{,}800} = 1.03$$

### Examiner Report
Candidates were expected to use the NCCI manual to correctly calculate an experience modification factor.
Credit was given for using either the 2010 or 2011 tables, as long as they were used consistently.
Common mistakes include:
- Incorrectly calculating ratable losses for medical only claims, i.e., not applying 0.3 factor to medical only claims.
- Mixing values from different years, e.g. selecting ELR from 2011 table but picking up W and/or B from 2010 or vice versa.
- Incorrectly selecting W and/or B from the tables.
