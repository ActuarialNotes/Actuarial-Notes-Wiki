You are given the following ARMA(p, q) model:

$$
x_t = \left(\frac{3}{2}\right)x_{t-1} - \left(\frac{1}{2}\right)x_{t-2} + w_t - w_{t-1} + \left(\frac{1}{4}\right)w_{t-2}
$$

Determine (p, q) and whether the model is stationary and/or invertible.

- A) p = 2, q = 2, Stationary, Invertible
- B) p = 3, q = 3, Stationary, Not Invertible
- C) p = 3, q = 3, Not Stationary, Not Invertible
- D) p = 2, q = 2, Not Stationary, Invertible
- E) p = 2, q = 2, Not Stationary, Not Invertible

## Explanation

Move the AR terms to the left and write both sides with the backshift operator $B$:

$$
\left(1 - \tfrac{3}{2}B + \tfrac{1}{2}B^2\right)x_t = \left(1 - B + \tfrac{1}{4}B^2\right)w_t
$$

Both polynomials have degree 2, so as written the model is ARMA(2, 2). Factor each one:

$$
\begin{align*}
1 - \tfrac{3}{2}B + \tfrac{1}{2}B^2 &= (1 - B)\left(1 - \tfrac{1}{2}B\right) \\
1 - B + \tfrac{1}{4}B^2 &= \left(1 - \tfrac{1}{2}B\right)^2
\end{align*}
$$

**Stationarity** needs every root of the AR polynomial to lie outside the unit circle. Its roots are $B = 1$ and $B = 2$. The unit root $B = 1$ lies on the circle, so the model is **not stationary**.

**Invertibility** needs every root of the MA polynomial to lie outside the unit circle. It has a double root at $B = 2$, so the model is **invertible**.

The two polynomials also share the factor $1 - \tfrac{1}{2}B$. Cancelling it leaves $(1 - B)x_t = (1 - \tfrac{1}{2}B)w_t$, an ARIMA(0, 1, 1). Neither conclusion changes, and the options count $(p, q)$ as written.

$p = 2$, $q = 2$, not stationary, invertible, so the answer is **D**.
