Given the following information:

| Accident Year | Cumulative Paid Loss (\$000): 12 Months | 24 Months | 36 Months | 48 Months | 60 Months |
|---|---|---|---|---|---|
| 2012 | 500 | 750 | 950 | 1,050 | 1,100 |
| 2013 | 800 | 1,500 | 1,850 | 2,000 | |
| 2014 | 1,100 | 2,100 | 2,750 | | |
| 2015 | 1,400 | 2,300 | | | |
| 2016 | 2,000 | | | | |

- Age-to-age factors are determined by a volume weighted average of all years.
- There is no development beyond 60 months.
- Reserves are approximated by a lognormal distribution.
- The 90th percentile of the standard normal distribution is 1.28
- The accident year 2014 loss reserve estimate, $R_3$, has a standard error of 52.33

## Part a (2 points)

Construct an 80% confidence interval for $R_3$.

### Explanation
36–48 LDF $= 1.089$; 48–60 LDF $= 1.048$, so the 36-to-ultimate factor is $1.141$.

$$R_3 = 2750 \times (1.141 - 1) = 387.75 \ (\$000)$$

Assume $se(R_3) = 52.33$ is also in \$000.

$$\sigma^2 = \ln\left(1 + \frac{se(R_3)^2}{R_3^2}\right) = 0.018$$

$$\mu = \ln(R_3) - \sigma^2/2 = 5.951$$

$$80\%\ \text{C.I.} = \left(e^{5.951 \pm 1.28\sqrt{0.018}}\right) \Rightarrow (323.52,\ 456.11)\ (\$000)$$

Alternatively:

Treating $R_3$ in dollars: LDF 36–48 $= (1050 + 2000)/(950 + 1850) = 1.0893$, LDF 48–60 $= 1100/1050 = 1.0476$, CLDF 36–ult $= 1.1412$, so $R_3 = 2750\text{K} \times (1.1412 - 1) = 388{,}180$.

$$\sigma^2 = \ln\left(1 + \left(\frac{52.33}{388{,}180}\right)^2\right) = 0.000000018$$

$$80\%\ \text{CI for } R_3 = R_3\, e^{\pm 1.28\sigma - 0.5\sigma^2} = (388{,}113,\ 388{,}247)$$

### Examiner Report
Candidates were expected to construct the 80% confidence interval for R_3 based on the lognormal distribution mu and sigma.
Common errors include:

- Confusing the standard error of R_3 with sigma
- Not providing a final numerical answer
- Using the wrong formula for the confidence interval
- Using the wrong LDF to calculate the confidence interval
- Not plugging in numbers to the confidence interval formula correctly
- Assuming a normal distribution for R_3
- Confusing R for C
- Using the reserves from all years as R, rather than just AY 2014

## Part b (0.75 points)

Construct a confidence interval for the accident year 2014 ultimate loss estimate using empirical limits.

### Explanation
Age-to-age factors by year:

| AY | 36–48 | 48–60 |
|---|---|---|
| 2012 | 1.105 | 1.048 |
| 2013 | 1.081 | |

- Maximum bound: $(1.105 \times 1.048) \times 2750 = 3184.61$
- Minimum bound: $(1.081 \times 1.048) \times 2750 = 3115.44$

Interval is (3115.44, 3184.61).
