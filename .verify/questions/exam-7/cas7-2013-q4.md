## [F-001] Intermediate algebra in the 3rd-iteration line is wrong (as printed by the report)
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-10-11T02:10Z/e7p13a
- date: 2026-10-11
- severity: minor
- status: open
- locus: Part b explanation, 3rd-iteration display equation
- claim: U_CL(1-q_i) + q_i[U_CL(1-q_i^2) + U_0 q_i^2] = U_CL(1-q_i)[1 + q_i - q_i^2] + U_0 q_i^3 = ... = U_CL(1-q_i^3) + U_0 q_i^3
- evidence: Report p.39, sample answer 2 to Q4(b), prints exactly this bracket, so the vault transcribes the publisher. But the step is algebraically wrong: (1-q) + q(1-q^2) = (1-q)[1 + q(1+q)] = (1-q)(1 + q + q^2) = 1 - q^3, whereas (1-q)(1 + q - q^2) = 1 - 2q^2 + q^3, which does not equal the next expression 1 - q^3. With q = 0.1424 (part a): 1 - q^3 = 0.99711, (1-q)(1+q-q^2) = 0.96233. The first and last expressions of the line are right, so the conclusion (U_CL = 8,167) stands; only the middle step misleads.
- source_rank: 5
- proposed_action: Keep the published line and annotate it, as Q1 and Q8 do for their report misprints: note that the report prints the bracket as 1 + q_i - q_i^2 and that expanding the left side gives 1 + q_i + q_i^2.
