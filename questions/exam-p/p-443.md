A continuous random variable, $X$, has density function $f(x)$ where

$$
f(x) = \begin{cases}
\dfrac{x-1}{4}, & \text{for } 1 < x < 3 \\[4pt]
\dfrac{5-x}{4}, & \text{for } 3 \leq x < 5 \\[4pt]
0, & \text{otherwise.}
\end{cases}
$$

Determine which of the following expressions equals $E\bigl(|X-2|\bigr)$.

- A) $\dfrac{1}{4}\int_1^2 (2-x)(x-1)\,dx + \dfrac{1}{4}\int_2^3 (x-2)(x-1)\,dx + \dfrac{1}{4}\int_3^5 (2-x)(5-x)\,dx$
- B) $\dfrac{1}{4}\int_1^3 (2-x)(x-1)\,dx + \dfrac{1}{4}\int_3^5 (x-2)(5-x)\,dx$
- C) $\dfrac{1}{4}\int_1^2 (x-2)(x-1)\,dx + \dfrac{1}{4}\int_2^3 (2-x)(x-1)\,dx + \dfrac{1}{4}\int_3^5 (2-x)(5-x)\,dx$
- D) $\dfrac{1}{4}\int_1^3 (x-2)(x-1)\,dx + \dfrac{1}{4}\int_3^5 (x-2)(5-x)\,dx$
- E) $\dfrac{1}{4}\int_1^2 (2-x)(x-1)\,dx + \dfrac{1}{4}\int_2^3 (x-2)(x-1)\,dx + \dfrac{1}{4}\int_3^5 (x-2)(5-x)\,dx$

## Explanation

Two separate things force the domain to be split, and the expression must respect both.

**The absolute value** changes form at $x = 2$:

$$
|x - 2| = \begin{cases}
2 - x, & \text{for } x < 2 \\
x - 2, & \text{for } x \geq 2
\end{cases}
$$

**The density** changes form at $x = 3$.

So the integral over $(1,5)$ breaks into three pieces at the breakpoints 2 and 3, and each piece pairs the correct absolute-value form with the correct density branch:

$$
\begin{align*}
E\bigl(|X-2|\bigr) &= \int_1^2 (2-x)\frac{x-1}{4}\,dx + \int_2^3 (x-2)\frac{x-1}{4}\,dx + \int_3^5 (x-2)\frac{5-x}{4}\,dx
\end{align*}
$$

which is choice **(E)**.

Choices (B) and (D) split only at 3, handling the density but not the absolute value. Choice (A) uses $(2-x)$ on the last piece and choice (C) has the two forms swapped on the first two pieces — both would produce negative contributions, which is impossible for the expectation of a quantity that is never negative. That sign check alone eliminates every wrong option.
