An actuary is asked to model a non-negative response variable and requires that the model form produces an unbiased estimate.

Determine which error structure and link function combination would be the best choice for the modelling request.

- A) Poisson and Identity
- B) Compound Poisson-Gamma and Log
- C) Normal and Identity
- D) Gamma and Log
- E) Poisson and Log

## Explanation

Work through the two requirements.

**Non-negative response.** A normal error structure puts probability on negative values, and an identity link can predict a negative mean. That rules out C, and A as well (a Poisson mean must stay positive, which the identity link does not guarantee). The log link keeps every prediction positive, which leaves B, D and E.

**Unbiased.** When a GLM uses its distribution's *canonical* link and includes an intercept, the maximum-likelihood equations force the fitted values to sum to the observed values, $\sum \hat{\mu}_i = \sum y_i$ — the model is unbiased in aggregate, and within every level of each categorical predictor. The log link is canonical for the Poisson. It is not canonical for the gamma (whose canonical link is the inverse) or for the compound Poisson-gamma, i.e. Tweedie with $1 < p < 2$ (whose canonical link is $\mu^{1-p}$), so B and D carry no such guarantee.

Poisson with a log link satisfies both requirements, so the answer is **E**.
