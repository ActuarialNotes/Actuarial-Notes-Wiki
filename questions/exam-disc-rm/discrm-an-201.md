An insurer's commercial property guide grants this authority:

- **Producer:** approved classes, total insured value (TIV) up to \$1,500,000, no loss over \$20,000 in the past three years.
- **Line underwriter:** approved classes, TIV up to \$8,000,000, any loss history.
- **Senior underwriter:** approved and borderline classes, TIV up to \$20,000,000.
- **Home office:** everything else.

A submission is a print shop, a borderline class, with TIV of \$1,200,000 and no losses. Who must decide it?

- A) The producer, because its value and loss history are both within the producer's limits
- B) The line underwriter, because the account is small and has no losses at all
- C) The senior underwriter, because only that level may accept a borderline class
- D) The home office, because borderline classes always go to the top level

## Explanation

Each criterion gives the lowest level that can handle it, and the account goes to the highest of those levels. The value and the loss history would allow the producer to bind it, but the class is borderline, and the first level allowed to accept a borderline class is the senior underwriter. The strictest criterion decides, so the answer is **C**.

**Why not the others**

- **A** — Checks only value and losses and ignores the class criterion, which the producer's authority does not cover.
- **B** — The line underwriter's authority is limited to approved classes, however small the account.
- **D** — The guide gives senior underwriters authority over borderline classes up to \$20,000,000, so the account need not go higher.
