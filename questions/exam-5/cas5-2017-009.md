Given the following information for an insurance company:

| State | Class | Exposures | Losses | Current Pure Premium |
|---|---|---|---|---|
| A | 1 | 200 | \$800 | 4.00 |
| A | 2 | 300 | \$2,100 | 7.00 |
| A | Subtotal | 500 | \$2,900 | 5.80 |
| B | 1 | 300 | \$600 | 2.00 |
| B | 2 | 300 | \$1,500 | 5.00 |
| B | Subtotal | 600 | \$2,100 | 3.50 |
| C | 1 | 500 | \$1,500 | 3.00 |
| C | 2 | 750 | \$4,500 | 6.00 |
| C | Subtotal | 1,250 | \$6,000 | 4.80 |
| All | 1 | 1,000 | \$2,900 | 2.90 |
| All | 2 | 1,350 | \$8,100 | 6.00 |
| All | Total | 2,350 | \$11,000 | 4.68 |

- Full credibility standard is 1,500 exposures.

## Part a (1.5 points)

Calculate the credibility-weighted pure premium for class 2, state B using Harwayne's method.

### Answer
\$4.78 per exposure

### Explanation
Harwayne's method builds the complement of credibility for a class in one state out of the *other* states' experience for that class — but first strips out the distortion caused by those states having a different class mix. Taking the other states' raw class 2 pure premiums directly would import their exposure distribution along with their loss experience.

**Step 1 — restate each other state's overall pure premium at state B's class distribution.** State B has 300 class 1 and 300 class 2 exposures, so re-weight states A and C using 300/300:

$$\text{PP}_A^{\,\text{at }B} = \frac{4.00(300) + 7.00(300)}{600} = \frac{3{,}300}{600} = 5.50$$

$$\text{PP}_C^{\,\text{at }B} = \frac{3.00(300) + 6.00(300)}{600} = \frac{2{,}700}{600} = 4.50$$

State B's own overall pure premium is $2{,}100/600 = 3.50$. This is the like-for-like comparison: three overall pure premiums, all on the same class mix, so any remaining difference is a genuine state effect rather than a mix effect.

**Step 2 — state adjustment factors.** Each factor scales the other state down to state B's overall cost level:

$$f_A = \frac{3.50}{5.50} = 0.6364 \qquad f_C = \frac{3.50}{4.50} = 0.7778$$

**Step 3 — restate the other states' class 2 pure premiums at state B's level.**

$$\text{PP}_{A,2}^{\,\text{adj}} = 0.6364 \times 7.00 = 4.4545 \qquad \text{PP}_{C,2}^{\,\text{adj}} = 0.7778 \times 6.00 = 4.6667$$

**Step 4 — the complement of credibility.** Weight the two adjusted figures by each state's **class 2** exposures ($300$ in A, $750$ in C):

$$\text{Complement} = \frac{300(4.4545) + 750(4.6667)}{1{,}050} = \frac{1{,}336.36 + 3{,}500.00}{1{,}050} = 4.6061$$

**Step 5 — credibility of state B's own class 2 experience.** By the square root rule against the 1,500-exposure standard, on the 300 class 2 exposures in state B:

$$Z = \min\left(\sqrt{\frac{300}{1{,}500}},\, 1\right) = \sqrt{0.20} = 0.4472$$

**Step 6 — credibility weighting.** State B's own class 2 pure premium is $1{,}500/300 = 5.00$:

$$\text{PP}^{cw} = 0.4472(5.00) + 0.5528(4.6061) = 2.2361 + 2.5462 = \mathbf{4.78}$$

Note that the credibility standard and the exposure weights in step 4 both use **class 2** exposures, not the state subtotals — the estimate being credibility-weighted is a class 2 pure premium.

### Examiner Report
Candidates were expected to work Harwayne's method end to end: re-weight the other states' overall pure premiums at the subject state's class distribution, form the adjustment factors, apply them to the other states' class 2 pure premiums, weight those into a complement, compute the square-root credibility of the subject experience, and credibility-weight.

Common errors included not using Harwayne's method at all, when the question named it; omitting the re-weighted overall pure premiums for states A and C; computing the adjustment factors upside down; misweighting the complement; stopping once the complement was calculated without going on to credibility-weight; miscomputing the credibility; using the wrong pure premium for state B class 2; and applying $Z$ to the complement and $(1-Z)$ to the subject experience rather than the other way round.

## Part b (0.5 points)

Discuss the appropriateness of using Harwayne's method for this company.

### Answer
Appropriate — the states have materially different class distributions, which is precisely the distributional bias Harwayne's method removes, and state B class 2 is too thin to stand on its own.

### Explanation
The method is appropriate here for two reinforcing reasons.

**The class mix genuinely differs by state.** State B is split 50/50 between class 1 and class 2 (300 and 300), while states A and C are both weighted toward the more expensive class 2 (300 of 500, and 750 of 1,250 — 60% each). Using the other states' class 2 experience without adjustment would carry that mix difference into the complement. Harwayne's method exists to remove exactly this distributional bias, so the data pattern in this exhibit is the case it was designed for.

**State B class 2 needs a complement.** With 300 exposures against a 1,500-exposure full credibility standard, $Z = 0.45$: over half the estimate has to come from somewhere else, so the quality of the complement matters a great deal. A well-constructed complement is worth the extra computation here.

Low volume across all three states is *not* an argument against the method — Harwayne's method addresses distributional bias in the aggregate experience and works perfectly well on thin data.

### Examiner Report
Candidates were expected to evaluate Harwayne's method against the specific data given, and to recognize that its appropriateness rests on the differing class distributions across states: the method corrects for distributional bias, and that bias is present here.

Common errors included commenting only on credibility, or on the general merits of using a complement of credibility, without addressing Harwayne's method itself as the question required; and concluding that the method was inappropriate because volume was low in all three states, when low volume is a reason to seek a good complement rather than a bar to this one.

## Part c (0.75 points)

Evaluate Harwayne's method using three desirable qualities for a complement of credibility.

### Explanation
Any three of the six desirable qualities, each stated *and* applied to Harwayne's method:

**Unbiased.** The whole construction is an adjustment for bias: re-weighting each other state's experience at the subject state's class distribution removes the distributional bias that would otherwise arise from the states having different class mixes. On this criterion the method scores well.

**Logical relationship to the quantity being estimated.** The complement is built from the *same class* in *other states*, restated to the subject state's cost level. There is a clear and defensible connection between that and the class 2 pure premium in state B, so the complement is not an arbitrary benchmark.

**Easy to compute.** This is the method's weak point. It requires class-level exposure and loss detail for every state and a multi-step re-weighting for each one — doable, but appreciably more work than simpler complements such as the countrywide class relativity, and demanding of the data.

Three others could be used instead:

- **Available.** The company already reports exposures and losses by state and class, so the required data is on hand.
- **Accurate.** Pooling several other states supplies far more exposure than state B class 2 has on its own, so the complement carries less process variance than the subject estimate it supplements.
- **Statistically independent of the base statistic.** The complement is drawn from states A and C, which contribute nothing to state B's own class 2 experience, so the two quantities being weighted are independent.

### Examiner Report
Candidates were expected to name three desirable qualities of a complement of credibility and judge Harwayne's method against each. This part was general rather than tied to the exhibit data used in parts a and b.

The one common error was listing the desirable qualities without saying how each applies to Harwayne's method — the evaluation, not the list, was what the part asked for.
