## [F-001] Explanation's closed form for the geometric annuity carries a spurious 1/1.03 factor
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-28T14:47Z/aa33
- date: 2026-09-28
- severity: major
- status: open
- locus: Explanation, lines 50 and 52
- claim: Line 50: X (1 - (1.02/1.03)^20)/(0.03 - 0.02) · 1/1.03 = X (1 - 1.02^20/1.03^20)/0.01 · 1/1.03; line 52: X (1/1.03 - 1.02^20/1.03^21)/0.01 = X · 17.7267.
- evidence: SOA's solution (solutions PDF p.52, page image): 200,000 = X (1/1.03 - 1.02^20/1.03^21)/(1 - 1.02/1.03) = 17.7267X. The denominator 1 - 1.02/1.03 equals 0.01/1.03, not 0.01; the page replaces it by 0.01 (0.03 - 0.02) and keeps the 1/1.03, so both expressions on lines 50 and 52 evaluate to 17.2104, not 17.7267 (recomputed: (1 - (1.02/1.03)^20)/0.01 = 17.726695; the same divided by 1.03 = 17.210384). The page's number 17.7267, X = 11,282.42 and the final payment 16,436.36 are right, so the key (B) is unaffected, but the stated formula — PV = (1 - ((1+g)/(1+i))^n)/(i - g) · 1/(1+i) — is off by a factor (1+i) and would misprice any geometric annuity-immediate a student used it on (here X = 200,000/17.2104 = 11,621 and a final payment of 16,929, not an option).
- source_rank: 1
- proposed_action: Drop the '· 1/1.03' factors on line 50 (leaving X(1 - (1.02/1.03)^20)/0.01 = 17.7267X) and write line 52's denominator as SOA's 1 - 1.02/1.03, or delete line 52 — a maintainer's call on how the derivation should read.
- applied: false
- fingerprint: dcc59b1325de
