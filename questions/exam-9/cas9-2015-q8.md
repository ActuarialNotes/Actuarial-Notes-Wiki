Given the following information about bonds with annual coupon payments:

| Bond | Par Value | Time to Maturity (in years) | Annual Coupon Rate | Bond Price |
|---|---|---|---|---|
| 1 | \$100 | 1 | 2% | \$97.89 |
| 2 | \$100 | 2 | 4% | Not Given |
| 3 | \$100 | 3 | 4% | Not Given |
| 4 | \$100 | 4 | 0% | \$81.34 |

| Forward Rate Agreement | Lending Period Begins | Term | Principal | Annual Effective Interest Rate | Value (to Lender) |
|---|---|---|---|---|---|
| A | in 2 years | 1 year | \$1,000,000 | 6.4% | \$6,000 |
| B | in 3 years | 1 year | \$2,000,000 | 7.5% | \$26,000 |

Calculate the price of Bond 3.

### Explanation
$f_t$ is forward rate from $t$ to $t+1$.

$$97.89 = \frac{102}{(1 + r_1)} \;\Rightarrow\; r_1 = 4.2\%; \qquad 81.34 = \frac{100}{(1 + r_4)^4} \;\Rightarrow\; r_4 = 5.3\%$$

$$26{,}000 = \frac{2{,}000{,}000 \times (.075 - f_3) \times (4 - 3)}{(1 + r_4)^4} = \frac{2{,}000{,}000 \times (.075 - f_3) \times (1)}{(1 + .053)^4} \qquad f_3 = 5.9\%$$

$$(1 + r_4)^4 = (1 + r_3)^3(1 + f_3) \qquad (1 + .053)^4 = (1 + r_3)^3(1 + .059) \qquad r_3 = 5.1\%$$

$$6{,}000 = \frac{1{,}000{,}000 \times (.064 - f_2) \times (3 - 2)}{(1 + r_3)^3} = \frac{1{,}000{,}000 \times (.064 - f_2) \times (1)}{(1 + .051)^3} \qquad f_2 = 5.7\%$$

$$(1 + r_3)^3 = (1 + r_2)^2(1 + f_2) \qquad (1 + .051)^3 = (1 + r_2)^2(1 + .057) \qquad r_2 = 4.8\%$$

$$\text{Bond 3} = \frac{4}{(1 + r_1)} + \frac{4}{(1 + r_2)^2} + \frac{104}{(1 + r_3)^3} = \frac{4}{(1 + .042)} + \frac{4}{(1 + .048)^2} + \frac{104}{(1 + .051)^3}$$

Bond 3 = \$97.06

Alternatively:

$$97.89 = \frac{102}{(1 + r_1)} \;\Rightarrow\; r_1 = 4.2\%; \qquad 81.34 = \frac{100}{(1 + r_4)^4} \;\Rightarrow\; r_4 = 5.3\%$$

$$26{,}000 = \frac{2{,}000{,}000 \times (f_3 - .075) \times (4 - 3)}{(1 + r_4)^4} = \frac{2{,}000{,}000 \times (f_3 - .075) \times (1)}{(1 + .053)^4} \qquad f_3 = 9.1\%$$

$$(1 + r_4)^4 = (1 + r_3)^3(1 + f_3) \qquad (1 + .053)^4 = (1 + r_3)^3(1 + .091) \qquad r_3 = 4.06\%$$

$$6{,}000 = \frac{1{,}000{,}000 \times (f_2 - .064) \times (3 - 2)}{(1 + r_3)^3} = \frac{1{,}000{,}000 \times (f_2 - .064) \times (1)}{(1 + .0406)^3} \qquad f_2 = 7.08\%$$

$$(1 + r_3)^3 = (1 + r_2)^2(1 + f_2) \qquad (1 + .0406)^3 = (1 + r_2)^2(1 + .0708) \qquad r_2 = 2.58\%$$

$$\text{Bond 3} = \frac{4}{(1 + r_1)} + \frac{4}{(1 + r_2)^2} + \frac{104}{(1 + r_3)^3} = \frac{4}{(1 + .042)} + \frac{4}{(1 + .0258)^2} + \frac{104}{(1 + .0406)^3}$$

Bond 3 = \$99.94

Alternatively:

$$97.89 = \frac{102}{(1 + r_1)} \;\Rightarrow\; r_1 = 4.20\%$$

$$26{,}000 = \frac{2{,}000{,}000 \times (.075 - f_3) \times (4 - 3)}{(1 + f_3)} = \frac{2{,}000{,}000 \times (.075 - f_3) \times (1)}{(1 + f_3)} \qquad f_3 = 6.12\%$$

$$6{,}000 = \frac{1{,}000{,}000 \times (.064 - f_2) \times (3 - 2)}{(1 + f_2)} = \frac{1{,}000{,}000 \times (.064 - f_2) \times (1)}{(1 + f_2)} \qquad f_2 = 5.77\%$$

$$100 = 81.34 * (1 + r_1)(1 + f_1)(1 + f_2)(1 + f_3)$$

$$100 = 81.34 * (1 + .0420)(1 + f_1)(1 + .0577)(1 + .0612) \qquad f_1 = 5.12\%$$

$$\text{Bond 3} = \frac{4}{(1 + r_1)} + \frac{4}{(1 + r_1)(1 + f_1)} + \frac{104}{(1 + r_1)(1 + f_1)(1 + f_2)} = \frac{4}{(1 + .0420)} + \frac{4}{(1 + .0420)(1 + .0512)} + \frac{104}{(1 + .0420)(1 + .0512)(1 + .0577)}$$

Bond 3 = \$97.26

Alternatively:

$$97.89 = \frac{102}{(1 + r_1)} \;\Rightarrow\; r_1 = 4.20\%$$

$$26{,}000 = 2{,}000{,}000 * (.075 - f_3) * (4 - 3) \qquad f_3 = 6.20\%$$

$$6{,}000 = 1{,}000{,}000 * (.064 - f_2) * (3 - 2) \qquad f_2 = 5.80\%$$

$$100 = 81.34 * (1 + r_1)(1 + f_1)(1 + f_2)(1 + f_3)$$

$$100 = 81.34 * (1 + .0420)(1 + f_1)(1 + .0580)(1 + .0620) \qquad f_1 = 5.01\%$$

$$\text{Bond 3} = \frac{4}{(1 + r_1)} + \frac{4}{(1 + r_1)(1 + f_1)} + \frac{104}{(1 + r_1)(1 + f_1)(1 + f_2)} = \frac{4}{(1 + .0420)} + \frac{4}{(1 + .0420)(1 + .0501)} + \frac{104}{(1 + .0420)(1 + .0501)(1 + .0580)}$$

Bond 3 = \$97.33

Alternatively:

$$97.89 = \frac{102}{(1 + r_1)} \;\Rightarrow\; r_1 = 4.2\%; \qquad 81.34 = \frac{100}{(1 + r_4)^4} \;\Rightarrow\; r_4 = 5.3\%$$

$f_2 = 6.4\%$ (given)

$f_3 = 7.5\%$ (given)

$$(1 + r_4)^4 = (1 + r_3)^3(1 + f_3) \qquad \frac{100/81.34}{1.075} = (1 + r_3)^3 \qquad r_3 = 4.575\%$$

$$(1 + r_3)^3 = (1 + r_2)^2(1 + f_2) \qquad (1 + .04575)^3 = (1 + r_2)^2(1 + .064) \qquad r_2 = 3.67\%$$

$$\text{Bond 3} = \frac{4}{(1 + r_1)} + \frac{4}{(1 + r_2)^2} + \frac{104}{(1 + r_3)^3} = \frac{4}{(1 + .042)} + \frac{4}{(1 + .0367)^2} + \frac{104}{(1 + .04575)^3}$$

Bond 3 = \$98.50

### Examiner Report
The candidate was expected to understand how to calculate a spot rate, forward rate, and bond price.  Demonstrating how to apply the spot and forward rates correctly was required.  As a general rule it was expected that the candidate be familiar with valuing a forward rate agreement.
However, this was not required for full credit (see sample solution 5).  Either annual or continuous compounding was deemed appropriate.
Many candidates had difficulty applying or interpreting the rates correctly throughout the problem.  In particular, many candidates used the forward rate incorrectly in place of the spot rate and many used the wrong discount rate in the forward rate agreement.  Another common error was overlooking the \$2M nominal rate in FRA B and using \$1M instead.  Some candidates added a fourth term to "Bond 3".
This question was challenging due to the number and length of computations required.  Many candidates had trouble applying or interpreting the output of each calculation.
A variety of answers were accepted as the question could be interpreted multiple ways.  Some common methodologies that were accepted include:

- evaluation of FRA done from different company perspective
- candidate treated the given FRA value as at the beginning of FRA period
- candidate treated the given FRA value as at the end of FRA period
- candidate treated the given effective interest rates as forward rates
