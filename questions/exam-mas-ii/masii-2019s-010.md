You are building a Linear Mixed Model with constant variance at each time point. The covariance matrix for the residuals for a given subject, $\mathbf{R}_i$, has a constant diagonal structure. Consider the following statements about $\mathbf{R}_i$.

- I. This structure is often used in an experiment with repeated trials under the same condition.
- II. The residuals associated with observations of the same subject are assumed to be uncorrelated.
- III. This matrix requires only one parameter to be specified.

Determine which of the preceding statements are true.

- A) None of I, II, or III is true
- B) I and II only
- C) I and III only
- D) II and III only
- E) The correct answer is not given by (A), (B), (C), or (D)

## Explanation

A constant-diagonal (scaled identity) residual structure is

$$
\mathbf{R}_i = \sigma^2 \mathbf{I}_{n_i}.
$$

**I is false.** Repeated trials on the same subject under the same condition are precisely the setting where residuals *are* expected to be correlated — a compound-symmetry or first-order autoregressive structure is used there. The scaled identity is the structure used when, conditional on the random effects, the within-subject residuals carry no remaining dependence.

**II is true.** Every off-diagonal entry is zero, so residuals within a subject are uncorrelated by construction.

**III is true.** The single unknown is $\sigma^2$; the identity supplies everything else.

Statements II and III only, so the answer is **D**.
