A continuous random variable $X$ has density $f(x)$, with $f(3) = 0.20$. What is $P(X = 3)$?

- A) 0.20, the height of the density there
- B) 0.20 only if $f$ is also the CDF at that point
- C) Exactly 0, since a single point has no width
- D) Undefined for a continuous variable
