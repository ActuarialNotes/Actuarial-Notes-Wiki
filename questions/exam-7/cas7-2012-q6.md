Given the following information for an insurance company's book of policies with a \$250,000 deductible:

| Age-to-Age Loss and ALAE Development Factors | 12-24 | 24-36 | 36-48 | 48-60 | 60-72 |
|---|---|---|---|---|---|
| Limited | 1.720 | 1.151 | 1.072 | 1.025 | 1.011 |
| Excess | 2.577 | 1.412 | 1.350 | 1.281 | 1.316 |

| Age (months) | 12 | 24 | 36 | 48 | 60 | 72 |
|---|---|---|---|---|---|---|
| Limited Severity Relativities ($R^L$) | 0.975 | 0.963 | 0.955 | 0.944 | 0.931 | 0.912 |

Calculate the unlimited 36-72 month development factor.

### Explanation
36-72 dev. factor = 36-48 factor × 48-60 factor × 60-72 factor

Limited = 1.072 × 1.025 × 1.011 = 1.111

Excess = 1.350 × 1.281 × 1.316 = 2.726 (as printed)

$$LDF_{36\text{-}48} = LDF^L_{36\text{-}48} \cdot R_{36} + LDF^{XS}_{36\text{-}48}(1 - R_{36}) = 1.072(0.955) + 1.350(1 - 0.955) = 1.085$$

$$LDF_{48\text{-}60} = 1.035(0.944) + 1.281(1 - 0.944) = 1.039$$

(1.035 as printed)

$$LDF_{60\text{-}72} = 1.011(0.931) + 1.316(1 - 0.931) = 1.032$$

$$\text{total } LDF_{36\text{-}72} = 1.088 \times 1.039 \times 1.032 = 1.163$$

(1.088 as printed)

Alternatively:

$$\text{Limited } LDF_{36\text{-}72} = (1.072)(1.025)(1.011) = 1.111$$

$$\text{XS } LDF_{36\text{-}72} = (1.35)(1.281)(1.316) = 2.276$$

$R^L$ = 9.55 (as printed) – the 36 month rel

$$\text{Unlimited } LDF_{36\text{-}72} = (\text{LimLDF}_{36\text{-}72}(R^L) + (\text{XSLDF}_{36\text{-}72})(1 - R^L) = (1.111)(.955) + (2.276)(1 - .955) = 1.163$$

Alternatively:

$$\text{From } \frac{LDF^L_{36\text{-}72}}{LDF_{36\text{-}72}} = \frac{R^L_{72}}{R^L_{36}}, \text{ and } LDF^L_{36\text{-}72} = 1.072 \times 1.025 \times 1.011 = 1.1109$$

$$R^L_{72} = 0.912 \qquad R^L_{36} = 0.955$$

$$\therefore LDF_{36\text{-}72} = \frac{1.1109}{0.912} \times 0.955 = 1.163$$

Alternatively:

$$LDF_t = LDF_t^L \times R^L + XSLDF_t^L(1 - R^L)$$

$$LDF_t^L = LDF_t\, \Delta R^L$$

$$XSLDF_t^L = LDF_t\, \Delta(1 - R^L)$$

| | 36-72 |
|---|---|
| Limited: | 1.072×1.025×1.011 = 1.1108868 |
| Excess: | 1.35×1.281×1.316 = 2.2758246 |

Using $LDF_t^L = LDF_t + \Delta R^L$ (as printed)

$$\Rightarrow 1.1108868 = LDF_t + (.912/.955) \text{ (as printed)}$$

$$\Rightarrow LDF_t = (1.1108/.95497) = 1.163$$

If using $XSLDF_t^L = LDF_t \Delta(1 - R^L)$

$$2.2758 = LDF_t + ((1 - .912)/(1 - .955)) \text{ (as printed)} = LDF_t \times 1.955$$

$$LDF_t = 1.163$$

### Examiner Report
For this question, most candidates received full credit.

The following was a common error that yielded a correct final factor but used incorrect methodology. We gave partial credits for this response.

$$\text{LDF}_t^{L} = 1.072 \times 1.025 \times 1.011 = 1.1109$$

$$\text{XSLDF}_t^{L} = 1.316 \times 1.281 \times 1.35 = 2.2758$$

$$\text{LDF}_t = 1.1109 \times (.912/.955) + 2.2758 \times (1 - .912/.955)$$

$$\text{LDF}_{t\,72} = 1.1633$$
