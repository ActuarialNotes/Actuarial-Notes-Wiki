You want to perform a regression of $Y$ onto predictors $X_1, X_2, \ldots, X_p$, using a large number of observations, and are considering the following modelling techniques:

- Lasso Regression
- Partial Least Squares
- Principal Component Analysis
- Ridge Regression

Determine how many of the above modelling procedures perform variable selection.

- A) 0
- B) 1
- C) 2
- D) 3
- E) 4

## Explanation

A procedure performs variable selection when the final model can leave some of the predictors out entirely — their coefficients are set exactly to zero.

**Lasso regression** — *performs selection.* The $\ell_1$ penalty $\lambda\sum_j |\beta_j|$ forces some coefficient estimates to be exactly zero once $\lambda$ is large enough, so the fitted model uses only a subset of the predictors.

**Ridge regression** — *does not.* The $\ell_2$ penalty $\lambda\sum_j \beta_j^2$ shrinks every coefficient toward zero but never sets any exactly to zero (unless $\lambda = \infty$), so all $p$ predictors stay in the model.

**Principal component analysis** and **partial least squares** — *do not.* Both are dimension-reduction methods: the regression is run on a few new directions $Z_1, \ldots, Z_M$, but each $Z_m$ is a linear combination of **all** $p$ original predictors. Fewer components are used, yet every predictor still contributes to the fit.

Only the lasso performs variable selection, so the count is 1 and the answer is **B**.
