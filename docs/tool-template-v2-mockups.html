Acceptance criteria

Rules the build must keep

  1. No exam logo on tool cards or the bank. The tint stays.
  2. A quantity has one swatch on every tool. Bar segments carry their own labels.
  3. A breadcrumb on every tool and on the bank. Back returns to the same place.
  4. "Takes from" and "Gives to" come from the tools' hand-offs, both ways. Hidden when empty; "+ N more" opens a list; "Gives to" shows which value fills which field.
  5. A value carried by "Gives to" arrives linked, not as the reader's own.
  6. One "from" chip shape. Always on a judgment and on changed inputs; default rows share one line.
  7. Published figures and links explain themselves in place, in two levels.
  8. A published figure with no value yet is listed, explained and unselectable.
  9. A figure that matches the answer is a comparison under the bar, with no Use button.
