Given the following information:

|  |  |
|---|---|
| Underwriting profit provision | 5% |

|  | Expenses (\$000) | % Fixed |
|---|---|---|
| Countrywide General Expenses | 3,648 | 75% |
| Countrywide Other Acquisition Expenses | 4,368 | 75% |
| State Tax, Licenses & Fees | 315 | 25% |
| State Commission & Brokerage | 1,868 | 0% |

|  | Countrywide | State |
|---|---|---|
| Earned Premium (\$000) | 80,948 | 18,036 |
| Written Premium (\$000) | 82,583 | 18,498 |
| Earned Exposures | 84,115 | 19,712 |
| Written Exposures | 87,476 | 20,217 |

Calculate the fixed expense fee per exposure.

### Explanation
Each expense is split into its fixed and variable parts. Countrywide expenses are spread over countrywide data and state expenses over state data; general expenses are incurred over the life of the policy, so they use **earned** premium and exposures, while other acquisition expenses, taxes, licenses and fees, and commissions are incurred when the policy is written, so they use **written** premium and exposures. Expenses are in thousands, so the fixed amounts are multiplied by 1,000.

**Average fixed expense per exposure**

| Expense | Fixed expense | Exposures | Per exposure |
|---|---|---|---|
| General | 3,648 × 75% = 2,736 | 84,115 earned (countrywide) | 32.53 |
| Other acquisition | 4,368 × 75% = 3,276 | 87,476 written (countrywide) | 37.45 |
| Taxes, licenses & fees | 315 × 25% = 78.75 | 20,217 written (state) | 3.90 |
| Commission & brokerage | 0 | | 0.00 |
| **Total** | | | **73.87** |

**Variable expense provision (as a ratio to premium)**

| Expense | Variable expense | Premium | Ratio |
|---|---|---|---|
| General | 3,648 × 25% = 912 | 80,948 earned (countrywide) | 1.13% |
| Other acquisition | 4,368 × 25% = 1,092 | 82,583 written (countrywide) | 1.32% |
| Taxes, licenses & fees | 315 × 75% = 236.25 | 18,498 written (state) | 1.28% |
| Commission & brokerage | 1,868 | 18,498 written (state) | 10.10% |
| **Total** | | | **13.82%** |

**Fixed expense fee.** The fee must also carry the variable expenses and profit it generates:

$$\text{Fee} = \frac{73.87}{1 - 0.1382 - 0.05} = \frac{73.87}{0.8118} = 91.00$$

The fixed expense fee is about \$91.00 per exposure.

### Examiner Report
Candidates were expected to demonstrate knowledge pertaining to the development of a fixed expense fee per exposure. Candidates were expected to split expenses into fixed and variable components; generate fixed and variable expense provisions by expense type (general, other acquisition, taxes, licenses & fees, and commissions); develop an average fixed expense amount per exposure; develop a variable expense provision as a proportion of premium; and ultimately calculate a fixed expense fee by incorporating variable expense and underwriting profit provisions.

Common errors included:

- Not developing a fixed expense fee after calculating an average fixed expense per exposure.
- Not developing a variable expense provision or incorrectly using exposures in the denominator to develop the provision.
- Not using the correct exposures in the denominator to develop the average fixed expense (e.g. using written exposures for general expenses or using countrywide exposures for the state taxes, licenses & fees).
- Developing the fixed expense as a percentage of premium using the correct written/earned, state/countrywide premiums, but then using a single ratio of premium to exposure to convert all expenses back to an average fixed expense per exposure (e.g.
using countrywide earned premium per exposure for the other acquisition expenses and taxes, licenses and fees).
- Not grossing up the final fixed expense fee to reflect the cost in dollars (i.e., candidates were expected to multiply the numerator at some point in the calculation by \$1,000 to result in the correct expense fee per policy).
