A loss $X$ is uniformly distributed on the interval $(0, 1{,}000)$. An insurance policy pays the amount of the loss in excess of a deductible of 200, up to a maximum payment of 500. Let $Y$ be the payment, so

$$Y = \min\big(\max(X - 200,\ 0),\ 500\big).$$

Which of the following statements about the random variable $Y$ is true?

- A) $Y$ is mixed: it has probability 0.2 at 0, probability 0.3 at 500, and a density in between
- B) $Y$ is continuous, since it is a function of the continuous loss $X$ and can take any value in $[0, 500]$
- C) $Y$ is discrete, since its distribution function has jumps, which a continuous random variable cannot have
- D) $Y$ is mixed: it has probability 0.2 at 0, and its distribution function has no jump at 500
- E) $Y$ is mixed: it has probability 0.2 at 0, probability 0.5 at 500, and a density in between

## Explanation

Find where $Y$ puts probability on single values:

$$
\begin{align*}
P(Y = 0) &= P(X \le 200) \\
         &= 0.2 \\[4pt]
P(Y = 500) &= P(X - 200 \ge 500) \\
           &= P(X \ge 700) \\
           &= 0.3
\end{align*}
$$

Between the two, for $y$ strictly between 0 and 500, $Y = X - 200$ has density $\tfrac{1}{1{,}000}$, which carries the remaining 1 - 0.2 - 0.3 = 0.5 of probability. Single values carry positive probability, so $Y$ is not continuous; it also takes a continuum of values with no single value carrying the middle 0.5, so it is not discrete either. $Y$ is **mixed**, and its distribution function jumps by 0.2 at 0 and by 0.3 at 500. The answer is **A**.

**Why not the others**

- **B** — a function of a continuous random variable need not be continuous. The deductible maps every loss below 200 to the single value 0, and the maximum maps every loss above 700 to 500.
- **C** — a jump in the distribution function rules out "continuous", not "mixed". A discrete random variable's distribution function is flat between its jumps, and this one rises steadily between 0 and 500.
- **D** — forgets the maximum payment. Every loss of 700 or more is paid exactly 500, so the distribution function jumps by 0.3 there.
- **E** — applies the maximum to the loss rather than the payment, $P(X > 500) = 0.5$. The payment reaches 500 only once the loss reaches 200 + 500 = 700.
