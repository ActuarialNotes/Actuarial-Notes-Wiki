Given the following information:

Age-to-Age Loss Development Factors

| Accident Year | 12-24 Months | 24-36 Months | 36-48 Months | 48-60 Months | 60-72 Months |
|---|---|---|---|---|---|
| 2009 | 2.50 | 1.45 | 1.06 | 1.05 | 1.01 |
| 2010 | 1.80 | 1.38 | 1.15 | 1.02 | |
| 2011 | 2.13 | 1.20 | 1.13 | | |
| 2012 | 2.18 | 1.36 | | | |
| 2013 | 1.95 | | | | |

| Degrees of Freedom | t-statistic for 0.9 |
|---|---|
| 1 | 3.078 |
| 2 | 1.886 |
| 3 | 1.638 |
| 4 | 1.533 |
| 5 | 1.476 |
| 6 | 1.440 |

Assume that $T = r \cdot [(n-2)/(1-r^2)]^{1/2}$ is $t$-distributed with $(n-2)$ degrees of freedom, where $r$ is the sample correlation coefficient.

Using Mack's correlation test with a 10% $t$-statistic significance standard, test the null hypothesis that the 12-24 month and 24-36 month age-to-age factors are independent.

### Explanation
Test the correlation of adjacent factors, using $X$ = 12-24 factor - 1 and $Y$ = 24-36 factor - 1 for the four accident years that have both:

| AY | $X$ | $Y$ | $X - E[X]$ | $Y - E[Y]$ | $(X - E[X])^2$ | $(Y - E[Y])^2$ | $(X - E[X])(Y - E[Y])$ |
|---|---|---|---|---|---|---|---|
| 2009 | 1.5000 | 0.4500 | 0.3475 | 0.1025 | 0.1208 | 0.0105 | 0.0356 |
| 2010 | 0.8000 | 0.3800 | (0.3525) | 0.0325 | 0.1243 | 0.0011 | (0.0115) |
| 2011 | 1.1300 | 0.2000 | (0.0225) | (0.1475) | 0.0005 | 0.0218 | 0.0033 |
| 2012 | 1.1800 | 0.3600 | 0.0275 | 0.0125 | 0.0008 | 0.0002 | 0.0003 |
| Mean / $\Sigma$ | 1.1525 | 0.3475 | | | 0.2463 | 0.0335 | 0.0278 |

$$r = \frac{\sum (X - E[X])(Y - E[Y])}{\left(\sum (X - E[X])^2 \sum (Y - E[Y])^2\right)^{0.5}} = \frac{0.0278}{(0.2463 \times 0.0335)^{0.5}} = 0.3065$$

With $n = 4$:

$$T = r\left[\frac{n-2}{1-r^2}\right]^{0.5} = 0.3065\left[\frac{4-2}{1-0.3065^2}\right]^{0.5} = 0.4553$$

The $t$-statistic for 2 degrees of freedom is 1.8860. Since $0.4553 < 1.8860$, we do not reject the null hypothesis: the 12-24 month and 24-36 month age-to-age factors are independent.

The examiners' report notes that the question named Mack's correlation test by mistake — the intended approach was Venter's correlation test, above — so responses built on elements of Mack's test (a Spearman rank correlation, $r = 0.400$, $T = 0.6172 < 1.8860$) also received full credit.

> **Note — the 2020 erratum.** The solution above is CAS's 2015 answer, which compares $T$ with the one-tailed $t$-statistic for 0.90. The CAS's *Errata to Testing the Assumptions of Age-to-Age Factors* (Version 1.0, January 31, 2020; on the current Exam 7 syllabus) amends Venter p. 833: since correlations can be positive or negative, the test is two-tailed, and $r$ is significant at the 10% level only if $|T|$ exceeds the $t$-statistic for **0.95** at $n-2$ degrees of freedom. At 2 degrees of freedom that is 2.920, and $0.4553 < 2.920$, so the conclusion is unchanged: the independence of the 12-24 and 24-36 month factors is not rejected.

### Examiner Report
Overall, many candidates performed very well on this question. Candidates needed to know key assumptions of the chain ladder models and how to test these assumptions. The core of the question is determining whether the age-to-age factors are independent.
The question referenced Mack's correlation test by mistake; the intended approach was to use Venter's correlation test. Due to this error, we accepted a variety of responses which used some elements of Mack's correlation test.
