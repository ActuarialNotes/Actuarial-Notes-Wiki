A personal auto underwriter wants an applicant's history of traffic convictions and accidents. Which source provides it?

- A) A loss run from the applicant's prior insurer
- B) The vehicle's make and model rating
- C) A credit-based insurance score
- D) A motor vehicle record

## Explanation

A motor vehicle record (MVR) summarizes a driver's convictions and accidents on file with the home state, and it is one of the primary tools of auto underwriting. Personal auto underwriting also weighs use, garaging, the vehicle and, where permitted, credit-based insurance scores, but those don't show the driving record. The answer is **D**.

**Why not the others**

- **A** — A loss run reports the claims an insurer handled, not traffic convictions.
- **B** — The vehicle's rating reflects the car, not the driver.
- **C** — A credit-based score is built from credit information, not driving history.
