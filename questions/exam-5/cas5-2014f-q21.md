Given the following information for an insurance company:

Gross Cumulative Reported Claims ($000)

| Accident Year | 12 Months | 24 Months | 36 Months | 48 Months |
|---|---|---|---|---|
| 2010 | 3,500 | 8,120 | 12,180 | 14,616 |
| 2011 | 3,000 | 6,840 | 10,465 | |
| 2012 | 3,300 | 7,656 | | |
| 2013 | 3,250 | | | |

Net Cumulative Reported Claims ($000)

| Accident Year | 12 Months | 24 Months | 36 Months | 48 Months |
|---|---|---|---|---|
| 2010 | 2,275 | 5,278 | 7,917 | 9,500 |
| 2011 | 2,100 | 4,788 | 7,326 | |
| 2012 | 2,475 | 5,742 | | |
| 2013 | 2,600 | | | |

- Assume no further development after 48 months.

## Part a (0.5 points)

Using the data, determine the structure of the company's reinsurance program.

### Explanation
Accepted Answer 1

Net to Gross triangle

| Accident Year | 12 Months | 24 Months | 36 Months | 48 Months |
|---|---|---|---|---|
| 2010 | 0.65 | 0.65 | 0.65 | 0.65 |
| 2011 | 0.70 | 0.70 | 0.70 | |
| 2012 | 0.75 | 0.75 | | |
| 2013 | 0.80 | | | |

Since the net to gross ratios are consistent along the accident years, we know that the reinsurance structure is Quota Share.

Accepted Answer 2

2010 has 65% quota share, 2011 has 70% quota share, 2012 has 75% quota share, 2013 has 80% quota share.

### Examiner Report
The candidate needed to show some calculation and deduce that the reinsurance structure was quota share.
Most candidates got full credit on this part. The most common error was claiming the reinsurance was excess loss because the net / gross ratios changed year over year.

## Part b (1.5 points)

Estimate the ceded IBNR for accident year 2013.

### Explanation
Gross age-to-age reported claim development factors (shared by all three approaches):

| AY | 12-24 Months | 24-36 Months | 36-48 Months |
|---|---|---|---|
| 2010 | 2.320 | 1.5 | 1.2 |
| 2011 | 2.280 | 1.53 | |
| 2012 | 2.320 | | |
| Select | 2.307 | 1.515 | 1.2 |
| Age-to-Ult | 4.194 | 1.818 | 1.2 |

Accepted Answer 1 — determine the gross IBNR, then apply the quota share percentage to get ceded.

$$\text{Gross IBNR} = 3{,}250{,}000(4.194) - 3{,}250{,}000 = 10{,}380{,}500$$

Net/Gross factor = 0.8, so the ceded factor = 0.2.

$$\text{Ceded IBNR} = 10{,}380{,}500 \times (1 - 0.8) = 2{,}076{,}100$$

Accepted Answer 2 — determine ceded by calculating gross ultimate and net ultimate separately.

$$\text{Gross Ultimate} = 3{,}250{,}000(4.194) = 13{,}630{,}500$$

$$\text{Net Ultimate} = 2{,}600{,}000(4.194) = 10{,}904{,}400$$

$$\text{Ceded Ultimate} = 13{,}630{,}500 - 10{,}904{,}400 = 2{,}726{,}100$$

$$\text{Ceded IBNR} = 2{,}726{,}100 - (3{,}250{,}000 - 2{,}600{,}000) = 2{,}076{,}100$$

Accepted Answer 3 — develop the ceded triangle directly.

Ceded Cumulative Reported Claims ($000)

| Accident Year | 12 Months | 24 Months | 36 Months | 48 Months |
|---|---|---|---|---|
| 2010 | $1,255 | $2,842 | $4,263 | $5,116 |
| 2011 | $900 | $2,052 | $3,139 | |
| 2012 | $825 | $1,914 | | |
| 2013 | $650 | | | |

$$\text{Ceded Ultimate} = 650{,}000(4.194) = 2{,}726{,}100$$

$$\text{Ceded IBNR} = 2{,}726{,}100 - 650{,}000 = 2{,}076{,}100$$

Note on the report's 2010 ceded figure: the published table prints $1,255 at 12 months, but gross minus net for 2010 at 12 months is $3,500 - $2,275 = $1,225. Nothing downstream uses the cell.

### Examiner Report
The candidate was expected to calculate and select age-ultimate factors, correctly develop ultimate claims, correctly take out paid claims (depending on the candidate's method) and keep track of gross/net/ceded claims.
Most candidates did very well on this part. The most common mistakes were:

- Not subtracting paid claims to get IBNR
- Providing net IBNR not ceded IBNR
- Applying 20% quota share to the net claim estimate, not the gross.
