Given the following information for a retrospectively rated book of business as of December 31, 2015:

| Policy Effective Year | Policy Effective Quarter | Ultimate Loss | Losses Reported at Prior Retro Adjustment |
|---|---|---|---|
| 2011 | 1 | \$92,500 | \$92,500 |
| 2011 | 2 | 57,000 | 57,000 |
| 2011 | 3 | 125,000 | 125,000 |
| 2011 | 4 | 80,000 | 78,000 |
| 2012 | 1 | 64,000 | 57,000 |
| 2012 | 2 | 37,500 | 30,000 |
| 2012 | 3 | 60,000 | 55,000 |
| 2012 | 4 | 65,000 | 60,000 |
| 2013 | 1 | 55,000 | 50,000 |
| 2013 | 2 | 40,000 | 33,000 |
| 2013 | 3 | 70,000 | 52,500 |
| 2013 | 4 | 60,000 | 45,000 |
| 2014 | 1 | 50,000 | 0 |
| 2014 | 2 | 40,000 | 0 |
| 2014 | 3 | 65,000 | 0 |
| 2014 | 4 | 45,000 | 0 |
| 2015 | 1 | 25,000 | 0 |
| 2015 | 2 | 20,000 | 0 |
| 2015 | 3 | 30,000 | 0 |
| 2015 | 4 | 5,000 | 0 |

| Retro Adjustment Period | Selected PDLD Ratio | Percent Loss Emerged |
|---|---|---|
| First | 1.75 | 78.5% |
| Second | 0.70 | 10% |
| Third | 0.55 | 7% |
| Fourth | 0.45 | 4% |
| Subsequent | 0.00 | 0.5% |

| Policy Period | Premiums Booked from Prior Adjustment | Premiums Booked as of December 31, 2015 |
|---|---|---|
| 2011 | \$450,000 | \$452,000 |
| 2012 | 335,000 | 337,000 |
| 2013 | 330,000 | 335,000 |
| 2014-2015 | 0 | 425,000 |

Calculate the premium asset as of December 31, 2015.

### Explanation
Cumulative PDLD ratios weight the remaining PDLD ratios by the loss expected to emerge at each remaining adjustment:

$$CPDLD_k = \frac{\sum PDLD \times \%\,\text{Loss Emerged}}{\sum \%\,\text{Loss Emerged}}$$

$$CPDLD_1 = 1.5, \quad CPDLD_2 = 0.588, \quad CPDLD_3 = 0.491, \quad CPDLD_4 = 0.4$$

Expected future loss = ultimate loss - loss reported as of the prior adjustment:

| AY | Expected Future Loss |
|---|---|
| 2011 | 2,000 |
| 2012 | 24,500 |
| 2013 | 44,500 |
| 2014 & 2015 | 280,000 |

Each policy year's next adjustment is the 4th (2011), 3rd (2012), 2nd (2013) or 1st (2014 and 2015), which fixes its CPDLD. Then

$$\text{Expected Future Prem} = \text{Expected Future Loss} \times CPDLD$$

$$\text{Prem Asset} = \text{Expected Future Prem} + \text{Prior Booked} - \text{Current Booked}$$

| AY | CPDLD | Future Premium | Premium Asset |
|---|---|---|---|
| 2011 | 0.4 | 800 | -1,200 |
| 2012 | 0.491 | 12,029.5 | 10,029.5 |
| 2013 | 0.588 | 26,166 | 21,166 |
| 2014 & 2015 | 1.5 | 420,000 | -5,000 |
| Total | | | 24,995.5 |

For example, for 2013: $330{,}000 + 26{,}166 - 335{,}000 = 21{,}166$. (The 2012 future premium is printed as "1,2029.5" in the examiner's report.)

The premium asset as of December 31, 2015 is 24,995.5.

Alternatively:

Carrying $CPDLD_3 = 0.4913$, the estimated future premiums are 800, 12,037, 26,166 and 420,000, and

$$\text{Prem asset} = \text{prem from prior adj} + \text{est future prem} - \text{premium booked now} = 1{,}574{,}003 - 1{,}549{,}000 = 25{,}003$$

### Examiner Report
Candidates were expected to know most calculations and how to interpret the item, with the understanding that it requires a long calculation with many subtle details.
The most common errors candidates made were simple calculation errors or calculator errors.
Also, a few candidates:

- Did not calculate expected future loss correctly
- Applied the CPDLD ratios to the wrong periods
- Used PDLD ratios instead of CPDLD ratios
- For the Premium asset formula, added current booked premium to expected future premium and subtracted prior booked premium (whereas they should have added prior booked premium to expected future premium and subtracted current booked premium)
Most candidates did very well (either received full credit or lost credit only for minor calculation errors).
