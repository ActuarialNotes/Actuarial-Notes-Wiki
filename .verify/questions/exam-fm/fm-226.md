## [F-001] Explanation derives v^n from a misstated premium-discount formula (v^n = 0.8715, inconsistent with n = 72)
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-28T14:47Z/aa33
- date: 2026-09-28
- severity: major
- status: open
- locus: Explanation, lines 47-66 (align blocks)
- claim: Explanation writes the second bond's price as 0.8 = v^n + ((4/9)i - i) a_n (called the premium-discount formula), reduces it to 0.8 = (14/9)v^n - 5/9 and concludes v^n = 9 x 1.3556/14 = 0.8715, then switches to a calculator (PV 0.8, I/Y 0.6218, PMT 0.002763, FV 1) to state n = 72.
- evidence: SOA solution 226 (solutions PDF p.57, page image) writes P = 0.8F = Fv^n + (4/9)(0.006218)F a_n, i.e. 0.8 = v^n + 0.0027634 a_n, and solves with the BA II Plus for n = 72. The premium-discount form of the same price is P/F = 1 + (r - i) a_n, not v^n + (r - i) a_n: the vault's first line mixes the two. Recomputation: with r = (4/9)i and i a_n = 1 - v^n, 0.8 = v^n + (4/9)(1 - v^n) gives (5/9)v^n = 0.8 - 4/9 = 0.35556, v^n = 0.64 = 0.8^2, n = 2 x 36 = 72 (D). The vault's v^n = 0.8715 (its own arithmetic (0.8 + 5/9)(9/14) = 0.87143 resolves from the wrong equation) implies n = 36 ln 0.87143 / ln 0.8 = 22.2 years, which is not an option and contradicts the n = 72 the final calculator line reports. Key D, stem and options are unaffected; the derivation a student would copy is wrong.
- source_rank: 1
- proposed_action: Maintainer to replace the two align blocks (lines 49-66) with a correct derivation, e.g. SOA's 0.8 = v^n + (4/9)(0.006218) a_n solved by calculator, or 0.8 = v^n + (4/9)(1 - v^n) => v^n = 0.64 = (0.8)^2 => n = 72. Not auto-fixed: requires composing new explanation text.
