An actuary working at an insurance company is using a frequency-severity technique to estimate ultimate claims. The company made an effort to close claims more quickly starting in 2014. Given the following information:

**Closed Claim Counts as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 435 | 600 | 670 | 705 |
| 2013 | 520 | 700 | 740 | |
| 2014 | 600 | 650 | | |
| 2015 | 620 | | | |

**Paid Claims (\$000s) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 393 | 650 | 765 | 776 |
| 2013 | 511 | 697 | 744 | |
| 2014 | 637 | 825 | | |
| 2015 | 722 | | | |

**Reported Claim Counts as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 600 | 670 | 720 | 730 |
| 2013 | 640 | 715 | 750 | |
| 2014 | 620 | 690 | | |
| 2015 | 650 | | | |

**Reported Claims (\$000s) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 560 | 720 | 780 | 790 |
| 2013 | 580 | 720 | 760 | |
| 2014 | 670 | 850 | | |
| 2015 | 760 | | | |

- 48-Ultimate reported claim count factor = 1.03.
- 48-Ultimate closed claim count factor = 1.06.
- 48-Ultimate paid severity factor = 1.15.
- 48-Ultimate reported severity factor = 1.02.

## Part a (0.5 points)

Determine whether evidence exists to support that claims are closing more quickly starting in 2014.

### Answer
Yes — the closed-to-reported claim count ratio jumps sharply on the calendar year 2014 diagonal.

### Explanation
Divide closed claim counts by reported claim counts, cell by cell:

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 0.725 | 0.896 | 0.931 | 0.966 |
| 2013 | 0.813 | 0.979 | 0.987 | |
| 2014 | 0.968 | 0.942 | | |
| 2015 | 0.954 | | | |

Read down each column, and be careful to track **calendar** years — the accident year 2014 row at 12 months is calendar year 2014, but the accident year 2014 row at 24 months is calendar year 2015.

- **At 12 months:** 0.725 (CY 2012) → 0.813 (CY 2013) → **0.968 (CY 2014)** → 0.954 (CY 2015). The step up into calendar year 2014 is large and holds in 2015.
- **At 24 months:** 0.896 (CY 2013) → **0.979 (CY 2014)**. Again a marked increase on the calendar year 2014 evaluation.

A higher proportion of reported claims already closed at the same maturity is precisely what accelerated settlement looks like, so the evidence supports the company's stated effort.

The ratio of paid to reported *claims* is an equally acceptable diagnostic and tells the same story — 0.702, 0.881, 0.951 down the 12-month column, and 0.903 → 0.968 into calendar year 2014.

### Examiner Report
Candidates were expected to build one of the acceptable diagnostic triangles, point out the relevant movement in it, and state explicitly that the movement indicates a speed-up in claim closure — describing either the increasing trend or the large jump in calendar year 2014.

Common mistakes included using age-to-age factors on the closed claim count triangle, which show a *slowdown* after 12 months rather than the effect asked about, and misreading the accident year 2014 row at 12–24 months as calendar year 2014. Many candidates cited the fall in the 24-month ratio from accident year 2013 to 2014 as proof that no speed-up occurred, when the relevant comparison in that column is the increase from accident year 2012 to 2013 — that is the calendar year 2014 evaluation.

## Part b (2.5 points)

Calculate an appropriate frequency-severity estimate of ultimate claims for accident years 2014 and 2015.

### Answer
AY 2014: approximately \$967,000; AY 2015: approximately \$1,095,000

### Explanation
Because the **closure rate has changed**, closed counts and paid severities are distorted — their historical development factors describe the old settlement pattern. Reported counts and reported severities are unaffected by when a claim is paid, so the estimate must be built on **reported** data throughout.

**Step 1 — develop reported claim counts.**

| AY | 12-24 | 24-36 | 36-48 |
|---|---|---|---|
| 2012 | $670/600 = 1.117$ | $720/670 = 1.075$ | $730/720 = 1.014$ |
| 2013 | $715/640 = 1.117$ | $750/715 = 1.049$ | |
| 2014 | $690/620 = 1.113$ | | |
| **Selected** | **1.116** | **1.062** | **1.014** |

All-year averages are used since the factors within each column are close together. With the given 48-to-ultimate factor of 1.03:

$$\text{CDF}_{24} = 1.062 \times 1.014 \times 1.03 = 1.109 \qquad \text{CDF}_{12} = 1.116 \times 1.109 = 1.238$$

$$N^{ult}_{2014} = 690 \times 1.109 = 765 \qquad N^{ult}_{2015} = 650 \times 1.238 = 805$$

**Step 2 — build the reported severity triangle** as reported claims divided by reported counts (in dollars):

| AY | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 933 | 1,075 | 1,083 | 1,082 |
| 2013 | 906 | 1,007 | 1,013 | |
| 2014 | 1,081 | 1,232 | | |
| 2015 | 1,169 | | | |

Both numerator and denominator are reported figures, which is what keeps the severity consistent — dividing paid claims by reported counts would mix the two bases.

**Step 3 — develop severity.**

| AY | 12-24 | 24-36 | 36-48 |
|---|---|---|---|
| 2012 | $1{,}075/933 = 1.151$ | $1{,}083/1{,}075 = 1.008$ | $1{,}082/1{,}083 = 0.999$ |
| 2013 | $1{,}007/906 = 1.111$ | $1{,}013/1{,}007 = 1.006$ | |
| 2014 | $1{,}232/1{,}081 = 1.140$ | | |
| **Selected** | **1.134** | **1.007** | **0.999** |

With the given 48-to-ultimate severity factor of 1.02:

$$\text{CDF}_{24} = 1.007 \times 0.999 \times 1.02 = 1.026 \qquad \text{CDF}_{12} = 1.134 \times 1.026 = 1.164$$

$$S^{ult}_{2014} = 1{,}232 \times 1.026 = \$1{,}264 \qquad S^{ult}_{2015} = 1{,}169 \times 1.164 = \$1{,}361$$

**Step 4 — multiply frequency by severity.**

$$\text{Ultimate claims}_{2014} = 765 \times 1{,}264 = \mathbf{\$967{,}000}$$

$$\text{Ultimate claims}_{2015} = 805 \times 1{,}361 = \mathbf{\$1{,}095{,}000}$$

The given closed count (1.06) and paid severity (1.15) tail factors are deliberate distractors — they belong to the paid/closed route this question's data rules out.

### Examiner Report
Candidates were expected to recognize that the change in claim closure rate requires reported rather than paid or closed data in the frequency-severity estimate, then to develop separate count and severity triangles into loss development factors and cumulative factors, estimate ultimate counts and ultimate severity, and combine the two into ultimate claims.

Common mistakes included using paid severity or closed claim counts to estimate the ultimates, which is not appropriate where closure rates are changing, and using a disposal rate method built on incremental severity — an approach that assumes there are no partial payments in the paid claim data.
