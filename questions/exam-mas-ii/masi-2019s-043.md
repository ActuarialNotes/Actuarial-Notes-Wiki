You are given an autoregressive time series of order 1:

$$
x_t = \alpha_1 x_{t-1} + w_t
$$

and the following time series graphs:

![Four time series plots labelled s1 to s4, each over Time 0 to 100 with a vertical axis marked -5, 0 and 5 (range about -8 to 8). s1: a jagged series centred on 0 that flips sign almost every step, with swings mostly within about ±4 and some calmer stretches. s2: a smoother series centred on 0 that moves in short runs of the same sign rather than alternating, staying within about ±2.5. s3: flips sign almost every step like s1, but with much larger swings (up to about ±8) that come in long, persistent bursts. s4: a smooth wandering series with no pull back to 0, drifting from about -7 at time 0 up to about 8 near time 95](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/masi-2019s-q43-ar1-series.png)

Determine the most likely coefficient $\alpha_1$ for each graph, s1-s4.

- A) s1 = 0.90, s2 = 0.50, s3 = 0.99, s4 = 0.99
- B) s1 = 0.99, s2 = -0.50, s3 = 0.90, s4 = -0.99
- C) s1 = -0.90, s2 = 0.50, s3 = -0.99, s4 = 0.99
- D) s1 = -0.99, s2 = 0.50, s3 = -0.90, s4 = 0.99
- E) s1 = -0.90, s2 = 0.99, s3 = -0.99, s4 = 0.50

## Explanation

Two properties of a stationary AR(1) read straight off a plot. The lag-$k$ autocorrelation is $\alpha_1^k$, and the variance is

$$
\operatorname{Var}(x_t) = \frac{\sigma^2}{1 - \alpha_1^2}.
$$

**The sign of $\alpha_1$.** With $\alpha_1 < 0$, consecutive values are negatively correlated, so the series flips sign almost every step and looks jagged. With $\alpha_1 > 0$ it moves in runs of the same sign.

**The size of $|\alpha_1|$.** The closer $|\alpha_1|$ is to 1, the larger the swings and the longer a departure persists. At $|\alpha_1| = 0.90$ the standard deviation is $\sigma/\sqrt{0.19} = 2.3\sigma$; at 0.99 it is $\sigma/\sqrt{0.0199} = 7.1\sigma$. At $\alpha_1 = 0.99$ the series is close to a random walk and wanders with almost no pull back to its mean.

Matching the plots:

- **s4** wanders from about $-7$ up to about 8 with no visible return to 0, so it is nearly a random walk: $\alpha_1 = 0.99$.
- **s2** moves in short same-sign runs, stays within about $\pm 2.5$ and returns to 0 quickly, so it is positive and modest: $\alpha_1 = 0.50$.
- **s1** and **s3** both alternate sign step to step, so both are negative. s3 swings about twice as wide (to about $\pm 8$, against about $\pm 4$ for s1), in long persistent bursts, so it has the larger magnitude: s3 = $-0.99$ and s1 = $-0.90$.

That is s1 = $-0.90$, s2 = 0.50, s3 = $-0.99$ and s4 = 0.99, so the answer is **C**.
