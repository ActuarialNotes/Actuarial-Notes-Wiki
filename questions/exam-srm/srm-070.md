A dataset has 100 observations with six predictor variables, X1, X2, X3, X4, X5, and X6 and a response variable, Y. Three ordinary regression models have been run, with the following results:

| Model Number | Variables Used | Residual Sum of Squares | Residual Standard Error |
|---|---|---|---|
| I | X1 only | 183,663.30 | 43.2911 |
| II | X1 and X2 only | 8,826.47 | 9.5391 |
| III | X1, X2, X3, X4, X5, and X6 | 8,319.59 | 9.4582 |

The Akaike Information Criterion (AIC) is to be used to select the best model from these three choices.

Determine which of the following statements is true.

- A) Select Model I with an AIC value of 1,838.42
- B) Select Model I with an AIC value of 1,874.12
- C) Select Model II with an AIC value of 91.84
- D) Select Model II with an AIC value of 91.90
- E) Select Model III with an AIC value of 93.93

## Explanation

The AIC formula uses the estimated variance from the full model (Model III, with all six predictors):

$$\hat{\sigma}^2 = 9.4582^2 = 89.45755.$$

For a model with $d$ predictors fitted to $n = 100$ observations,

$$\text{AIC} = \frac{1}{n}\left(\text{RSS} + 2d\hat{\sigma}^2\right),$$

so for each model:

$$
\begin{align*}
\text{Model I:}\quad & \frac{183{,}663.30 + 2(1)(89.45755)}{100} = 1{,}836.42 \text{ (as printed)} \\
\text{Model II:}\quad & \frac{8{,}826.47 + 2(2)(89.45755)}{100} = 91.84 \\
\text{Model III:}\quad & \frac{8{,}319.59 + 2(6)(89.45755)}{100} = 93.93
\end{align*}
$$

The model with the smallest AIC should be selected, which is Model II with AIC = 91.84. (The SOA's printed solution gives Model I's value as 1,836.42; the arithmetic gives 1,838.42. Either way Model I is not selected.)

Note that the residual standard error did not have to be given. It can be calculated from the residual sum of squares, the sample size, and the number of predictors.
