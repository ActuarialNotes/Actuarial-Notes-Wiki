Given the following data as of December 31, 2014:

Cumulative Closed Claim Counts:

| Accident Year | 12 months | 24 months | 36 months |
|---|---|---|---|
| 2012 | 730 | 800 | 820 |
| 2013 | 750 | 825 | |
| 2014 | 775 | | |

Cumulative Paid Claims ($000):

| Accident Year | 12 months | 24 months | 36 months |
|---|---|---|---|
| 2012 | 2,250 | 2,600 | 2,700 |
| 2013 | 2,600 | 3,000 | |
| 2014 | 2,000 | | |

| Accident Year | Ultimate Claim Counts |
|---|---|
| 2012 | 820 |
| 2013 | 846 |
| 2014 | 874 |

- The latest diagonal is representative of current claim adjusting practices.
- There is no development beyond 36 months.
- Annual severity trend is 4%.

## Part a (2 points)

Using the disposal rate frequency-severity technique, calculate the ultimate claims.

### Explanation
**Disposal rates** (cumulative closed counts over ultimate counts):

| Accident Year | 12 months | 24 months | 36 months |
|---|---|---|---|
| 2012 | 0.890 | 0.976 | 1.000 |
| 2013 | 0.887 | 0.975 | |
| 2014 | 0.887 | | |
| **Selected** | **0.887** | **0.975** | **1.000** |

Select the latest diagonal, per the note in the problem that it is representative of current claim adjusting practices.

**Average severity, untrended** (incremental paid over incremental closed counts):

| Accident Year | 12 months | 24 months | 36 months |
|---|---|---|---|
| 2012 | 3,082 | 5,000 | 5,000 |
| 2013 | 3,467 | 5,333 | |
| 2014 | 2,581 | | |
| **Selected** | **2,581** | **5,333** | **5,000** |

Again the latest diagonal, for the same reason.

**Ultimate claims.** For each accident year, the claims still to be closed are the ultimate counts times the increase in disposal rate over each remaining interval, valued at the selected severity for that interval and trended forward at 4% per year from the latest diagonal:

$$\begin{align*}
\text{AY 2012} &= \$2{,}700{,}000 \quad \text{(development complete)} \\[4pt]
\text{AY 2013} &= [846(1 - 0.975)] \times 5{,}000 \times 1.04 + \$3{,}000{,}000 \\
               &= \$3{,}109{,}200 \\[4pt]
\text{AY 2014} &= [874(0.975 - 0.887)] \times 5{,}333 \times 1.04 \\
&\quad + [874(1 - 0.975)] \times 5{,}000 \times 1.04^{2} + \$2{,}000{,}000 = \$2{,}546{,}069
\end{align*}$$

### Examiner Report
The candidate was expected to know how to use the Disposal Rate Frequency Severity technique.  Most candidates were able to calculate disposal rates and project incremental claim counts correctly.

The most common mistakes included using cumulative average severity instead of incremental average severity and incorrectly applying the trend.

## Part b (0.5 points)

Assume accident year 2013 experienced a one-time increase in the severity of claim payments with no impact on frequency or disposal rates. Briefly discuss two adjustments to the disposal rate frequency-severity technique that would be appropriate in this scenario.

### Explanation
Adjust the 24 months expected severity for 2013 to reflect higher severity levels.
Exclude 2013 data from the calculation of average severity to be used for other AYs

Alternatively:

If we assume it was a law change in 2013 that continues for 2014, then the severity for 2012 can be adjusted to reflect the change. This should be done by adjusting the incremental severity triangle.

### Examiner Report
The candidate was expected to be able to provide at least one fix to the methodology.  Overall candidates scored poorly on this part, as they did not discuss how the adjustment should be made or to which year(s) the adjustment should be applied, but simply stated "adjust the data".
