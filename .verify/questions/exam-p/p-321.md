Q 321, solutions PDF p.89-90: "Solution: A" - X ~ Binomial(50, 1-p) and P(X >= t*) = sum_{t=t*}^{50} C(50,t)(1-p)^t p^(50-t), which must be at least 0.95, so A is correct. Independent recomputation before reading either key: sum_{k=n}^{50} C(50,k)(1-p)^k p^(50-k) >= 0.95 is the given condition P[X >= n] >= 0.95 restated, the one statement that must hold; in the vault option list that statement is option C, not D. The explanation contradicts itself: it derives P[X <= n-1] <= 0.05, says D is P[X <= n] <= 0.05 which only ensures P[X >= n+1] >= 0.95, then concludes P[X <= n-1] <= 0.05 corresponds to choice D.
