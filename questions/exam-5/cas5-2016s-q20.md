Given the following information:

Cumulative Closed Claim Counts as of (months):

| Accident Year | 12 | 24 | 36 | 48 | Estimated Ultimate Claim Count |
|---|---|---|---|---|---|
| 2012 | 3,314 | 4,260 | 4,340 | 4,380 | 4,380 |
| 2013 | 3,390 | 4,404 | 4,550 | | 4,596 |
| 2014 | 3,342 | 4,365 | | | 4,454 |
| 2015 | 3,607 | | | | 4,509 |

| Months | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| Selected Disposal Rate | 0.800 | 0.980 | 0.990 | 1.000 |

Cumulative Paid Claims ($) as of (months):

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 7,760 | 13,664 | 15,515 | 16,484 |
| 2013 | 8,797 | 13,543 | 16,824 | |
| 2014 | 7,821 | 13,928 | | |
| 2015 | 9,113 | | | |

| Accident Year | Parameter ("a";"b") for Two-Point Exponential Fit as of 12 months | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | | (1,069 ; 0.00060) | (16 ; 0.00159) | (22 ; 0.00151) |
| 2013 | | (2,080 ; 0.00043) | (19 ; 0.00149) | |
| 2014 | | (1,187 ; 0.00056) | | |

- The relationship between the cumulative number of closed claims ("X") and cumulative paid claims ("Y") is: $Y = ae^{bX}$.
- The adjusted paid claims for calendar year 2015 are the same as the unadjusted paid claims.
- There is no development after 48 months.
- An all-year volume weighted average is used to calculate claim development factors.

Calculate ultimate claims for accident year 2015 using the Berquist-Sherman paid claim development adjustment.

### Explanation
**Step 1 — adjust the closed claim counts to the selected disposal rates.** Each cell is the selected disposal rate for that age times the accident year's estimated ultimate claim count, e.g. $0.8 \times 4{,}380 = 3{,}504$ and $0.8 \times 4{,}596 = 3{,}677$.

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 3,504 | 4,292 | 4,336 | 4,380 |
| 2013 | 3,677 | 4,504 | 4,550 | |
| 2014 | 3,563 | 4,365 | | |
| 2015 | 3,607 | | | |

**Step 2 — restate paid claims at those counts** with the fitted $Y = ae^{bX}$. The latest diagonal is left unadjusted; age 12 uses the parameters of age 24 and age 24 those of age 36 (interpolation), while age 36 uses its own (extrapolation). For example:

$$8{,}751 = 1{,}069\,e^{0.00060(3{,}504)}, \qquad 15{,}785 = 16\,e^{0.00159(4{,}336)}$$

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 8,751 | 14,719 | 15,785 | 16,484 |
| 2013 | 10,110 | 15,606 | 16,824 | |
| 2014 | 8,730 | 13,928 | | |
| 2015 | 9,113 | | | |

**Step 3 — develop the adjusted triangle** with all-year volume-weighted factors:

| | 12-24 | 24-36 | 36-48 | 48-ult |
|---|---|---|---|---|
| Age-to-age | 1.604 | 1.075 | 1.044 | 1.000 |
| Age-to-ultimate | 1.800 | 1.122 | 1.044 | 1.000 |

$$\text{AY 2015 ultimate} = 9{,}113 \times 1.800 = 16{,}403$$
