Given the following auto liability claims information:

| Claim # | Case Incurred Indemnity (\$) | Case Incurred ALAE (\$) |
|---|---|---|
| 1 | 800 | 100 |
| 2 | 5,000 | 250 |
| 3 | 2,100 | 0 |
| 4 | 12,000 | 1,800 |
| 5 | 77,000 | 4,000 |

## Part a (1 point)

Calculate the Pearson's correlation coefficient.

### Explanation
Let $X$ be the case incurred indemnity and $Y$ the ALAE.

$$E(X) = \tfrac{1}{5}(800 + 5{,}000 + 2{,}100 + 12{,}000 + 77{,}000) = 19{,}380$$

$$E(X^2) = \tfrac{1}{5}(800^2 + 5{,}000^2 + 2{,}100^2 + 12{,}000^2 + 77{,}000^2) = 1{,}220{,}610{,}000$$

$$E(Y) = \tfrac{1}{5}(100 + 250 + 0 + 1{,}800 + 4{,}000) = 1{,}230, \qquad E(Y^2) = 3{,}802{,}500$$

$$E(XY) = \tfrac{1}{5}\left[800(100) + 5{,}000(250) + 2{,}100(0) + 12{,}000(1{,}800) + 77{,}000(4{,}000)\right] = 66{,}186{,}000$$

$$\sigma_X = \left[E(X^2) - E(X)^2\right]^{1/2} = 29{,}069.32404, \qquad \sigma_Y = \left[E(Y^2) - E(Y)^2\right]^{1/2} = 1{,}532.840501$$

$$\rho = \frac{E(XY) - E(X)E(Y)}{\sigma_X \sigma_Y} = \frac{66{,}186{,}000 - (19{,}380)(1{,}230)}{(29{,}069.32404)(1{,}532.840501)} = 0.950402$$

## Part b (1.25 points)

Using a dependency measure other than Pearson's correlation coefficient, draw a conclusion with respect to the appropriateness of using Pearson's correlation coefficient for this set of claims information.

### Explanation
Use Kendall's tau. Rank the claims by indemnity:

| Indemnity | ALAE |
|---|---|
| 800 | 100 |
| 2,100 | 0 |
| 5,000 | 250 |
| 12,000 | 1,800 |
| 77,000 | 4,000 |

The ALAE column needs one swap to be in order (0 and 100), so $Q = 1$. With $n(n-1)/2 = 5(4)/2 = 10$ pairs:

$$\tau = 1 - \frac{Q}{\#\text{ pairs}/2} = 1 - \frac{1}{10/2} = 0.8$$

The case incurred indemnity is positively correlated with the ALAE: both Pearson's $\rho$ and Kendall's $\tau$ are high (close to 1), so they tell the same story.

Alternatively:

Use Spearman's $\rho = 1 - \dfrac{6s}{n(n^2 - 1)}$, where $s$ is the sum of squared differences in ranks:

| Claim | Indemnity | ALAE | Indemnity rank | ALAE rank | (difference)² |
|---|---|---|---|---|---|
| 1 | 800 | 100 | 1 | 2 | 1 |
| 2 | 5,000 | 250 | 3 | 3 | 0 |
| 3 | 2,100 | 0 | 2 | 1 | 1 |
| 4 | 12,000 | 1,800 | 4 | 4 | 0 |
| 5 | 77,000 | 4,000 | 5 | 5 | 0 |
| Total | | | | | 2 |

$$\rho_S = 1 - \frac{6(2)}{5(25 - 1)} = 0.9$$

Pearson's appears appropriate, since it is similar to Spearman's. One of Pearson's weaknesses is that it is severely affected by outliers, but the entire distribution appears correlated, so that is not a problem here.

## Part c (0.5 points)

Identify one similarity and one difference between Pearson's correlation coefficient and the dependency measure in b. above.

### Explanation
Similarity: Both summarize the overall dependency in one single number.

Difference: Pearson's correlation uses value in determining correlation whereas Kendall's τ uses ranks in determining correlation.

Alternatively:

Similarity: both weight by the squares of the differences

Different: Spearman is an ordinal measure of correlation where as Pearson is a cardinal measure

### Examiner Report
Candidate can calculate either Kendall's Tau (0.80) or Spearman's (0.90) rank correlation.  Both give results similar to Pearson, that is, strong positive correlation.  Candidates should conclude that Pearson's correlation is appropriate in this case.  We also give credit if they say that Pearson's may be appropriate, but the 77K outlier is driving up the correlation since it's not truly linear.  Basically any reasonable conclusion based on assumptions is valid for full credit. If candidate's comment was a correct conclusion based on incorrect calculation, we will give full credit for the comment.
