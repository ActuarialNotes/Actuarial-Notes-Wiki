You are given the following information regarding an insurance company.

| Item | Value |
|---|---|
| Written Premium | \$200 million |
| Loss | \$150 million |
| Expense | \$50 million |
| Surplus | \$75 million |
| Target return on surplus | 15% |
| Client Retention | 90% |
| Risk-free interest rate | 5% |

Assume premium is collected and expenses are paid at the beginning of the year, and losses are paid at the end of the year.

Calculate the total economic value of the firm.

### Explanation
- $TEV = C + F$
- $C = P - E + S$ (as printed)
- $= 200 - 50 + 75 - 150/1.05$
- $= 82.14$ Mil
- $F = \left(P - E - L/(1 + y)\right)\frac{d}{1 - d}$; $d = c_r/(1 + y) = .9/1.05$; $1 - d = 0.15/1.05$
- $= (200 - 50 - 150/1.05)\frac{.9}{15}$ (as printed)
- $= 42.86$ Mil

testing P: $p = \frac{5(15\% - 5\%) + 1}{1.05} + E = 200$ Mil (as printed)

TEV = 42.86 mil + 82.14 Mil = 124.997 mil ≈ 125 mil

Alternatively:

TEV = CEV + FV

- Using formulae from Panning Paper:
  - $CEV = S + \frac{(k - y)S}{1 + y} = 82.14$

    $FV = \frac{(k - y)S}{1 + y} \times \frac{c_r}{1 + y - c_r} = 42.86$

    TEV = 82.14 + 42.86 = 125.0

    (assuming) $P - E - C/(1 + 4) = \frac{(k - y)S}{1 + y}$ (as printed)

Panning formula can be used to calculate the franchise value.

$$F = \frac{c \cdot s\,(a + by)}{(1 + y)(1 + y - c_r)}$$

Cr = Reflection rate = 90X (as printed). Here the pricing does not depend on the...........rate so b = 0, a = 15%

$$= \frac{(.9)(75)(.15 - .05)}{(1.05)(1.05 - .9)} = \$42.857\text{ M}$$

(the formula as printed; its numerator is evaluated as $.15 - .05$).

Current value $= S + P - E - \frac{L}{1 + y}$

$= 75 + 200 - 50 - \frac{150}{1.05}$

$= \$82.14 = (75 + 7.14)$

Total value = \$42.857 + 82.14

Sum of Franchise and current economic value = 125 Mil

### Examiner Report
Of the responses that lost credit, there were two that were by far the most common:

1. The first was incorrectly using the firm's target rate of return in place of the risk free rate.  Most often, candidates just made this error when calculating the 'd', however, others did make the incorrect substitution in the Current Economic Value section as well.
2. The second common error was an incorrect formula for the Current Economic Value, either by omitting the surplus, omitting the first year of profits, or by adding in an additional investment income term that should not appear.

A few candidates used algebraic manipulations to make the formulas easier to memorize, and there were errors in the algebra causing them to lose points.  Several candidates recalculated the premium, in some cases incorrectly, despite the value being given in the problem. The remaining errors were primarily calculation errors or substitution errors (using the value of surplus for losses, for example).
