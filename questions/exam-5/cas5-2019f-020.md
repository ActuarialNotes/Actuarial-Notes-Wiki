## Part a (2.25 points)

Use the frequency-severity disposal rate technique to estimate unpaid claims for accident year 2018.

### Answer
Approximately \$765,000

### Explanation
The disposal rate technique projects the *number* of claims that will close in each future period and the *average severity* at which they will close, then multiplies the two.

**Step 1 — disposal rates.** The disposal rate is closed claim counts divided by **ultimate** claim counts:

| AY | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 0.476 | 0.858 | 0.992 | 1.000 |
| 2016 | 0.521 | 0.824 | 0.993 | |
| 2017 | 0.523 | 0.841 | | |
| 2018 | 0.506 | | | |
| **Selected** | | **0.841** | **0.992** | **1.000** |

**Step 2 — allocate accident year 2018's remaining claims across future periods.** AY2018 has closed 402 of an ultimate 795, so 393 remain open. Those 393 are spread over the remaining disposal-rate increments, rescaled by the proportion still to be disposed of $(1 - 0.506)$:

$$n_j = \frac{d_j - d_{j-1}}{1 - 0.506} \times 393$$

| Period | Calculation | Incremental counts |
|---|---|---|
| 24 | $\dfrac{0.841 - 0.506}{1 - 0.506} \times 393$ | 266.6 |
| 36 | $\dfrac{0.992 - 0.841}{1 - 0.506} \times 393$ | 120.0 |
| 48 | $\dfrac{1.000 - 0.992}{1 - 0.506} \times 393$ | 6.4 |

These sum to 393, as they must.

**Step 3 — incremental paid severity.** Difference both triangles, then divide **incremental** paid claims by **incremental** closed counts — not incremental dollars over cumulative counts:

| Incremental Paid (\$000s) | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 375 | 370 | 161 | 10 |
| 2016 | 397 | 353 | 172 | |
| 2017 | 422 | 340 | | |
| 2018 | 385 | | | |

| Incremental Closed Counts | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 308 | 247 | 87 | 5 |
| 2016 | 356 | 207 | 115 | |
| 2017 | 358 | 217 | | |
| 2018 | 402 | | | |

| Incremental Severity (\$000s) | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 1.218 | 1.498 | 1.851 | 2.000 |
| 2016 | 1.115 | 1.705 | 1.496 | |
| 2017 | 1.179 | 1.567 | | |
| 2018 | 0.958 | | | |
| **Selected** | | **1.590** | **1.673** | **2.000** |

There is no severity trend, so the column averages are used as they stand.

**Step 4 — unpaid claims, with the court decision.** The decision takes effect December 31, 2018, so it affects **all** of accident year 2018's future payments — the entire unpaid amount is loaded by 20%:

$$\text{Unpaid} = 1.20 \times \left[1.590(266.6) + 1.673(120.0) + 2.000(6.4)\right]$$

$$= 1.20 \times \left[423.9 + 200.8 + 12.7\right] = 1.20 \times 637.4 = \$765 \text{ thousand}$$

### Examiner Report
Candidates were expected to apply the frequency-severity disposal rate technique and know how to adjust the data to deal with a sudden increase in severity due to a change in the legal environment.

Candidates were expected to calculate unpaid for a single accident year using the frequency-severity disposal rate technique and correctly increase this number by 20% to account for the tort change.

Common mistakes included:

- Not allocating the accident year 2018 claim counts by year.
- Using the paid development technique.
- Incorrectly calculating severity, either by calculating a cumulative-to-date severity or using an incremental loss dollar amount divided by a cumulative or ultimate count.
- Attempting to calculate one unpaid frequency value and one unpaid severity factor.
- Neglecting to add the tort factor or applying it incorrectly.

## Part b (0.5 points)

Describe an advantage of using the frequency severity technique over a paid development technique in part a. above.

### Explanation
**The frequency-severity technique allows the court decision to be reflected explicitly.** Because it separates the estimate into a claim count component and a severity component, the 20% increase in future payments can be applied directly to the severities of the claims still to be settled — which is exactly where the change bites. A paid development technique offers no such lever: its link ratios are derived entirely from historical payment patterns that pre-date the decision, so a change in the legal environment on December 31, 2018 cannot be reflected without distorting the factors themselves.

More generally, splitting frequency from severity gives greater insight into what is driving the estimate and lets the actuary vary assumptions about settlement speed and severity independently — for example if disposal rates were speeding up or slowing down.

### Examiner Report
Candidates were expected to successfully describe one advantage of the frequency-severity method over the paid development method.

Other common mistakes included:

- Mentioning case reserve adequacy, despite neither the disposal rate frequency-severity technique nor the paid development technique using case reserves
- An incomplete answer that identified a difference between the methods but didn't describe why the frequency severity technique was advantageous
- Providing "advantages" that are true for both methods or not always true for either method.
