Given the following information:

- The variance-covariance matrix:

| | Stock A | Stock B | Market Portfolio |
|---|---|---|---|
| Stock A | 0.16 | | |
| Stock B | -0.48 | 1.44 | |
| Market Portfolio | -0.0108 | 0.252 | 0.09 |

- Stock A and Stock B are perfectly negatively correlated.
- The risk-free rate is 3%.
- The market portfolio has an expected return of 8%.
- Portfolio P consists of:
  - 75% invested in Stock A.
  - 25% invested in Stock B.

## Part a (1.5 points)

Using CAPM, calculate the expected return of Portfolio P.

### Explanation
$$\beta_A = \frac{\text{Cov}(r_A, r_M)}{\sigma_M^2} = \frac{-0.0108}{0.09} = -0.12$$

$$\beta_B = \frac{\text{Cov}(r_B, r_M)}{\sigma_M^2} = \frac{0.252}{0.09} = 2.8$$

$$E(r_A) = r_f + \beta_A(r_M - r_f) = 0.03 + (-0.12)(0.08 - 0.03) = 0.024$$

$$E(r_B) = r_f + \beta_B(r_M - r_f) = 0.03 + 2.8(0.08 - 0.03) = 0.17$$

$$E(r_P) = 0.75\,E(r_A) + 0.25\,E(r_B) = 0.75(0.024) + 0.25(0.17) = 0.0605$$

Alternatively:

Weight the betas instead: $\beta_P = 0.75(-0.12) + 0.25(2.8) = 0.61$, so $E(r_P) = 0.03 + 0.61(0.08 - 0.03) = 6.05\%$.

### Examiner Report
In this part, the candidate was expected to calculate the expected return of a portfolio of two assets using CAPM.
In order to obtain full credit, the candidates needed to calculate the beta, and expected returns for both A and B and then weight with the correct portfolio weights in order to calculate the expected return of the portfolio.  Alternatively, the candidate could weigh the betas for A and B to calculate the beta of the portfolio and then calculate the expected return of the portfolio.
Common mistakes included:

- calculating Betas Using Std Dev of Market instead of Variance
- squaring portfolio variance assuming that std dev was provided

## Part b (1.25 points)

Construct an arbitrage strategy using the risk-free rate and some combination of Stock A and Stock B.

### Explanation
A portfolio of 75% Stock A and 25% Stock B has

$$\sigma_P^2 = (0.75)^2(0.16) + (0.25)^2(1.44) + 2(-1)(0.75)(0.25)\sqrt{0.16}\sqrt{1.44} = 0.09 + 0.09 + (-0.18) = 0$$

So a portfolio of 75% Stock A and 25% Stock B has zero variance, but as part a showed, its expected return is 6.05%, which is greater than the risk-free rate. For arbitrage, borrow at the risk-free rate and purchase a portfolio of 75% Stock A and 25% Stock B, to make a risk-free profit with no net investment up front.

Alternatively:

Since A and B are negatively correlated, a combination with zero variance exists. For $\rho = -1$:

$$w_A = \frac{\sigma_B^2 + \sigma_A\sigma_B}{\sigma_A^2 + \sigma_B^2 + 2\sigma_A\sigma_B} = \frac{\sigma_B(\sigma_A + \sigma_B)}{(\sigma_A\sigma_B)^2} = \frac{\sigma_B}{\sigma_A\sigma_B} = \frac{\sqrt{1.44}}{\sqrt{0.16} + \sqrt{1.44}} = \frac{1.2}{0.4 + 1.2} = 0.75$$

(the two middle denominators as printed), and $w_B = 1 - 0.75 = 0.25$. Check: $\sigma^2 = 0.75^2(0.16) + 0.25^2(1.44) + 2(-1)\sqrt{0.16}\sqrt{1.44}(0.75)(0.25) = 0$.

Since $\sigma = 0$, the return calculated in part a is "risk-free":

- Borrow at the risk-free rate.
- Use the borrowed money to purchase the portfolio from part a, with 75% in A and 25% in B (Portfolio P).
- Use the proceeds from Portfolio P to pay back the loan and still have $6.05\% - 3\% = 3.05\%$ of risk-free return.

### Examiner Report
In this part, candidates were expected to construct a portfolio with zero variance, and explain how to exploit an arbitrage opportunity using the zero-variance portfolio and a risk-free security.
In order to obtain full credit, candidates needed to calculate the weights of A and B that would result in a zero variance portfolio and, using these weights, calculate the expected return on such a portfolio.  Candidates then needed to recognize that an arbitrage opportunity existed between the zero-variance portfolio and the risk free security, and outline an investment strategy with no up-front costs that borrowed at the lower risk free rate and invested the proceeds in the zero variance portfolio (which had a higher return).
Overall, most candidates had difficulty obtaining full credit on Part b.  The majority of candidates seemed to understand the concept of an arbitrage strategy, but struggled to identify the arbitrage opportunity that existed within the problem.
Common mistakes included:

- explaining an arbitrage exploitation strategy that had up-front costs
- assuming a 50-50 weighting of A and B for the zero variance portfolio
- constructing a portfolio of A & B with a beta of 0 and outlining an arbitrage strategy between this portfolio and the risk-free security (these portfolios have the same return, so no arbitrage opportunity exists)
- constructing a portfolio of A & B with beta of 1 and outlining an arbitrage strategy between this portfolio and the market portfolio (these portfolios have the same return, so no arbitrage opportunity exists
