Suppose we want to model the standard deviation $\sigma_i$ of a Gaussian distribution for each observation such that it is a function of a predictor variable $x_i$:

$$
\begin{align*}
y_i &\sim \text{Normal}(\mu, \sigma_i^2) \\
\mu &\sim \text{Normal}(0, 25) \\
g(\sigma_i) &= \alpha + \beta x_i \\
\alpha &\sim \text{Uniform}(-5, 5) \\
\beta &\sim \text{Normal}(0, 2)
\end{align*}
$$

where $g$ is a link function.

Three candidates for $g$ are considered:

I. $g(z) = \log(z)$
II. $g(z) = (z-1)^{\frac{1}{\tau}}$, where $\tau = 2$
III. $g(z) = e^{z}$

Determine which of the candidate link functions would be appropriate for this model.

- A) None
- B) I and II only
- C) I and III only
- D) II and III only
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

The constraint is that $\sigma_i$ is a standard deviation, so it must be **strictly positive for every value the linear predictor can take**. Since $\alpha \in (-5,5)$ and $\beta$ is normal, $\eta = \alpha + \beta x_i$ ranges over the whole real line. Invert each candidate and check.

**I — $g(z) = \log(z)$.** Then

$$
\sigma_i = e^{\eta} > 0 \quad \text{for every real } \eta.
$$

Appropriate — this is the standard log link for a positive parameter.

**II — $g(z) = (z-1)^{1/2}$.** Then

$$
\sigma_i = \eta^2 + 1 \geq 1 > 0 \quad \text{for every real } \eta.
$$

Appropriate — the square guarantees positivity, and the $+1$ keeps it away from zero.

**III — $g(z) = e^{z}$.** Then

$$
\sigma_i = \ln(\eta),
$$

which is undefined for $\eta \leq 0$ and negative for $0 < \eta < 1$. Since $\eta$ can freely take those values, this link produces invalid standard deviations. Not appropriate.

Candidates I and II only, so the answer is **B**.

*Note: the CAS answer key accepted both **B** and **E** for this question. Candidate II restricts $\sigma_i$ to be at least 1 — the link is undefined for $0 < \sigma_i < 1$ — so a candidate who rejected II on those grounds would conclude "I only", which is not among options (A) to (D) and leads to (E).*
