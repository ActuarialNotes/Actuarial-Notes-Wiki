Given the following information:

- The projected calendar year loss reserve payout as of December 31, 2012 is:

| Accident Year | Calendar Year Payments (\$000,000): 2013 | Calendar Year Payments (\$000,000): 2014 |
|---|---|---|
| 2012 | \$10 | \$10 |
| 2011 | \$10 | |

- Losses are paid at the end of each year.
- Liabilities are discounted using the bond yield curve rates.
- The asset portfolio is composed of:

| Asset | Market Value (\$000,000) |
|---|---|
| Cash | \$25 |
| Bonds | \$75 |

- The duration of cash is zero.
- The bond portfolio is composed of an equal investment in the following bonds:

| Time to Maturity (Years) | Coupon Rate | Face Value | Bond Price |
|---|---|---|---|
| 1 | 5% | \$1,000 | \$1,020 |
| 2 | 6% | \$1,000 | \$1,040 |

- Bond coupons are paid annually.

Calculate the duration gap of the market value surplus for the insurer as of December 31, 2012.

### Explanation
$$DG_S = \frac{MVA \times D_A - MVL \times D_L}{MVS}$$

Finding Duration of bonds portfolio

$$P = \frac{\sum PV(CF_t) \times t}{\sum PV(CF_t)} = \frac{304.754}{2060} = 1.4766 \text{ (304.754 as printed)}$$

$\sum PV(CF_t) = 1020 + 1040 + 2060$ (as printed)

$$\sum PV(CF_t) \times 6 = \frac{1050 + 60}{1.0294} + \frac{1060 \times 2}{1.0391^2} = 3041.754 \text{ (}\times 6\text{ as printed)}$$

$$1020 = \frac{1050}{1 + r_1} \Rightarrow r_1 = .0294$$

$$1040 = \frac{60}{1 + r_1} + \frac{1060}{(1 + r_2)^2}$$

$(1 + r_2)^2 = 1.07974$; $r_2 = .0391$

MVA = 100M; $D_{mva} = (.75)(1.4766) + (.25)(0) = 1.10745$

Loss Payments: 2013/20, 2014/10

$$Duration_L = \frac{\sum PV(CF_t) \times t}{\sum PV(CF_t)} = \frac{37.952}{28.69} = 1.323$$

$$\Sigma(CF_t) = \frac{20}{1.0294} + \frac{10}{1.0391^2} = 28.69$$

$$\Sigma(CF_t) \times t = \frac{20}{1.0294} + \frac{10 \times 2}{1.0391^2} = 37.952$$

$D_L = 1.323$; MVL = 28.69M

$$DG_S = \frac{100(1.17045) - 28.69(1.323)}{100 - 28.69} = 1.0207$$

(the asset duration 1.17045 is as printed).

Alternatively:

$$\frac{1050}{1 + r_1} = 1020 \qquad r_1 = 2.94\%$$

$$\frac{60}{1.0294} + \frac{1060}{(1 + r_2)^2} = 1040 \qquad \frac{1060}{(1 + r_2)^2} = 981.71 \qquad r_2 = 3.91\%$$

Bonds

$$\text{Duration} = \frac{3041.76}{2060.03} = 1.4766$$

(the bond duration 1.4776 is as printed).

Mv surplus = 100M - 28,690,378 = 71,309,622

$$\text{Dur MVs} = \frac{1.1705(100M) - 1.3228(28{,}690{,}378)}{71{,}309{,}622}$$

(the asset duration 1.1705 is as printed).

Dur = 1.0209

Dur Gap = 1.0209 - 0 = 1.0209

Alternatively:

Spot Rates

$$1020 = \frac{1050}{1 + S_1} \Rightarrow S_1 = 2.94\%$$

$$1040 = \frac{60 \times 1020}{1050} + \frac{1060}{(1 + S_2)^2} \Rightarrow S_2 = 3.91\%$$

$$PV(L_{2012}) = \frac{10}{1.0294} + \frac{10}{(1.0351)^2} = 18.98 \text{ (1.0351 as printed)}$$

$$PV(L_{2011}) = \frac{10}{1.0294} = 9.71$$

$$D_{2012} = \frac{1}{PV(L_{2012})} \times \left(1 \times \frac{10}{1.0294} + 2 \times \frac{10}{(1.0391)^2}\right) = \frac{28.24}{18.98} = 1.49$$

$$D_{2011} = \frac{1}{PV(L_{2011})} \times \frac{10}{1.0294} = 1$$

$$D_{MVL} = \frac{18.88 \times 1.49 \times 9.71 \times 1}{18.98 + 9.71} = 1.32 \text{ (as printed)}$$

MVL = 18.98 + 9.71 = 28.69

Duration of Bonds

$D_{B1} = 1$

$$D_{B2} = \frac{1}{1040}\left(\frac{60}{1.0294} + \frac{2 \times 1060}{(1.0391)^2}\right) = 1.94$$

$$D_B = \frac{1020 \times 1 + 1040 \times 1.94}{1020 + 1040} = 1.47$$

$$D_{MVA} = \frac{0 \times 25 + 1.47 \times 75}{100} = 1.10$$

Duration Surplus

$$D_{MVS} = \frac{MVA \times D_{mva} - MVL\,D_{MVL}}{MVA - MVL} = \frac{100 \times 1.1 - 28.69 \times 1.32}{100 - 28.69} = \frac{72.13}{71.31} = 1.01$$

Duration Gap MVS $= D_{MVS} = 1.01$

$r_2$, 2) $1040 = 60(1 + r_1)^{-1} + 1060(1 + r_2)^{-2}$ — $i_2 = 3.91\%$
