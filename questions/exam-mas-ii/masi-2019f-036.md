You are given the following three statements regarding shrinkage methods in linear regression:

- I. As tuning parameter, $\lambda$, increases towards $\infty$, the penalty term has no effect and a ridge regression will result in the unconstrained estimates.
- II. For a given dataset, the number of variables in a lasso regression model will always be greater than or equal to the number of variables in a ridge regression model.
- III. The issue of selecting a tuning parameter for a ridge regression can be addressed with cross-validation.

Determine which of the above statements are true.

- A) I only
- B) II only
- C) III only
- D) I, II and III
- E) The answer is not given by (A), (B), (C) or (D)

## Explanation

Ridge regression minimizes $\text{RSS} + \lambda\sum_{j=1}^{p}\beta_j^2$ and lasso minimizes $\text{RSS} + \lambda\sum_{j=1}^{p}\lvert\beta_j\rvert$.

**I is false.** It reverses the two ends. At $\lambda = 0$ the penalty vanishes and ridge returns the unconstrained least-squares estimates. As $\lambda \to \infty$ the penalty dominates and every slope coefficient is shrunk toward zero.

**II is false.** Ridge shrinks coefficients but never sets any exactly to zero, so a ridge model keeps all $p$ variables. The lasso's absolute-value penalty can set coefficients exactly to zero, so a lasso model has *at most* $p$ variables: fewer than or equal to ridge, not greater than or equal.

**III is true.** The standard way to choose $\lambda$ is to compute the cross-validation error over a grid of values and pick the $\lambda$ with the smallest error.

Only statement III, so the answer is **C**.
