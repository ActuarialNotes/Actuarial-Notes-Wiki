| Reported Claims (\$000) — Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|

|---|---|---|---|---|
| 2015 | 108 | 115 | 115 | 115 |
| 2016 | 112 | 120 | 120 | |
| 2017 | 104 | 110 | | |
| 2018 | 106 | | | |

| Paid Claims (\$000) — Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 560 | 1,325 | 1,650 | 1,680 |
| 2016 | 650 | 1,350 | 1,720 | |
| 2017 | 615 | 1,305 | | |
| 2018 | 625 | | | |

| Closed Claim Counts — Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|

| Value | Item |
|---|---|
| 5.0% | Annual severity trend |

- Exposures have remained constant throughout all accident years.

Calculate unpaid claims for accident year 2018 using the reported Berquist-Sherman technique.

### Answer
Approximately \$1,009 thousand

### Explanation
The reported Berquist-Sherman technique corrects a reported triangle distorted by a **change in case reserve adequacy**. It restates every historical average case outstanding as though it had been set at the *current* level of adequacy, by de-trending the latest diagonal back through the triangle at the severity trend rate.

**Step 1 — case outstanding and open counts.** Both come from differencing the given triangles:

| Case O/S (\$000) | 12 | 24 | 36 | 48 | | Open Counts | 12 | 24 | 36 | 48 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2015 | 540 | 325 | 25 | 0 | | 2015 | 30 | 9 | 1 | 0 |
| 2016 | 600 | 330 | 30 | | | 2016 | 32 | 9 | 2 | |
| 2017 | 585 | 495 | | | | 2017 | 29 | 11 | | |
| 2018 | 875 | | | | | 2018 | 24 | | | |

**Step 2 — average case outstanding** (\$000 per open claim). The diagnostic that motivates the adjustment is visible here: at 12 months the average has climbed from 18.0 to 36.5, and at 24 months from 36.1 to 45.0 — case reserves have been strengthened substantially.

| Avg Case O/S | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | 18.0 | 36.1 | 25.0 | — |
| 2016 | 18.8 | 36.7 | 15.0 | |
| 2017 | 20.2 | 45.0 | | |
| 2018 | 36.5 | | | |

(AY2015 at 48 months has no open claims, so its average is undefined and contributes nothing.)

**Step 3 — de-trend the latest diagonal back through each column** at 5% per year. Each column is rebuilt from its most recent value, which represents current reserving adequacy:

$$\text{De-trended}_{y,j} = \frac{\text{Avg Case O/S at the latest diagonal in column } j}{1.05^{\,(\text{diagonal year}) - y}}$$

| De-trended Avg Case O/S | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2015 | $36.5/1.05^3 = 31.5$ | $45.0/1.05^2 = 40.8$ | $15.0/1.05 = 14.3$ | 0.0 |
| 2016 | $36.5/1.05^2 = 33.1$ | $45.0/1.05 = 42.9$ | 15.0 | |
| 2017 | $36.5/1.05 = 34.7$ | 45.0 | | |
| 2018 | 36.5 | | | |

**Step 4 — rebuild the reported triangle.** Multiply the de-trended averages back by the open counts to get adjusted case outstanding, then add the (unadjusted) paid claims:

| Adjusted Case O/S | 12 | 24 | 36 | 48 | | Adjusted Reported | 12 | 24 | 36 | 48 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2015 | 945 | 367 | 14 | 0 | | 2015 | 1,504.8 | 1,692.3 | 1,664.3 | 1,680.0 |
| 2016 | 1,058 | 386 | 30 | | | 2016 | 1,708.2 | 1,735.7 | 1,750.0 | |
| 2017 | 1,007 | 495 | | | | 2017 | 1,621.9 | 1,800.0 | | |
| 2018 | 875 | | | | | 2018 | 1,500.0 | | | |

The latest diagonal is unchanged, as it must be — it already reflects current adequacy.

**Step 5 — develop the adjusted triangle.** Age-to-age factors from the adjusted reported claims, straight average:

| Age | Factors | Selected |
|---|---|---|
| 12–24 | $1.1246$, $1.0160$, $1.1098$ | $1.084$ |
| 24–36 | $0.9835$, $1.0082$ | $0.996$ |
| 36–48 | $1.0094$ | $1.009$ |

$$CDF_{12-\text{ult}} = 1.084 \times 0.996 \times 1.009 = 1.089$$

**Step 6 — unpaid claims.** Develop, then subtract what has already been paid:

$$\text{Ultimate}_{2018} = 1{,}500 \times 1.089 = \$1{,}633.7 \text{ thousand}$$

$$\text{Unpaid}_{2018} = 1{,}633.7 - 625 = \$1{,}008.7 \text{ thousand}$$

Using volume-weighted rather than straight averages gives $CDF_{12-\text{ult}} = 1.087$, an ultimate of \$1,630.7 thousand and unpaid of **\$1,005.7 thousand** — both selections were accepted.

### Examiner Report
Candidates were expected to know the steps required to adjust the average case outstanding triangle under the reported Berquist-Sherman technique, and to calculate an unpaid estimate from the reported triangle after adjusting it for the change in case outstanding adequacy. Full triangles were not required so long as the candidate demonstrated how to de-trend the average case outstanding triangle and build an adjusted reported triangle from the results.

Common mistakes included calculating the estimated ultimate but not subtracting the 2018 paid amount to reach an unpaid estimate, and arithmetic errors in constructing the adjusted reported triangle after de-trending.
