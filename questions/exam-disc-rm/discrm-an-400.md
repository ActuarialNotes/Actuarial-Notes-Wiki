A drywall contractor applies for workers compensation. It reports \$50,000 of payroll for its wallboard installers and \$75,000 for a clerical office manager and two clerks, who work in an office walled off from the job sites. Which is the governing classification?

- A) The clerical office classification (Code 8810), because it has the most payroll
- B) The wallboard installation classification, because a standard exception cannot govern while a basic classification applies
- C) The clerical office classification, because the office is physically separated from the operating hazards
- D) Whichever classification carries the higher rate, because the governing class is the highest-rated one

## Explanation

Under NCCI's Basic Manual the governing classification is the **basic** classification with the most payroll. Clerical office employees (Code 8810) are a **standard exception** class, so they are rated separately but never govern when a basic classification applies. The wallboard classification is the only basic class, so it governs even though the clerical payroll is larger. The answer is **B**.

**Why not the others**

- **A** — Most payroll decides among basic classifications only; it doesn't let a standard exception govern.
- **C** — Physical separation is what qualifies the office staff for Code 8810, but qualifying for a standard exception doesn't make it the governing class.
- **D** — The highest-rated basic class governs only when several basic classes apply and none has payroll assigned; it isn't the general rule.
