An actuary is comparing five models for a loss-related random variable. Put them in order from **smallest** variance to **largest**. Enter the letters with no spaces, e.g. ABCDE.

- (A) A Poisson claim count with mean 3.9
- (B) A claim size uniformly distributed on the interval $(0, 7)$
- (C) An exponential claim size with mean 1.9
- (D) The number of claims among 16 independent policies, each with claim probability 0.25
- (E) The number of independent policies examined up to and including the first one with a claim, when each has claim probability 0.4

## Explanation

Compute each variance:

$$
\begin{aligned}
\text{(A) Poisson: } & \lambda = 3.90 \\
\text{(B) Uniform: } & \frac{(b-a)^2}{12} = \frac{49}{12} = 4.083 \\
\text{(C) Exponential: } & \theta^2 = 1.9^2 = 3.61 \\
\text{(D) Binomial: } & np(1-p) = 16(0.25)(0.75) = 3.00 \\
\text{(E) Geometric: } & \frac{1-p}{p^2} = \frac{0.6}{0.16} = 3.75
\end{aligned}
$$

From smallest to largest: $\operatorname{Var}(D) = 3.00 < 3.61 < 3.75 < 3.90 < 4.083$, so the order is **DCEAB**.

**Common wrong entries**

- **CDEAB** — taking the exponential's variance to be its mean, 1.9. That is the Poisson's property (variance = mean); an exponential's variance is the *square* of its mean, $\theta^2 = 3.61$.
- **CEADB** — using the binomial mean $np = 4.0$ as its variance, forgetting the factor $(1-p)$, which moves D from first to fourth.
- **DCABE** — using $\frac{1}{p^2} = 6.25$ for the geometric instead of $(1-p)/p^2$. The geometric variance is $(1-p)/p^2$ whether it counts trials or failures: the two versions differ by the constant 1, which shifts the mean but not the variance.
- **EDCAB** — using the geometric mean $\frac{1}{p} = 2.5$ in place of its variance.

Using $(b-a)^2/4 = 12.25$ for the uniform leaves B last, so that slip does not change the entry here — but it is still the wrong variance.
