Given the following information:

| Accident Year | Incremental Paid Loss 0-12 (\$000) | Incremental Paid Loss 12-24 (\$000) | Incremental Paid Loss 24-36 (\$000) | Premium (\$000) |
|---|---|---|---|---|
| 2010 | 1,400 | 650 | 280 | 3,600 |
| 2011 | 1,000 | 850 | | 3,700 |
| 2012 | 1,500 | | | 3,650 |
| Total | 3,900 | 1,500 | 280 | 10,950 |

Assume that there is no further development beyond 36 months.

## Part a (2 points)

Calculate the individual loss ratio claims reserve $R^{\text{ind}}$ for the total of accident years 2010 through 2012.

### Explanation
$$R^{\text{ind}} \text{ for total (2010-2012)} = \sum \frac{q_i}{p_i} \times C_i$$

Incremental loss ratios by development age, $m_k = \dfrac{\text{sum(loss @ dev age } k)}{\text{sum(Premium)}}$, using only the accident years with losses at that age:

$$m_{0\text{-}12} = \frac{1{,}400 + 1{,}000 + 1{,}500}{3{,}600 + 3{,}700 + 3{,}650} = 0.356$$

$$m_{12\text{-}24} = \frac{650 + 850}{3{,}600 + 3{,}700} = 0.205$$

$$m_{24\text{-}36} = \frac{280}{3{,}600} = 0.078$$

Payout ratios $p_i = \dfrac{\sum m_k \text{ to date}}{\sum m_k}$ and $q_i = 1 - p_i$:

$$p_{2010} = \frac{0.356 + 0.205 + 0.078}{0.356 + 0.205 + 0.078} = 1.000 \qquad q_{2010} = 1 - 1 = 0$$

$$p_{2011} = \frac{0.356 + 0.205}{0.356 + 0.205 + 0.078} = 0.878 \qquad q_{2011} = 1 - 0.878 = 0.122$$

$$p_{2012} = \frac{0.356}{0.356 + 0.205 + 0.078} = 0.557 \qquad q_{2012} = 1 - 0.557 = 0.443$$

Paid losses to date: $C_{2010} = 1{,}400 + 650 + 280 = 2{,}330$, $C_{2011} = 1{,}000 + 850 = 1{,}850$, $C_{2012} = 1{,}500$.

$$R^{\text{ind}}_{2010} = \frac{0}{1} \times 2{,}330 = 0$$

$$R^{\text{ind}}_{2011} = \frac{0.122}{0.878} \times 1{,}850 = 256$$

$$R^{\text{ind}}_{2012} = \frac{0.443}{0.557} \times 1{,}500 = 1{,}193$$

$$R^{\text{ind}}_{\text{Total}} = 0 + 256 + 1{,}193 = 1{,}449$$

## Part b (0.75 points)

Calculate the collective loss ratio claims reserve $R^{\text{coll}}$ for the total of accident years 2010 through 2012.

### Explanation
The burning-cost ultimate $U^{BC}_i$ is the premium times the collective loss ratio $\sum m_k = 0.356 + 0.205 + 0.078$:

$$U^{BC}_i = \text{Premium} \times \text{ELR} = V_i \times \sum m_k$$

$$U^{BC}_{2010} = 3{,}600 \times (0.356 + 0.205 + 0.078) = 2{,}302$$

$$U^{BC}_{2011} = 3{,}700 \times (0.356 + 0.205 + 0.078) = 2{,}366$$

$$U^{BC}_{2012} = 3{,}650 \times (0.356 + 0.205 + 0.078) = 2{,}334$$

$R^{\text{coll}}_i = q_i \times U^{BC}_i$:

$$R^{\text{coll}}_{2010} = 0 \times 2{,}302 = 0$$

$$R^{\text{coll}}_{2011} = 0.122 \times 2{,}366 = 288$$

$$R^{\text{coll}}_{2012} = 0.443 \times 2{,}334 = 1{,}034$$

$$R^{\text{coll}}_{\text{Total}} = 0 + 288 + 1{,}034 = 1{,}322$$

Alternatively:

Each year's reserve is the unemerged part of the 63.9% collective loss ratio times its premium:

$$R^{\text{coll}}_{2010} = (63.9\% - 35.6\% - 20.5\% - 7.8\%) \times 3{,}600 = 0$$

$$R^{\text{coll}}_{2011} = (63.9\% - 35.6\% - 20.5\%) \times 3{,}700 = 288$$

$$R^{\text{coll}}_{2012} = (63.9\% - 35.6\%) \times 3{,}650 = 1{,}034$$

$$R^{\text{coll}}_{\text{Total}} = 1{,}322$$

### Examiner Report
Several candidates used a standard paid loss development method instead of calculating the individual loss ratio claims reserve Rind as requested.  Another common mistake was miscalculating the mk's using the total earned premium for all accident years.  Another common mistake was candidates misidentifying Rind as Rcoll, and vice versa.  Candidates making these mistakes did not receive full credit.
