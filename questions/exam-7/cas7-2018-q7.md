Given the following information:

Cumulative Reported Loss (\$000) as of (months):

| Accident Year | 12 | 24 | 36 | 48 | 60 |
|---|---|---|---|---|---|
| 2012 | 1,300 | 2,350 | 3,500 | 3,650 | 3,750 |
| 2013 | 1,450 | 3,000 | 5,050 | 5,850 | |
| 2014 | 1,600 | 2,500 | 3,700 | | |
| 2015 | 1,750 | 3,050 | | | |
| 2016 | 1,950 | | | | |

Observed Loss Development Factors as of (months):

| Accident Year | 12-24 | 24-36 | 36-48 | 48-60 |
|---|---|---|---|---|
| 2012 | 1.808 | 1.489 | 1.043 | 1.027 |
| 2013 | 2.069 | 1.683 | 1.158 | |
| 2014 | 1.563 | 1.480 | | |
| 2015 | 1.743 | | | |

- There is no development beyond 60 months.

## Part a (0.5 points)

Calculate the ultimate loss for AY 2014 under the assumption that the variance of the next incremental loss is a constant for each development age.

### Explanation
**Sample 1**

$$36-48 = \frac{1.043 \times 3{,}500^2 + 1.158 \times 5{,}050^2}{3{,}500^2 + 5{,}050^2} = 1.121$$

48-Ult = 1.027

2014 Ultimate = 3,700 × 1.121 × 1.027 = 4,260

**Sample 2**

$$LDF\ 36-48 = \frac{3{,}500 \times 3{,}650 + 5{,}050 \times 5{,}850}{3{,}500^2 + 5{,}050^2} = 1.121$$

$$LDF\ 48-60 = \frac{3{,}650 \times 3{,}750}{3{,}650^2} = 1.027$$

LDF 36-Ult = 1.121 × 1.027 = 1.151

Ultimate loss = 3,700 × 1.151 = 4,258.7

**Sample 3**

Use least squares LDF

| | 36-48 | 48-60 |
|---|---|---|
| LDF | 1.121 | 1.027 |
| CDF | 1.151 | 1.027 |

AY 2014 Ultimate = 3,700K × 1.151 = 4,260K

### Examiner Report
Candidates were expected to know which Chain Ladder weighting method corresponded to each of the Mack variance assumptions. They were also expected to know how to test which variance assumption was most appropriate.

Candidates were expected to use Mack's Least Squares methodology to generate LDFs. They were also expected to apply the LDFs to generate ultimate losses.

Common mistakes included:

- Using the Brosius Least Squares method.
- Using the simple average variance assumption.
- Using the wrong AY to calculate LDFs.

## Part b (0.5 points)

Calculate the ultimate loss for AY 2014 under the assumption that the variance of the next incremental loss is proportional to the losses reported to date.

### Explanation
**Sample 1**

$$f_{36-48} = \frac{1.043 \times 3{,}500 + 1.158 \times 5{,}050}{3{,}500 + 5{,}050} = 1.1109$$

AY 2014 Ult = 3,700 × 1.1109 × 1.027 = 4,221.4

**Sample 2**

$$\frac{3{,}650 + 5{,}850}{3{,}500 + 5{,}050} = 1.111$$

3,700 × 1.111 × 1.027 = 4,222

**Sample 3**

Use Volume Weighted LDF

| | 36-48 | 48-60 |
|---|---|---|
| LDF | 1.111 | 1.027 |
| CDF | 1.141 | 1.027 |

AY 2014 Ultimate = 3,700K × 1.141 = 4,222K

### Examiner Report
Candidates were expected to use the volume weighted average methodology to generate LDFs.
They were also expected to apply the LDFs to generate ultimate losses.
Common mistakes included:

- Using an incorrect variance assumption or a different weighting method which wasn't appropriate for the given situation.

## Part c (0.5 points)

Calculate the ultimate loss for AY 2014 under the assumption that the variance of the next incremental loss is proportional to the square of the losses reported to date.

### Explanation
**Sample 1**

$$f_{36-48} = \frac{1.043 + 1.158}{2} = 1.101$$

3,700 × 1.101 × 1.027 = 4,184

**Sample 2**

Use Straight Average LDFs

| | 36-48 | 48-60 |
|---|---|---|
| LDF | 1.101 | 1.027 |
| CDF | 1.131 | 1.027 |

AY 2014 Ultimate = 3,700K × 1.131 = 4,182K

### Examiner Report
Candidates were expected to use the simple average methodology to generate LDFs. They were also expected to apply the LDFs to generate ultimate losses.

Common mistakes included:

- Using the Least Squares variance assumption, since similar to an OLS regression, Least Squares assumes that variance of the next incremental loss is constant (i.e. variance does not change based on the losses reported to date).
- Using square root or 3/2 power to weight.

## Part d (1 point)

Fully describe a test to determine which of the three variance assumptions in parts a., b., and c. above is most reasonable for the data in this triangle. Do not perform any calculations.

### Explanation
To test the variance assumptions, we can plot weighted residuals against $c_{i,k}$

- Plot a: $(c_{i,k+1} - c_{i,k} \times f_{k0})$ against $c_{i,k}$
- Plot b: $(c_{i,k+1} - c_{i,k} \times f_{k1}) / \text{sqrt}(c_{i,k})$ against $c_{i,k}$
- Plot c: $(c_{i,k+1} - c_{i,k} \times f_{k2}) / c_{i,k}$ against $c_{i.k}$ (as printed)

Compare plots a, b, and c for several values of k to see which shows the most random pattern. That one is the most reasonable for the data in the triangle.

Calculate the following residuals:

- Situation a: $r = (c_{i,k+1} - c_{i,k} \times f_{k0})$
- Situation b: $r = (c_{i,k+1} - c_{i,k} \times f_{k1}) / \text{sqrt}(c_{i,k})$
- Situation c: $r = (c_{i,k+1} - c_{i,k} \times f_{k2}) / c_{i,k}$

Plot these r's against previous cumulative losses. If an assumption's r's are random around 0 with no trends or patterns, then that assumption is appropriate. If all three plots are random, choose $f_{k1}$ because the other two are not superior.

### Examiner Report
Candidates were expected to be able to explain Mack's method for testing the proper variance assumption. This appeared to be the challenging part of the question for candidates.
Common mistakes included:

- Describing the linearity test instead.
- Describing a method that did not test the variance assumption (e.g. comparing MSE or adjusted SSE).
- Comparing the values in the triangle for seasonality or outliers.
- Not providing sufficient detail and/or inaccurate detail.
