Given the following information:

![Scatter plot of ultimate loss ratio (y-axis) against incurred loss ratio at 12 months (x-axis, 0.6200 to 0.7000) with a dotted fitted line using least squares. Three points are labelled 0.6282, y2014; 0.6375, y2015; and 0.6941, y2016.](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/cas7-2018-q4-least-squares-fit.png)

- The equation for the line in the graph above is $y = 0.1126 + bx$.
- $\overline{xy} = 0.5979$
- Cumulative incurred loss for accident year 2017 at 12 months is \$6,000,000.
- Earned premium for accident year 2017 is \$8,000,000.
- Assume there is no further development after 24 months.

Calculate the ultimate loss for accident year 2017 using the least squares method.

### Explanation
**Sample 1**

$$\bar{x} = \frac{0.6282 + 0.6375 + 0.6941}{3} = 0.6533$$

$$\bar{x}^2 = 0.4268$$

$$\overline{x^2} = \frac{0.6282^2 + 0.6375^2 + 0.6941^2}{3} = 0.4276$$

$$\bar{y} = 0.1126 + 0.6533b$$

$$b = \frac{\overline{xy} - \bar{x}\bar{y}}{\overline{x^2} - \bar{x}^2} = \frac{0.5979 - 0.6533\bar{y}}{0.4276 - 0.4268}$$

$$b = \frac{0.5979 - 0.6533 \times (0.1126 + 0.6533b)}{0.0008} = 1.2261$$

For AY 2017,

$$y = 0.1126 + 1.2261x = 0.1126 + 1.2261 \times \frac{6{,}000{,}000}{8{,}000{,}000} = 1.0322$$

$$Ultimate = 1.0322 \times 8{,}000{,}000 = 8{,}257{,}600$$

**Sample 2**

$$\overline{X\hat{Y}} = \overline{XY} = 0.5979 = \frac{1}{3} \times (0.6282 \times \hat{Y}_1 + 0.6375 \times \hat{Y}_2 + 0.6941 \times \hat{Y}_3)$$

$$= \frac{1}{3} \times [0.6282 \times (a + 0.6282b) + 0.6375 \times (a + 0.6375b) + 0.6941 \times (a + 0.6941b)]$$

$$= \frac{1}{3} \times (1.9598a + 1.2828b)$$

$$= \frac{1}{3} \times (1.9598 \times 0.1126 + 1.2828b)$$

$$b = 1.2261$$

$$Ult_{2017} = \left(0.1126 + 1.2261 \times \frac{6{,}000{,}000}{8{,}000{,}000}\right) \times 8{,}000{,}000 = 8{,}257{,}600$$

### Examiner Report
Candidates were expected to compute the least square estimate by applying and solving the equations for coefficients a and b.
Common mistakes included:

- Not calculating AY 2017 projected ultimate losses.

- Deriving AY 2017 Projected ultimate loss as a product of AY 2017 projected ultimate loss ratio and AY 2017 incurred loss.
- Estimating Y̅ from the graph
