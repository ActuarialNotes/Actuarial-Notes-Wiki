Two rating classes have the same number of observations, but the risks inside class A differ from one another far more than the risks inside class B. Which class's own experience gets the larger credibility factor?

- A) Class B — more homogeneous data is more stable, so it deserves more weight
- B) Neither — with equal $n$ the two classes get the same $Z$
- C) Class A — a larger variance of hypothetical means makes own experience informative
- D) Class A, but only once $n$ passes the standard for full credibility
