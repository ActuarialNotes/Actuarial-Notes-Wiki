Given the following information:

| Class | Exposures | Current Rate | True Expected Cost | Proposed Rate |
|---|---|---|---|---|
| A | 3,500 | \$500 | \$550 | \$540 |
| B | 8,000 | \$400 | \$350 | \$370 |

- Scenario 1: If the proposed rates are implemented, the projected number of class A exposures will decrease to 3,150; the projected number of class B exposures will remain unchanged.
- Scenario 2: If the proposed rates are not implemented, the projected number of class A exposures will increase to 4,500; the projected number of class B exposures will decrease to 7,000.
- No other expenses are changed in either scenario.
- Profit provision is 0% in the indicated rate.

## Part a (1 points)

Calculate the profit in each of the two scenarios.

### Answer
Scenario 1: \$128,500. Scenario 2: \$125,000.

### Explanation
With a 0% profit provision built into the indicated rate, the true expected cost *is* the break-even rate. Profit is therefore whatever margin the charged rate carries above that cost, on the exposures the company actually ends up writing:

$$\text{Profit} = \sum_{\text{class}} \big(\text{rate charged} - \text{true expected cost}\big) \times \text{projected exposures}$$

The two moving parts are which **rate** is charged and which **exposure** projection applies. Scenario 1 charges the *proposed* rates and gets the exposures that go with them; Scenario 2 keeps the *current* rates and gets the exposures that go with those. The 3,500 / 8,000 exposures in the exhibit are today's, and are not used in either scenario.

**Scenario 1 — proposed rates implemented:**

| Class | Projected exposures | Proposed rate | True expected cost | Margin | Profit |
|---|---|---|---|---|---|
| A | 3,150 | \$540 | \$550 | -\$10 | -\$31,500 |
| B | 8,000 | \$370 | \$350 | +\$20 | \$160,000 |
| **Total** | | | | | **\$128,500** |

$$3{,}150(540 - 550) + 8{,}000(370 - 350) = -31{,}500 + 160{,}000 = \$128{,}500$$

**Scenario 2 — current rates retained:**

| Class | Projected exposures | Current rate | True expected cost | Margin | Profit |
|---|---|---|---|---|---|
| A | 4,500 | \$500 | \$550 | -\$50 | -\$225,000 |
| B | 7,000 | \$400 | \$350 | +\$50 | \$350,000 |
| **Total** | | | | | **\$125,000** |

$$4{,}500(500 - 550) + 7{,}000(400 - 350) = -225{,}000 + 350{,}000 = \$125{,}000$$

The exposure shifts are the mechanism of adverse selection at work. Class A is underpriced under both rate sets, so it grows when the subsidy is largest (Scenario 2, where A pays \$500 against a \$550 cost) and shrinks when the subsidy is trimmed. Class B is overpriced, so it shrinks under the current rates and holds under the proposed ones.

### Examiner Report
Candidates were expected to understand how to calculate the expected profit given premium, expected loss, and exposure information. Candidates were also expected to determine the impact of implementing a proposed rating plan given an implementation cost.

Candidates were expected to calculate profit by class for two scenarios by taking the proper (rate – expected cost) x exposures.

Common errors included:

- Incorrectly stating the formula.
  - The proper formula for Scenario 1 is (proposed rate – true expected cost) x projected exposure. Common errors included using current exposures, current rate, or reversing the proposed rate and true expected cost.
  - The proper formula for Scenario 2 is (current rate – true expected cost) x projected exposure. Common errors included using current exposures, proposed rate, or reversing the current rate and true expected cost.
- Stating the formulas correctly but using the wrong values from the question as inputs.

## Part b (0.5 points)

Explain whether the proposed rates should be implemented given a \$10,000 implementation cost.

### Answer
The proposed rates gain \$3,500 of profit per year against a one-time \$10,000 cost — do not implement on a one-year view; implement if the gain is expected to persist, since it pays back in about three years.

### Explanation
The implementation cost attaches to **Scenario 1 only** — there is nothing to implement in Scenario 2 — so it must be netted against that scenario before the two are compared, not deducted from both.

$$\text{Annual benefit of implementing} = 128{,}500 - 125{,}000 = \$3{,}500$$

$$\text{Scenario 1 net of implementation cost} = 128{,}500 - 10{,}000 = \$118{,}500 \; < \; \$125{,}000$$

**Short-term view.** In the first year the \$10,000 outlay swamps the \$3,500 gain, leaving the company \$6,500 worse off than doing nothing. On that basis the rates should not be implemented.

**Long-term view.** The \$10,000 is a one-time cost while the \$3,500 recurs, so implementing pays for itself in $10{,}000 / 3{,}500 \approx 2.9$ years and is profitable thereafter. If the company expects the improved rate structure to stay in force beyond about three years, it should implement.

There is a further, non-monetary argument for implementing: the proposed rates are closer to the true expected costs, so class B subsidizes class A less. That is the more equitable structure and it slows the adverse selection visible in the Scenario 2 exposure shift, which would erode the current rates' apparent advantage over time.

### Examiner Report
Candidates were expected to reflect the implementation cost in the proposed rating plan in comparing to the current rating plan and determine if the proposed rates should be implemented given the resulting profit. Both short-term and long-term views of the implementation cost were acceptable.

Common errors included:

- Subtracting the \$10,000 implementation cost from the profit in both scenarios; only Scenario 1 had an implementation cost.
- Subtracting the \$10,000 implementation cost from Scenario 1 but not comparing it to the profit in Scenario 2.
