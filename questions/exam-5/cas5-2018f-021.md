| 2015 | 4,300 | 6,600 | 6,800 | |
| 2016 | 4,300 | 6,800 | | |
| 2017 | 4,900 | | | |

**Cumulative Paid Claims Gross of S&S (\$000) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 13,500 | 16,800 | 16,800 | 16,800 |
| 2015 | 13,300 | 16,900 | 16,900 | |
| 2016 | 13,200 | 16,800 | | |
| 2017 | 12,900 | | | |

| Accident Year | Selected Ultimate Claims Gross of S&S (\$000) |
|---|---|
| 2014 | 16,800 |
| 2015 | 16,900 |
| 2016 | 16,800 |
| 2017 | 16,400 |

- There is no development beyond 48 months.

## Part a (1.5 points)

Estimate ultimate salvage and subrogation for accident year 2017 using a ratio approach.

### Answer

Approximately \$6,920 thousand (selected ultimate ratio of 0.422 applied to \$16,400)

### Explanation

**Step 1 — Ratio of received S&S to cumulative paid claims gross of S&S:**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 0.348 | 0.417 | 0.429 | 0.435 |
| 2015 | 0.323 | 0.391 | 0.402 | |
| 2016 | 0.326 | 0.405 | | |
| 2017 | 0.380 | | | |

**Step 2 — Development of the ratios:**

| | 12–24 | 24–36 | 36–48 | 48–ult |
|---|---|---|---|---|
| 2014 | 1.198 | 1.029 | 1.014 | |
| 2015 | 1.208 | 1.028 | | |
| 2016 | 1.242 | | | |
| Selected | 1.216 | 1.029 | 1.014 | 1.000 |
| CDF to ult | 1.269 | 1.043 | 1.014 | 1.000 |

**Step 3 — Estimated ultimate S&S ratio by accident year:**

| Accident Year | Latest Ratio | CDF | Ultimate Ratio |
|---|---|---|---|
| 2014 | 0.435 | 1.000 | 0.435 |
| 2015 | 0.402 | 1.014 | 0.408 |
| 2016 | 0.405 | 1.043 | 0.422 |
| 2017 | 0.380 | 1.269 | 0.482 |

**Step 4 — Select and apply.** The AY 2017 indication of 0.482 is far out of line with the mature years, driven by the leveraged 12-month CDF applied to an unusually high 12-month ratio. Selecting the average of the three prior accident years' ultimate ratios:

$$\frac{0.435 + 0.408 + 0.422}{3} = 0.422$$

$$\text{Ultimate S\&S}_{2017} = 0.422 \times 16{,}400 = 6{,}920$$

A candidate who instead judged the 12-month ratios to show a genuine increasing trend, and kept the 0.482 indication, was also given credit — the selection had to be actuarially reasoned, not merely mechanical ($0.485 \times 16{,}400 \approx 7{,}960$).

### Examiner Report

Candidates were expected to apply the ratio approach: calculate the S&S-to-paid-claims ratios, develop those ratios to ultimate, make an actuarially sound selection of the ultimate ratio, and apply it to ultimate claims gross of S&S.

Common mistakes included failing to calculate or consider the ultimate S&S ratios for 2014–2016 before selecting for 2017, confusing the ratio approach for S&S with ALAE estimation methods, and computing the ratios against ultimate gross claims rather than cumulative paid claims.
