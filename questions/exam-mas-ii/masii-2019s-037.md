An actuary fits two models, X and Y, to the same dataset.

- Model X contains 10 parameters, resulting in a DIC of 1,020.18.
- The actuary drops two parameters from Model X – the resulting model, Model Y, contains 8 parameters, resulting in a DIC of 1,016.18.
- In both models, the actuary selects flat and non-informative prior distributions for the parameters.

Consider the following statements:

- I. Model Y fits the data more closely than model X.
- II. Model Y is preferred over Model X to make out-of-sample predictions.
- III. Model Y is not overfit.

Determine which of the above statements must be true.

- A) I only
- B) II only
- C) III only
- D) I, II, and III
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

The Deviance Information Criterion, like AIC, estimates out-of-sample deviance by penalizing in-sample fit for the effective number of parameters. Lower is better, and Model Y's 1,016.18 beats Model X's 1,020.18.

**I is false.** Model Y is Model X with two parameters removed, so Model Y is nested inside Model X. A nested model can never fit the sample *more closely* — the larger model has every option the smaller one has plus two more. Model X necessarily has the smaller (better) in-sample deviance; Y wins on DIC because it pays a smaller complexity penalty, not because it fits better.

**II is true.** That is exactly what DIC is for — the criterion is an estimate of out-of-sample predictive performance, and Y's is lower.

**III is false.** DIC compares two models against each other; it does not certify either one in absolute terms. Model Y beating Model X says nothing about whether Model Y is itself overfit — a still simpler model might do better again.

Only statement II must be true, so the answer is **B**.
