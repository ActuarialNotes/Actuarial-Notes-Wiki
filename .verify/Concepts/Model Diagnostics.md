## [F-001] Suggested remedy for top-end under-prediction points the wrong way
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-10-04T20:47Z/8861
- date: 2026-10-04
- severity: minor
- status: open
- locus: example 'Reading Four Diagnostics for a Severity GLM', answer item 2
- claim: Marginal model plot: data smooth well above the model smooth for the largest insured values -> 'the model under-predicts large risks. Try ln(insured value) in place of the raw value, or an interaction with the variable that separates the large risks'.
- evidence: Goldburd et al., GLMs for Insurance Rating, 2nd ed., §2.4.1 'Logging Continuous Variables' pp.11-12 (PDF 21-22): in a log-link model an unlogged predictor gives 'exponential growth, that is, increasing at an increasing rate'; a logged one gives a power curve x^b. So with the raw term ln(mu) is linear in insured value v, with ln(v) it is concave in v (b ln v): fitted through the same bulk of data, the logged model sits BELOW the raw one at the largest values, i.e. it worsens the under-prediction the plot shows. Rank-5 check, done before writing this: simulated 20,000 Gamma(shape 2) severities with ln mu = 1 + 0.08 v^2, v ~ U(0.5, 5), fitted log-link Gamma GLMs by IRLS: at v = 4.75 data mean 16.53, raw-v fit 13.74, ln(v) fit 10.86. Logging addresses the opposite symptom (over-prediction at the top under a raw term). The interaction suggestion is not affected. sha256:89b203ea55208911c4d8f6ef1ede4dd6c0206d47999b5e8aff96fe233c0ff757 — https://www.casact.org/sites/default/files/2021-01/05-Goldburd-Khare-Tevet.pdf
- source_rank: 3
- proposed_action: Author to revise the remedy for this symptom (e.g. more flexibility at the top of the range - bands, a hinge or spline for large insured values - or the interaction already suggested); keep ln(insured value) only for the opposite pattern.
