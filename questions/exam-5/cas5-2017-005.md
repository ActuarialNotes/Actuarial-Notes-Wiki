Given the following information:

- Experience period on-level trended earned premium = \$250,000.
- Experience period trended and developed losses and LAE = \$200,000.
- Experience period earned exposure = 8,000.
- Variable expense provision = 19%.
- Fixed expenses for the experience period = \$16,000.
- Profit and contingency factor = 4%.

## Part a (0.75 points)

Calculate the indicated average rate level change using the loss ratio method.

### Answer
+12.21%

### Explanation
The loss ratio method returns a **change**, not a rate. Everything in it is expressed as a ratio to on-level trended earned premium:

$$\text{Indicated change factor} = \frac{L + \text{EL}_F}{1 - V - Q_T}$$

where $L$ is the projected loss and LAE ratio, $\text{EL}_F$ the fixed expense ratio, $V$ the variable expense provision and $Q_T$ the profit and contingency provision.

**Step 1 — the two ratios.** Both go over the same \$250,000 of on-level trended earned premium:

$$L = \frac{200{,}000}{250{,}000} = 0.80 \qquad \text{EL}_F = \frac{16{,}000}{250{,}000} = 0.064$$

**Step 2 — the indication.** Note that the fixed expense ratio is **added** in the numerator; only the *variable* expense provision and the profit provision are removed from the denominator, because those are the pieces that scale with the rate itself:

$$\text{Indicated change factor} = \frac{0.80 + 0.064}{1 - 0.19 - 0.04} = \frac{0.864}{0.77} = 1.12208$$

$$\text{Indicated rate level change} = 1.12208 - 1 = \mathbf{+12.21\%}$$

Exposures are not needed anywhere in this method — that is the practical distinction from part b.

### Examiner Report
Candidates were expected to understand the loss ratio and pure premium methods, how to apply the formulas for each given rating information, and when each method can or cannot be used.

Candidates were expected to calculate an indicated rate level change using the loss ratio method.

Common errors included:

- Subtracting fixed expense ratio in the numerator of the formula.
- Using exposures as a step to get one of the inputs, as exposures are not required for this method.
- Calculating the indicated rate using the pure premium method and dividing by the current rate, as this did not use the method required in this part of the question.

## Part b (0.75 points)

Calculate the indicated average rate using the pure premium method.

### Answer
\$35.06

### Explanation
The pure premium method returns a **rate** directly, and works entirely on a per-exposure basis:

$$\text{Indicated average rate} = \frac{\text{Pure premium} + \text{Fixed expense per exposure}}{1 - V - Q_T}$$

**Step 1 — the two per-exposure quantities.** Both go over the 8,000 earned exposures:

$$\text{Pure premium} = \frac{200{,}000}{8{,}000} = \$25.00 \qquad \text{Fixed expense per exposure} = \frac{16{,}000}{8{,}000} = \$2.00$$

**Step 2 — gross up for variable expenses and profit.**

$$\text{Indicated average rate} = \frac{25.00 + 2.00}{1 - 0.19 - 0.04} = \frac{27.00}{0.77} = \mathbf{\$35.06}$$

Premium is not used anywhere in this method, just as exposures were not used in part a. Consistently, the two methods agree: the current average rate implied by the experience is $250{,}000 / 8{,}000 = \$31.25$, and $35.06 / 31.25 - 1 = 12.21\%$, the part a indication.

### Examiner Report
Candidates were expected to calculate an indicated rate level using the pure premium method.

Common errors included:

- Subtracting fixed expense per exposure in the numerator of the formula.
- Dividing premium by exposure instead of dividing loss by exposure to get the pure premium.
- Using premium as a step to get one of the inputs, as premium is not required for this method.
- Calculating the rate change in part a. and applying it to the current rate to get the indicated rate level, as this did not use the method required in this part of the question.

## Part c (0.5 points)

Briefly describe one situation where the loss ratio method cannot be used and one situation where the pure premium method cannot be used.

### Explanation
Each method fails when one of its own critical inputs does not exist. The description has to name the missing input, not merely the situation.

**Loss ratio method — a new line of business or new territory.** The method produces a change to an existing rate, so it needs premium at current rate level. For a brand new program there is no historical premium and no rate history to on-level it with, so no indicated change can be computed; the pure premium method must be used instead to set the rate from first principles.

**Pure premium method — a line with no well-defined exposure base.** The method divides losses by exposures, so it needs a consistently measured exposure unit. On some commercial coverages the exposure base is ambiguous or has changed definition mid-experience-period, so the exposures cannot be aggregated meaningfully; the loss ratio method, which never touches exposures, remains available.

### Examiner Report
Candidates were expected to briefly describe a situation where the loss ratio method and the pure premium method cannot be used.

Common errors included:

- Confusing the methods; for example, stating that the loss ratio method needed exposures or that the pure premium method needed on-level premiums.
- Providing an example situation without elaborating as to why the stated method cannot be used for the example identified (i.e., not mentioning that it is the absence of a critical input that makes the example valid).
- Incorrectly listing an input that is not required in order to use the method.
