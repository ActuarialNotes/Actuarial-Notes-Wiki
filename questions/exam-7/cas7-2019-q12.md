The Exponential Dispersion Family ("EDF") is a family of distributions with probability density function $\pi(y; \theta, \phi)$ of the form:

$$\ln \pi(y; \theta, \phi) = \frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi)$$

and variance function of the form:

$$V(\mu) = b''\left((b')^{-1}(\mu)\right)$$

## Part a (0.5 points)

Briefly describe the parameter $\theta$ and the function $b(\theta)$ in the equation above.

### Explanation
Parameter $\theta$ — any of:

- Location parameter
- Canonical parameter
- $\theta = (b')^{-1}(\mu)$

Function $b(\theta)$ — any of:

- Cumulant function
- $b(\theta)$ describes the mean of the EDF: $\mu = b'(\theta)$
- Shape function

### Examiner Report
Candidates were expected to recall the name of $\theta$ and $b(\theta)$ in the context of an EDF probability density function, or state how they affect an EDF distribution.

Common mistakes included:

- stating that they are the dispersion parameter
- stating that they are the scale parameter

## Part b (0.5 points)

Explain how the Tweedie sub-family can be obtained from the EDF above.

### Explanation
- The Tweedie sub-family is obtained by allowing the variance function to be $V(\mu) = \mu^p$, where $p$ is not between 0 and 1.
- Equivalently, restrict the EDF's variance function to $V(\mu) = \mu^p$ with $p \le 0$ or $p \ge 1$.

### Examiner Report
Candidates were expected to recall the restriction on the variance function of an EDF distribution that would give rise to a Tweedie distribution. Both the form of the variance function and the restriction on $p$ must be identified.

Specific results of the Tweedie distribution, such as $\mu = [(1 - p)\theta]^{\frac{1}{1-p}}$, were given credit. Responses that did not identify the correct restriction on $p$ did not receive full credit.

Common mistakes included:

- not providing the restriction on $p$
- confusing the concept of variance versus the variance function

## Part c (0.25 points)

Briefly describe how to select a Tweedie distribution for a heavy-tailed exposure.

### Explanation
Sample Responses

- Choose a larger value for p
- Select a Tweedie with p = 2, since this is the Gamma which is heavy-tailed
- For heavy-tailed, use a Tweedie with p = 3 (inverse Gaussian)

### Examiner Report
Candidates were expected to recognize that a higher value of p will increase the variance of a Tweedie distribution and thus generate a distribution with a heavier tail. Alternatively, candidates can identify which member of a Tweedie distribution has a heavy tail, and how such a distribution would be generated by changing p.
Responses that stated selecting a higher φ will lead to higher variance and thus a heavier tail did not receive credit.  φ is a parameter of a distribution of the EDF family, so it does not affect the selection of a distribution.
Common mistakes included:

- stating decreasing p will increase tail heaviness
- stating a specific value of p without clear justification why it would lead to a heavy tail

## Part d (0.75 points)

Given the following information as of December 31, 2018:

**Cumulative Paid Loss (\$000):**

| Accident Year | 12 Months | 24 Months | 36 Months |
|---|---|---|---|
| 2016 | 180 | 1,000 | 1,200 |
| 2017 | 200 | 600 | |
| 2018 | 150 | | |

A GLM is used to model the incremental paid losses. The GLM uses a log link function and a Tweedie error distribution specified by:

- $p = 1$
- $b(\theta) = \exp(\theta)$
- $\mu = \exp(\theta)$
- $\ln \pi(y; \mu, \phi) = [y \ln \mu - \mu]/\phi$

Calculate the accident year 2018 ultimate loss.

### Explanation
With $p = 1$ this is an over-dispersed Poisson model; if the Mack assumptions hold (assumed here), it reproduces the chain ladder, so use chain ladder development factors:

$$\text{LDF}_{12\text{-}24} = \frac{1{,}000 + 600}{180 + 200} = 4.21 \qquad \text{LDF}_{24\text{-}36} = \frac{1{,}200}{1{,}000} = 1.2$$

$$\text{2018 ultimate} = 4.21 \times 1.2 \times 150 = 757.89$$

Alternatively, solve the ODP cross-classified model's MLEs directly (row parameters $\alpha$, column proportions $\beta$):

$$\alpha_{2016} = 1{,}200 \qquad \beta_3 = \frac{200}{1{,}200} = 0.167 \qquad \alpha_{2017} = \frac{600}{1 - 0.167} = 720$$

$$\beta_2 = \frac{820 + 400}{1{,}200 + 720} = 0.635 \qquad \alpha_{2018} = \frac{150}{1 - 0.167 - 0.635} = 758$$

$$\beta_1 = \frac{180 + 200 + 150}{1{,}200 + 720 + 758} = 0.198$$

$$\text{2018 Ult} = 150 + 758 \times (0.635 + 0.167) = 758$$

### Examiner Report
Candidates were expected to recognize when p = 1, the Tweedie distribution is an over dispersed Poisson (ODP) and it replicates the standard chain ladder method.
Common mistakes include

- using incorrect MLEs for the ODP cross-classified model
- not stating the reason why the CL method applies
