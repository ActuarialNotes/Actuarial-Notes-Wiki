The random vector $(W, X, Y)$ has the following properties:

i) $W$ assumes values of only 0 and 1.
ii) $X$ and $Y$ each assume values of only 1 and 2.
iii) $P[W = w, X = x, Y = y]$ is proportional to $x + y - w$.

Calculate $\text{Var}(W \mid Y = 1)$.

- A) $51/400$
- B) $15/64$
- C) $6/25$
- D) $3/8$
- E) $2/5$

## Explanation

There are $2 \times 2 \times 2 = 8$ outcomes. Tabulate $x + y - w$ for each:

| $(w,x,y)$ | weight | | $(w,x,y)$ | weight |
| --- | --- | --- | --- | --- |
| $(0,1,1)$ | 2 | | $(1,1,1)$ | 1 |
| $(0,1,2)$ | 3 | | $(1,1,2)$ | 2 |
| $(0,2,1)$ | 3 | | $(1,2,1)$ | 2 |
| $(0,2,2)$ | 4 | | $(1,2,2)$ | 3 |

The weights total 20, so each probability is its weight over 20.

Condition on $Y = 1$, which keeps the four rows with $y = 1$: weights 2, 3 (for $w=0$) and 1, 2 (for $w=1$), totalling 8. So

$$
\begin{align*}
P[W = 0 \mid Y = 1] &= \frac{2+3}{8} = \frac{5}{8} \\
P[W = 1 \mid Y = 1] &= \frac{1+2}{8} = \frac{3}{8}
\end{align*}
$$

$W$ is a 0/1 variable, so conditionally it is Bernoulli with $p = 3/8$ and

$$
\begin{align*}
\text{Var}(W \mid Y=1) &= p(1-p) \\
                       &= \frac{3}{8}\cdot\frac{5}{8} \\
                       &= \mathbf{\frac{15}{64}}
\end{align*}
$$

Choice (D), 3/8, is the conditional *mean* rather than the variance. Note that the overall normalizing constant of 20 cancels when conditioning — only the four $y=1$ weights matter, which is what keeps the arithmetic short.
