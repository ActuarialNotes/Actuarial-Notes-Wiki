Given the following:

| Portfolio | Expected Annual Rate of Return | Beta |
|---|---|---|
| A | 7.8% | 0.4 |
| B | 8.3% | 0.9 |

- The market portfolio has an expected annual rate of return of 10%.
- The risk-free rate is 5%.

## Part a (0.5 points)

Calculate the alpha for each of portfolio A and B using the capital asset pricing model (CAPM).

### Explanation
$$\alpha_A = .078 - \left[r_f + \beta_A(E(r_M) - r_f)\right] = .078 - [.05 + 0.4(.10 - .05)] = 0.008$$

$$\alpha_B = .083 - [.05 + 0.9(.10 - .05)] = -0.012$$

Alternatively:

α = Expected rate of return – Rate predicted by CAPM

$$\text{CAPM } E(r_a) = \left[r_f + \beta_A(E(r_M) - r_f)\right] = [.05 + 0.4(.10 - .05)] = .07$$

$$\text{CAPM } E(r_a) = \left[r_f + \beta_A(E(r_M) - r_f)\right] = [.05 + 0.4(.10 - .05)] = .095 \quad \text{(as printed; portfolio B, } \beta_B = 0.9 \text{, meant)}$$

$$\alpha_A = .078 - .070 = .8\%$$

$$\alpha_B = .083 - .095 = -1.2\%$$

### Examiner Report
Candidates were expected to understand the relationship between beta and the expected return of a portfolio using the CAPM. They were also expected to understand where each of the 4 portfolios plotted in relation to the SML. Candidates had to know that alpha was the difference between the SML's fair price given Beta and the published return. Candidates were then required to represent this difference graphically.

Candidates were expected to calculate the alpha for each of the 2 portfolios given by subtracting the expected return from the CAPM model from the published returns.

Common errors include:

- Simple calculation errors while calculating α
- Calculating the CAPM E(r) instead of alpha

## Part b (1 point)

Graph the security market line (SML).  Plot the positions of portfolio A, portfolio B, the market portfolio and the risk-free portfolio.  Clearly label the axes and the alpha for each of portfolio A and B.

### Explanation
![Security market line on axes of beta (horizontal, 0 to 1.2) and expected return E(R) (vertical, 0 to 0.12). The SML is a straight line from the risk-free rate rf at (0, 0.05) to the market portfolio M at (1, 0.1). Portfolio A at (0.4, 0.078) plots above the line, its alpha a bracket up from the SML's 0.07 at beta 0.4; portfolio B at (0.9, 0.083) plots below the line, its alpha a bracket down from the SML's 0.095 at beta 0.9](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/cas9-2017-q5-sml.png)

### Examiner Report
Candidates were expected to:

- Plot the portfolios using the appropriate Beta-Return coordinates
- Label the axes as Beta and Expected Return
- Plot the SML with the 2 key portfolios (risk free and Market) on it
- Clearly label the alphas as distances from the SML to the given portfolios A and B

Common errors include:

- Plotting A and B directly on the SML
- Plotting the risk free rate at a value other than 5%
- Mixing up Beta with Sigma
- Not plotting the alphas as distances between points
