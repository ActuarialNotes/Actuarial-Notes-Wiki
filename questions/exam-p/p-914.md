A company's profit $Y$ is uniformly distributed on an interval $[a, b]$, with $P[Y > 0] = 0.75$, $P[Y > 100] = 0.50$ and $P[Y > 200] = 0.25$.

Calculate $E[Y/100]$.

- A) 0.5
- B) 1.0
- C) 1.5
- D) 2.0
- E) 2.5

## Explanation

For $Y \sim \text{Uniform}[a, b]$ and $a \le y \le b$, $P(Y > y) = \dfrac{b-y}{b-a}$. Both 0 and 200 lie inside $[a, b]$, since $P(Y>0)$ and $P(Y>200)$ are strictly between 0 and 1.

$P(Y>0) - P(Y>200) = \dfrac{200}{b-a} = 0.75 - 0.25 = 0.50$, so $b - a = 400$.

$P(Y>0) = \dfrac{b}{400} = 0.75$, so $b = 300$ and $a = -100$. Check: $P(Y>100) = 200/400 = 0.50$.

$$E[Y] = \frac{-100+300}{2} = 100$$

$$E[Y/100] = \frac{100}{100} = \mathbf{1.0}$$
