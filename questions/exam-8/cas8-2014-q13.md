A Table M is constructed based on the experience of the following 10 similarly sized risks:

| Risk | Aggregate Loss Ratio |
|---|---|
| 1 | 10% |
| 2 | 30% |
| 3 | 35% |
| 4 | 40% |
| 5 | 60% |
| 6 | 75% |
| 7 | X% |
| 8 | 90% |
| 9 | 110% |
| 10 | 120% |

X is the aggregate loss ratio for Risk 7.

Assume:

- $75\% \le X \le 90\%$
- The Table M charge at entry ratio 1.5 is 0.05.

Calculate X.

### Explanation
Vertical slices approach:

$$\text{Average loss ratio} = \frac{.1 + .3 + .35 + .4 + .6 + .75 + X + .9 + 1.1 + 1.2}{10} = 0.57 + .1X$$

With $75\% \le X \le 90\%$ the average loss ratio is between 64.5% and 66%, so LR × entry ratio (1.5) is between 96.75% and 99%. Only losses 9 and 10 contribute to the charge. Therefore:

$$0.05 = \frac{[1.2 - 1.5(0.57 + .1X)] + [1.1 - 1.5(0.57 + .1X)]}{10(0.57 + .1X)}$$

$$.5(0.57 + .1X) = 2.3 - 3(0.57 + .1X) \quad\Rightarrow\quad 3.5(0.57 + .1X) = 2.3 \quad\Rightarrow\quad 0.57 + .1X = 0.657$$

$$X = 87.14\%$$

Alternatively, with horizontal slices: $\Phi(1.5) = 0.05$ and

$$M = \text{unlimited LR mean} = \tfrac{1}{10}[0.1 + 0.3 + 0.35 + 0.4 + 0.6 + 0.75 + 0.9 + 1.1 + 1.2 + X] = 0.57 + \tfrac{X}{10}$$

$$r = \frac{\text{risk LR}}{0.57 + X/10} = 1.5 \quad\Rightarrow\quad \text{risk LR} = 0.855 + 0.15X$$

Since $0.75 \le X \le 0.9$: $0.645 \le \text{mean} \le 0.66$ and $0.9675 \le \text{risk LR} \le 0.99$. Only risks 9 and 10 are above 0.9675 and 0.99.

| r | LR | # risks | risks above | % risk above |
|---|---|---|---|---|
| 1.5 | | | 2 | 0.2 |
| $1.667 \le r \le 1.7057$ | 1.1 | 1 | 1 | 0.1 |
| $1.818 \le r \le 1.86$ | 1.2 | 1 | 0 | 0 |

Building the charge up from the top with $\Phi(r_i) = \Phi(r_{i-1}) + (r_i - r_{i-1}) \times (\%\text{ above})$:

$$0.05 = \left(\frac{1.2}{M} - \frac{1.1}{M}\right) \times 0.1 + \left(\frac{1.1}{M} - 1.5\right) \times (0.2) \quad\Rightarrow\quad 0.05 = \frac{0.01}{M} + \frac{0.22}{M} - 0.3 \quad\Rightarrow\quad 0.35 = \frac{0.23}{M}$$

$$M = 0.657 = 0.57 + \frac{X}{10} \quad\Rightarrow\quad X = 87.14\%$$

### Examiner Report
This question was more challenging than a standard table M construction question. It required candidates to understand the interplay between the loss ratio, the entry ratio, the charge, and the calculation of the charge. Many candidates scored very well.

While some candidates were able to get to the final answer by testing various values of x and calculating the resulting charge, the optimal approach to complete was to set up the charge calculation in terms of x and set equal to 0.05, which many candidates were not able to do. Both the horizontal and vertical slicing methods of calculating the charge were used successfully.

In any approach, the use of the range was helpful in determining that only risks 9 & 10 would be included in the calculation, but a common mistake was not using that information and including more risks.

Another common mistake was an error in the setup of the equality, such as not dividing the calculation by the average loss ratio. Others set everything up correctly but had an algebra error in solving for x.
