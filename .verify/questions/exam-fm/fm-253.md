## [F-001] Explanation's quadratic in v^10 has the wrong sign; its roots (1 and -0.4) do not include the 0.4 it then uses

- locus: Explanation, lines 65-72
- claim: From 5 − 5v^{20} = 3 + 3v^{10} the explanation writes 5x^2 − 3x − 2 = 0, x = (3 ± √(9+40))/10 = (3+7)/10 = 1 or (3−7)/10, then 'Taking the positive root less than 1: x = v^{10} = 0.4 (discarding x=1 since i>0)'.
- evidence: SOA Q253 solution (solutions PDF p.65, page image): 5 − 5v^{20} = 3 + 3v^{10}; 0 = 5v^{20} + 3v^{10} − 2; x = v^{10} = (−3 ± √(9+4(5)(2)))/(2(5)) = (−3 ± 7)/10 = 0.4 ⇒ i = 9.59582%; X = 600/0.0959582·(1 + 0.4) = 8753.8. Recomputation: 5 − 5x^2 = 3 + 3x rearranges to 5x^2 + 3x − 2 = 0 with roots 0.4 and −1; the vault's 5x^2 − 3x − 2 = 0 has roots 1 and −0.4, neither of which is the 0.4 taken on line 72, so the step does not follow. The explanation's final i = 9.596% and X = 1000·a_20 = 8753 are right (1000 a_20 at 9.5958% = 8753.81); key B unaffected.
