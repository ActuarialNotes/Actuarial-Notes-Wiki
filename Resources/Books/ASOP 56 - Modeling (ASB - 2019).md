The standard governing how an actuary designs, develops, selects, uses and validates a **model**. It supplies the professional vocabulary of [[Exam PCPA (CAS)|PCPA]]: hold-out data, overfitting and [[Model Risk|model risk]]. It was adopted by the Actuarial Standards Board in December 2019.

## Section 2. Definitions

- 2.1 Assumption
- 2.2 Data
- 2.3 Governance and Controls
- 2.4 Hold-out Data — a subset of data withheld intentionally when developing a predictive model, so it can be validated on data not used to develop it (see [[Holdout Sample]])
- 2.5 Input
- 2.6 Intended Purpose
- 2.7 Intended User
- 2.8 Model — a simplified representation of relationships among real-world variables, entities or events, with an input component, a processing component and a results component
- 2.9 Model Risk — the risk of adverse consequences from relying on a model that does not adequately represent what is modelled, or from its misuse or misinterpretation (see [[Model Risk]])
- 2.10 Model Run
- 2.11 Output
- 2.12 Overfitting — fitting the development data so closely that prediction accuracy materially decreases on different data (see [[Bias-Variance Tradeoff]])
- 2.13 Parameter
