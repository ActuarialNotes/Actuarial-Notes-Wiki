A property reinsurer currently writes the following two renewal accounts with modeled losses as shown below:

| Event | Event Probability | Losses for Account X (in \$000's) | Losses for Account Y (in \$000's) | Losses for Account X + Y (in \$000's) |
|---|---|---|---|---|
| 1 | 0.5% | \$100 | \$85 | \$185 |
| 2 | 1.0% | \$75 | \$60 | \$135 |
| 3 | 2.5% | \$35 | \$25 | \$60 |
| 4 | 5.0% | \$20 | \$15 | \$35 |
| Coefficient of Variation | | 3.97 | 4.11 | 4.03 |

- The target return on marginal surplus is 12.5%.
- Using the marginal surplus method, the reinsurer calculated the sum of the risk loads for account X and Y to be \$4,071.

## Part a (2 points)

Determine the probability that the actual result will require more surplus than what was allocated.

### Explanation
Work in dollars. For each account, the mean from the event table and the standard deviation from the coefficient of variation:

**Account X + Y:**

$$\mu_{x+y} = 0.005 \times 185{,}000 + 0.01 \times 135{,}000 + 0.025 \times 60{,}000 + 0.05 \times 35{,}000 = 5{,}525$$

$$\sigma_{x+y} = 4.03 \times \mu_{x+y} = 4.03 \times 5{,}525 = 22{,}266$$

**Account X:**

$$\mu_x = 0.005 \times 100{,}000 + 0.01 \times 75{,}000 + 0.025 \times 35{,}000 + 0.05 \times 20{,}000 = 3{,}125$$

$$\sigma_x = 3.97 \times \mu_x = 3.97 \times 3{,}125 = 12{,}406$$

**Account Y:**

$$\mu_y = 0.005 \times 85{,}000 + 0.01 \times 60{,}000 + 0.025 \times 25{,}000 + 0.05 \times 15{,}000 = 2{,}400$$

$$\sigma_y = 4.11 \times \mu_y = 4.11 \times 2{,}400 = 9{,}864$$

**Risk loads.** Under the marginal surplus method each account's renewal risk load is $\lambda$ times its marginal standard deviation:

$$R_x = \lambda\,(\sigma_{x+y} - \sigma_y) = \lambda\,(22{,}266 - 9{,}864) = 12{,}402\,\lambda$$

$$R_y = \lambda\,(\sigma_{x+y} - \sigma_x) = \lambda\,(22{,}266 - 12{,}406) = 9{,}860\,\lambda$$

$$R_{x+y} = 12{,}402\,\lambda + 9{,}860\,\lambda = 4{,}071 \quad\Rightarrow\quad \lambda = 0.183$$

With $y$ the target return on marginal surplus:

$$\lambda = \frac{y\,Z}{1+y}: \quad 0.183 = \frac{0.125\,Z}{1 + 0.125} \quad\Rightarrow\quad Z = 1.645$$

Looking up $Z$ in the standard normal table gives 95%. Therefore the probability is 5% (100% - 95%).

Alternatively, use Mango's binomial approximation for the standard deviations:

$$\sigma^2 = \sum_i p_i\,(1 - p_i)\,L_i^2$$

$$\sigma_x^2 = 0.005 \times 0.995 \times 100{,}000^2 + 0.01 \times 0.99 \times 75{,}000^2 + 0.025 \times 0.975 \times 35{,}000^2 + 0.05 \times 0.95 \times 20{,}000^2 = 154{,}296{,}875$$

so $\sigma_x = 12{,}422$.

$$\sigma_y^2 = 0.005 \times 0.995 \times 85{,}000^2 + 0.01 \times 0.99 \times 60{,}000^2 + 0.025 \times 0.975 \times 25{,}000^2 + 0.05 \times 0.95 \times 15{,}000^2 = 97{,}506{,}250$$

so $\sigma_y = 9{,}875$.

$$\sigma_{x+y}^2 = 0.005 \times 0.995 \times 185{,}000^2 + 0.01 \times 0.99 \times 135{,}000^2 + 0.025 \times 0.975 \times 60{,}000^2 + 0.05 \times 0.95 \times 35{,}000^2 = 496{,}634{,}375$$

so $\sigma_{x+y} = 22{,}285$. Then

$$4{,}071 = \frac{0.125\,z}{1.125}\,(22{,}285 - 9.875) + \frac{0.125\,z}{1.125}\,(22{,}285 - 12{,}422)$$

(the 9.875 is as printed), giving $z = 1.645$ and $1 - N(z) = 0.05$: a 5% probability.

### Examiner Report
In part a, candidates were expected to derive the key components of the marginal surplus renewal risk load equation for accounts X and Y as described in the Mango paper. Candidates were expected to use these items to compute the last remaining input--the probability that the result would require more surplus than what was allocated.

As opposed to using the correct procedure applied above, $R_{x+y} = \lambda \times \left( (\sigma_{x+y} - \sigma_y) + (\sigma_{x+y} - \sigma_x) \right)$, many candidates used incorrect equations for the risk load.

The most common variations were:

- $R_{x+y} = \lambda \times (\sigma_{x+y})$
- $R_{x+y} = \lambda \times (\sigma_x + \sigma_y)$
- $R_{x+y} = \lambda \times \left( (\sigma_{x+y}) + (\sigma_{x+y} - \sigma_y) \right)$

Due to the high correlation of losses for accounts X and Y, as well as rounding, many candidates who applied one of the incorrect procedures above ended up with a similar probability to the correct procedure, resulting in partial credit.

Other Common Errors:

- Using an incorrect formula for the coefficient of variation
- Assuming additional surplus was equal to the risk load plus expected loss
- Calculating the probability that the surplus would be sufficient rather than the probability that more surplus would be required (i.e. forgetting to subtract the probability from 1)
- Assuming the Risk Load provided was in \$1000's
- Calculation Errors

## Part b (0.5 points)

Identify an alternative approach to using the marginal surplus method for calculating risk loads and briefly describe an advantage to that approach.

### Explanation
- Use the Covariance Share method--The advantage is that it is renewal additive.
- Covariance Share Method.  It spreads risk loads more equitably by using expected loss to allocate the covariance.
- The Shapley method allocates covariance equally to each account.  Advantage is that this method is renewal additive.
- Use Myers-Read marginal surplus method--advantage is that it is renewal additive.

### Examiner Report
Most candidates picked up on a major deficiency of the marginal surplus method from the paper and were able to show a method that would be superior.  The vast majority of candidates received full credit.  Some candidates provided multiple advantages: only the first one was considered.
Some Common Fully or Partially Incorrect Responses Were:

- Marginal Variance because it is more conservative
- Build Up Method
- Describing an alternate approach but not explicitly naming an advantage
- Naming an incorrect method
