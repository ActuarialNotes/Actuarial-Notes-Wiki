Given the following:

| Effective Date | Overall Average Rate Change | Rate Per Exposure (\$) | Class Factor X | Class Factor Y | Class Factor Z | Expense Fee (\$) |
|---|---|---|---|---|---|---|
| January 1, 2016 | 0.0% | 1,000 | 1.20 | 0.85 | 1.00 | 120 |
| July 1, 2017 | 10.0% | 1,112 | 1.20 | 0.85 | 1.00 | 120 |
| October 1, 2017 | 0.0% | 1,175 | 1.10 | 0.75 | 1.00 | 120 |
| April 1, 2018 | 1.0% | 1,175 | 1.10 | 0.75 | 1.00 | 132 |

- All policies are semi-annual.
- Exposures are written uniformly throughout the year.
- Expense fee is a per exposure fee that is added in the last step of the rate calculation.

## Part a (0.75 point)

Calculate the on-level factor for calendar year 2017 earned premium using the parallelogram method.

### Answer

1.084

### Explanation

Build the cumulative rate level index from the overall average rate changes:

| Effective Date | Change | Cumulative Rate Level |
|---|---|---|
| January 1, 2016 | 0.0% | 1.000 |
| July 1, 2017 | +10.0% | 1.100 |
| October 1, 2017 | 0.0% | 1.100 |
| April 1, 2018 | +1.0% | $1.100 \times 1.01 = 1.111$ |

Policies are **semi-annual**, so a rate change effective at time $t$ within the year is fully earned six months later. The portion of CY 2017 earned premium written at the new (1.100) level is the parallelogram area

$$\frac{(1 - t)^2}{2m} = \frac{(1 - 0.5)^2}{2(0.5)} = 0.25$$

leaving 0.75 of the year at the 1.000 level. The October 1, 2017 change is 0.0%, so it does not move the index, and the April 1, 2018 change earns entirely after CY 2017.

$$\overline{RL}_{2017} = 0.75(1.000) + 0.25(1.100) = 1.025$$

Current rate level is the level in effect today:

$$1.100 \times 1.01 = 1.111$$

$$\text{OLF}_{2017} = \frac{1.111}{1.025} = 1.0839$$

### Examiner Report

Candidates were expected to understand both parallelogram and extension of exposure methods, their underlying assumptions, and how to apply those methods to calculate on-level factors.

Candidates were expected to identify each rate level at different points in time and weight them to calculate the on-level factor.

A common mistake was miscalculating weights (portion of year) to apply to each rate level.

## Part b (0.5 point)

Calculate the on-level factor for a policy effective on April 1, 2017 within Class Y using the extension of exposure method.

### Answer

1.045

### Explanation

Extension of exposures re-rates the policy at current rates rather than applying an aggregate index, so the class factor and expense fee changes both matter.

**Premium at the rates in effect April 1, 2017** (the January 1, 2016 row):

$$1{,}000 \times 0.85 + 120 = 850 + 120 = 970$$

**Premium at current rates** (the April 1, 2018 row):

$$1{,}175 \times 0.75 + 132 = 881.25 + 132 = 1{,}013.25$$

$$\text{OLF} = \frac{1{,}013.25}{970} = 1.0446$$

### Examiner Report

Candidates were expected to calculate written premium on different effective dates for a class, then calculate the on-level factor.

Common mistakes include:

- Using wrong point in time (row in table) or class factors
- Not including expense fee

## Part c (0.5 point)

Assess the appropriateness of using the parallelogram method to calculate indicated class factors using the loss ratio method.

### Explanation

The parallelogram method is **not appropriate** here. It on-levels premium at the aggregate level using the *overall average* rate change, so it cannot capture rate changes that fall unevenly across classes. The October 1, 2017 revision had a 0.0% overall average change but moved Class X from 1.20 to 1.10 and Class Y from 0.85 to 0.75 — the individual classes were repriced even though the average did not move. On-leveling each class's premium with the overall index would therefore leave the class premium at the wrong level and distort the indicated class factors.

If the parallelogram method were applied separately at the class level, using each class's own rate impact, it could be acceptable. Otherwise extension of exposures is the appropriate method, since it re-rates each policy at current class factors.

### Examiner Report

Candidates were expected to understand that the parallelogram method is applied at the aggregate level using the average rate change.

Common mistakes include:

- Not identifying the different class factor changes
- Not realizing the parallelogram method uses overall average rate change
