Given the following information about a home:

|  |  |
|---|---|
| \$250,000 | Home value |
| \$200,000 | Insured value |
| 90% | Coinsurance requirement |

## Part a (1 point)

Calculate the coinsurance penalty for the following loss amounts:

- i. \$50,000
- ii. \$220,000
- iii. \$250,000

### Explanation
The coinsurance requirement is 90% × 250,000 = 225,000, and the home is insured for 200,000, so it is underinsured. For a loss $L$, the indemnity is

$$I = \min\left(L \times \frac{200{,}000}{225{,}000},\ 200{,}000\right)$$

and the coinsurance penalty is what the insured would have received without the clause, less $I$: $L - I$ for a loss up to the face value, 200,000 - I for a loss between the face value and the coinsurance requirement, and none for a loss at or above the requirement.

| Loss | Indemnity | Coinsurance penalty |
|---|---|---|
| i. 50,000 | 50,000 × 0.8889 = 44,444 | 50,000 - 44,444 = 5,556 |
| ii. 220,000 | 220,000 × 0.8889 = 195,556 | 200,000 - 195,556 = 4,444 |
| iii. 250,000 | min(222,222, 200,000) = 200,000 | 0 |

In ii the penalty is measured against the face value, since without the clause the payment would have been capped at 200,000; in iii the loss is above the coinsurance requirement, so there is no penalty — the insured simply bears the loss above the face value.

### Examiner Report
Candidates were expected to demonstrate an understanding of underinsurance compared to insurance to value and to demonstrate knowledge of coinsurance penalty calculations.

Candidates were expected to calculate coinsurance penalties for varying loss amounts, given specified home and policy characteristics.

Common errors included:

- Not recognizing the need to subtract the indemnity payment from the face value of the policy instead of from the loss amount in part ii.
- Not recognizing the need to cap the indemnity payment at the face value of the policy in part iii.
- Stating all losses above the face value resulted in a \$0 coinsurance penalty, instead of just those losses above the coinsurance requirement.
- Using incorrect values in the calculation of the indemnity payments or penalties.
- Calculating only indemnity payments.

## Part b (0.5 points)

Briefly describe two problems with underinsurance.

### Explanation
- **Inadequate rates:** rates per unit of insurance assume insurance to value. Most losses are partial, so an underinsured home generates nearly the same losses as one insured to value while paying premium on a smaller amount of insurance; the premium collected is too small for the expected loss.
- **Inequitable rates:** two homes of the same value with the same expected loss pay different premiums if one is insured to value and the other is not, so the fully insured policyholder subsidizes the underinsured one. (For the insured, underinsurance also means a large loss may not be fully indemnified, and a coinsurance penalty may reduce even a partial loss.)

### Examiner Report
Candidates were expected to briefly describe two problems with underinsurance.

Common errors included:

- Using "rates are inequitable or inadequate" or "rates are mispriced" as an issue for the insurer. There are several issues that cause rates to be inequitable or inadequate – candidates needed to demonstrate that they understand the mechanics of underinsurance specifically.
- Using "doesn't have full coverage" or "won't be fully indemnified for losses" as an issue for the insured without clarifying loss amounts or existence of a coinsurance penalty. An underinsured policy will have full coverage if the loss amount is under the insured amount and there is no coinsurance penalty.
- Incorrectly describing how partial losses or the loss distribution contribute to the inadequacy and inequity issues.
- Only providing one problem with underinsurance.
