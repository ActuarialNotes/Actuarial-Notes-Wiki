You are given the following regression tree predicting the weight of ducks in kilograms (kg):

![Regression tree. The root splits on Age > 7.5 Years. On the (no) branch, a split on Gender = 1 (Male): (no) gives 0.80 kg, (yes) gives 0.90 kg. On the (yes) branch, a split on Gender = 1 (Male): (no) gives 0.95 kg; (yes) leads to a split on Wing Span > 5.3 cm, where (no) gives 1.10 kg and (yes) gives 1.25 kg. In every split the (no) branch is drawn on the left and the (yes) branch on the right.](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/srm-q51-duck-tree.png)

You predict the weight of the following three ducks:

X: Wing Span = 5.5 cm, Male, Age = 7 years

Y: Wing Span = 5.8 cm, Female, Age = 5 years

Z: Wing Span = 5.7 cm, Male, Age = 8 years

Determine the order of the predicted weights of the three ducks.

- A) X < Y < Z
- B) X < Z < Y
- C) Y < X < Z
- D) Y < Z < X
- E) Z < X < Y

## Explanation

Run each duck down the tree, taking the (no) branch on the left and the (yes) branch on the right at each split.

- **Duck X** (Age 7, Male, Wing Span 5.5 cm): Age > 7.5 is no, so go left. Gender = Male is yes, so go right. Prediction = 0.90 kg.
- **Duck Y** (Age 5, Female, Wing Span 5.8 cm): Age > 7.5 is no, so go left. Gender = Male is no, so go left. Prediction = 0.80 kg.
- **Duck Z** (Age 8, Male, Wing Span 5.7 cm): Age > 7.5 is yes, so go right. Gender = Male is yes, so go right. Wing Span > 5.3 cm is yes, so go right. Prediction = 1.25 kg.

Wing span is never used for X or Y, because only the older-male branch splits on it. The order is $0.80 < 0.90 < 1.25$, that is, Y < X < Z.
