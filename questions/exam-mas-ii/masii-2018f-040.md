You are given the following classification decision tree and data set:

![Classification tree. The root splits on X1 < 21: the left branch is a terminal node predicting T. The right branch splits on X2 = Y into a left terminal node predicting T and a right terminal node predicting F](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/masii-2018f-q40-classification-tree.png)

| $i$ | $X_1$ | $X_2$ | $Y$ |
|---|---|---|---|
| 1 | 12 | Y | T |
| 2 | 23 | N | F |
| 3 | 4 | Y | F |
| 4 | 32 | Y | F |
| 5 | 22 | N | T |
| 6 | 30 | Y | T |
| 7 | 18 | N | T |

Determine the relationship between the classification error rate, the Gini index, and the cross-entropy, summed across all nodes.

- A) cross-entropy > Gini index > classification error rate
- B) cross-entropy > Gini index = classification error rate
- C) classification error rate > Gini index > cross-entropy
- D) Gini index > cross-entropy > classification error rate
- E) The answer is not given by (A), (B), (C), or (D).

## Explanation

Send each observation down the tree, then compute the three impurity measures in each terminal node from the proportion $\hat{p}$ of the node's majority class.

- **$X_1 < 21$:** observations 1, 3, 7 give T, F, T. The node predicts T, with $\hat{p} = 2/3$.
- **$X_1 \ge 21$, $X_2 = Y$:** observations 4, 6 give F, T. The node predicts T, with $\hat{p} = 1/2$.
- **$X_1 \ge 21$, $X_2 = N$:** observations 2, 5 give F, T. The node predicts F, with $\hat{p} = 1/2$.

For two classes the measures are

$$
\begin{align*}
E &= 1 - \max(\hat{p}, 1 - \hat{p}) \\
G &= 2\hat{p}(1 - \hat{p}) \\
D &= -\hat{p}\ln\hat{p} - (1 - \hat{p})\ln(1 - \hat{p})
\end{align*}
$$

| Node | $\hat{p}$ | Error rate | Gini | Cross-entropy |
|---|---|---|---|---|
| $X_1 < 21$ | 2/3 | 0.3333 | 0.4444 | 0.6365 |
| $X_2 = Y$ | 1/2 | 0.5 | 0.5 | 0.6931 |
| $X_2 = N$ | 1/2 | 0.5 | 0.5 | 0.6931 |
| **Sum** | | **1.3333** | **1.4444** | **2.0228** |

In the two pure 50/50 nodes the Gini index equals the error rate. In the first node Gini exceeds the error rate, so over the whole tree the sums are strictly ordered. Using $\log_2$ in the cross-entropy only makes it larger (2.918), and weighting the nodes by their size gives the same order.

$$
\text{cross-entropy} > \text{Gini index} > \text{classification error rate}
$$

The answer is **A**.
