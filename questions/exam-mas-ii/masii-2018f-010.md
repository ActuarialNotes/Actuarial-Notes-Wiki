Determine which of the following tests is not an appropriate alternative to the likelihood ratio tests of hypothesis for the parameters in a Linear Mixed Model.

- A) A $t$-test to test hypotheses about a single fixed-effect parameter.
- B) A Type I $F$-test to test for linear hypotheses about multiple fixed effects.
- C) A Type III $F$-test to test for linear hypotheses about multiple fixed effects.
- D) An omnibus Wald test to test linear hypotheses of the form $H_0\colon L\beta = 0$ vs. $H_A\colon L\beta \neq 0$.
- E) A Wald $z$-test to test for covariance parameters.

## Explanation

Likelihood ratio tests work for both kinds of parameter in a Linear Mixed Model. The question is which of the listed alternatives is *not* appropriate.

**A, B, C and D are standard alternatives for fixed effects.** A $t$-test handles a single fixed-effect parameter. Type I (sequential) and Type III (conditional) $F$-tests handle linear hypotheses involving several fixed effects. An omnibus Wald test of $H_0\colon L\beta = 0$ handles a general linear hypothesis on $\beta$ through a chi-square statistic.

**E is not appropriate.** The Wald $z$-test for a covariance parameter divides the estimate by its asymptotic standard error and refers the result to a standard normal distribution. That normal approximation needs very large samples for variance estimates, whose sampling distributions are skewed. It breaks down entirely when the null value lies on the boundary of the parameter space, as in testing whether a variance is 0. The likelihood ratio test, referred to a mixture of chi-square distributions, is recommended instead.

The answer is **E**.
