- locus: Explanation, B_40 formula and numeric block
- claim: B_40 = 1000(0.98)^40 (1-(0.98/1.0075)^20)/(1-0.98/1.0075) = ... /(0.0275/1.0075); (0.98)^40 = 0.44551; (0.98/1.0075)^20 = (0.97275)^20 = 0.57677; B_40 = 1000(0.44551)(1-0.57677)/0.02727 = 445.51 x 15.479 = 6889.
- evidence: SOA solution (solutions PDF p.75, image): B_40 = 1000(0.98)^40 [1-(0.98/1.0075)^20]/(0.0075+0.02) = 6889.11. Payments 41..60 are 1000(0.98)^(t-1) at t, so B_40 = 1000(0.98)^40 v (1-r^20)/(1-r) with r = 0.98/1.0075, = 1000(0.98)^40 (1-r^20)/0.0275. The page's denominator 1-r = 0.0275/1.0075 omits the factor v and values the payments as an annuity-due: it gives 6940.78, not 6889. Every figure below it is also off: 0.98^40 = 0.445700 (not 0.44551); 0.98/1.0075 = 0.972705 (not 0.97275); r^20 = 0.574937 (not 0.57677, and 0.97275^20 = 0.575473); 0.0275/1.0075 = 0.027295 (not 0.02727); (1-0.57677)/0.02727 = 15.520 (not 15.479); 445.51 x 15.479 = 6896.05 (not 6889). Key A (6889) is right; blind recomputation 6889.11 matches SOA.
