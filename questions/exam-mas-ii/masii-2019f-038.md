Given the following three statements about tree-based methods for regression and classification:

I. The main difference between bagging and random forests is the number of predictors used to build individual trees.
II. Single decision tree models generally have higher variance than random forest models.
III. Random forests provide an improvement over bagging because trees in a random forest are less correlated then those in bagged trees.

Determine which of the statements I, II, and III are true.

- A) I only
- B) II only
- C) III only
- D) I, II, and III
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

**I is true.** Both methods grow many trees on bootstrap resamples; what separates them is that a random forest considers only a random subset of $m$ predictors at each split, while bagging considers all $p$. Bagging is in fact the special case $m = p$.

**II is true.** A single tree is notoriously high-variance — change a few training points and the split structure can change completely. Averaging many trees is exactly the variance-reduction device, so the ensemble is far more stable.

**III is true, and it is the reason for I.** Under bagging, one dominant predictor tends to be chosen for the first split in almost every tree, so the trees look alike and averaging correlated trees reduces variance only slightly. Restricting the candidate predictors at each split forces trees to explore other structure, decorrelating them and making the average more effective.

All three statements are true, so the answer is **D**.
