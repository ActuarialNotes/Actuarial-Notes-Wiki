Given the following:

| Class | Earned Exposures | Reported Loss and ALAE | Current Relativity |
|---|---|---|---|
| A | 10,500 | \$512,000 | 1.00 |
| B | 5,200 | \$740,000 | 1.50 |
| C | 13,100 | \$632,000 | 1.30 |

- Full credibility standard is 13,260 exposures.
- Partial credibility is determined based on the square root rule.
- The complement of credibility is no change.

Calculate the indicated rate change for each class that results in a revenue-neutral overall change.

### Answer
Class A: -1.7%. Class B: +58.4%. Class C: -25.7%.

### Explanation
"Revenue-neutral" means the base rate does not move, so the class changes must average to zero across the book. The way to guarantee that is to keep every relativity on a **normalized** basis — divided by its own exposure-weighted average — at each step, so that the final relativities and the current relativities have the same average of 1.000 and the off-balance is built in rather than bolted on afterward.

**Step 1 — indicated relativities from pure premium.** Loss and ALAE per exposure, each class relative to the total:

$$\text{PP}_{\text{total}} = \frac{512{,}000 + 740{,}000 + 632{,}000}{10{,}500 + 5{,}200 + 13{,}100} = \frac{1{,}884{,}000}{28{,}800} = 65.4167$$

| Class | Pure premium | Indicated relativity |
|---|---|---|
| A | $512{,}000/10{,}500 = 48.76$ | $48.76/65.4167 = 0.7454$ |
| B | $740{,}000/5{,}200 = 142.31$ | $142.31/65.4167 = 2.1754$ |
| C | $632{,}000/13{,}100 = 48.24$ | $48.24/65.4167 = 0.7375$ |

**Step 2 — normalize the current relativities.** The indicated relativities above are normalized by construction (exposure-weighted average 1.000). The current relativities are not, so they must be rebased before they can serve as the complement:

$$\overline{R}_{\text{curr}} = \frac{10{,}500(1.00) + 5{,}200(1.50) + 13{,}100(1.30)}{28{,}800} = \frac{35{,}330}{28{,}800} = 1.2267$$

| Class | Current relativity | Normalized current relativity |
|---|---|---|
| A | 1.00 | $1.00/1.2267 = 0.8152$ |
| B | 1.50 | $1.50/1.2267 = 1.2228$ |
| C | 1.30 | $1.30/1.2267 = 1.0597$ |

The complement of credibility is "no change," which on this basis means the **normalized current** relativity — not 1.000, and not the raw current relativity.

**Step 3 — partial credibility by the square root rule.**

$$Z = \min\left(\sqrt{\frac{n}{13{,}260}},\, 1\right)$$

| Class | Exposures | $Z$ |
|---|---|---|
| A | 10,500 | $\sqrt{10{,}500/13{,}260} = 0.8899$ |
| B | 5,200 | $\sqrt{5{,}200/13{,}260} = 0.6262$ |
| C | 13,100 | $\sqrt{13{,}100/13{,}260} = 0.9939$ |

**Step 4 — credibility-weight.**

$$R^{cw} = Z \times R^{ind} + (1 - Z) \times R^{norm}_{\text{curr}}$$

| Class | Calculation | $R^{cw}$ |
|---|---|---|
| A | $0.8899(0.7454) + 0.1101(0.8152)$ | 0.7531 |
| B | $0.6262(2.1754) + 0.3738(1.2228)$ | 1.8193 |
| C | $0.9939(0.7375) + 0.0061(1.0597)$ | 0.7394 |

**Step 5 — renormalize, which is where revenue neutrality is imposed.** Credibility weighting has pulled the average off 1.000:

$$\overline{R}^{cw} = \frac{10{,}500(0.7531) + 5{,}200(1.8193) + 13{,}100(0.7394)}{28{,}800} = 0.9394$$

| Class | Normalized credibility-weighted relativity |
|---|---|
| A | $0.7531/0.9394 = 0.8017$ |
| B | $1.8193/0.9394 = 1.9367$ |
| C | $0.7394/0.9394 = 0.7871$ |

**Step 6 — the class changes.** Compare new against old **on the same basis** — normalized to normalized:

$$\text{Change} = \frac{R^{norm}_{\text{new}}}{R^{norm}_{\text{curr}}} - 1$$

| Class | Calculation | Indicated change |
|---|---|---|
| A | $0.8017/0.8152 - 1$ | **-1.7%** |
| B | $1.9367/1.2228 - 1$ | **+58.4%** |
| C | $0.7871/1.0597 - 1$ | **-25.7%** |

Check that this is revenue neutral: the exposure-weighted average of the new normalized relativities is 1.0000, exactly the average of the normalized current relativities, so total premium at an unchanged base rate is unchanged.

*Alternatively*, the same answers come out of comparing the new normalized relativities against the **raw** current relativities and then dividing out the off-balance. That gives raw changes of $0.8017/1.00 - 1 = -19.8\%$, $1.9367/1.50 - 1 = +29.1\%$ and $0.7871/1.30 - 1 = -39.5\%$, an average change of $1.0000/1.2267 - 1 = -18.5\%$, and

$$\text{Change with off-balance} = \frac{1 + \text{raw change}}{1 - 0.185} - 1$$

which reproduces -1.7%, +58.4% and -25.7%. The renormalization in Step 5 and the off-balance adjustment are the same operation applied at different points.

### Examiner Report
Candidates were expected to build class relativities from pure premium, credibility-weight them against the current relativities as the complement, and then off-balance the result so that the overall change is zero — recognizing that "no change" as the complement means the current relativity expressed on the same normalized basis as the indication.

Common errors included rebasing the indicated relativities to a weighted average but then using the *raw* current relativities as the complement; using 1.000 as the complement instead of the current relativity; comparing new relativities against old on inconsistent bases (one rebased, one raw), which corrupts every class change; and inverting the off-balance factor, which reverses the direction of the correction.
