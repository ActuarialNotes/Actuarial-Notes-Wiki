An insurance company with a book of business (Book A) has recently acquired a smaller book of business (Book B) in the same state and line of business. Given the following as of December 31, 2017:

**Book A — Reported Claims (\$000) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 55,000 | 92,000 | 112,500 | 123,700 |
| 2015 | 54,800 | 92,600 | 111,100 | |
| 2016 | 57,000 | 94,400 | | |
| 2017 | 62,600 | | | |

| Calendar Year | Book A Earned Premium (\$000) |
|---|---|
| 2014 | 175,200 |
| 2015 | 179,400 |
| 2016 | 182,800 |
| 2017 | 184,200 |

| | |
|---|---|
| 75% | Book A expected claims ratio |
| 1.06 | 48 to ultimate reported claim development factor |

**Book B — Reported Claims (\$000) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 2,600 | 5,900 | 6,700 | 7,500 |
| 2015 | 3,500 | 4,300 | 6,000 | |
| 2016 | 2,600 | 2,700 | | |
| 2017 | 4,400 | | | |

| Calendar Year | Book B Earned Premium (\$000) |
|---|---|
| 2014 | 8,700 |
| 2015 | 9,700 |
| 2016 | 11,000 |
| 2017 | 13,900 |

## Part a (0.75 point)

Calculate the Book A ultimate claims for accident year 2015 using the reported development technique.

### Answer

\$129,543 thousand

### Explanation

Only accident year 2014 has a 36–48 factor:

$$\text{LDF}_{36-48} = \frac{123{,}700}{112{,}500} = 1.100$$

$$\text{CDF}_{36-\text{ult}} = 1.100 \times 1.06 = 1.166$$

$$\text{Ultimate}_{2015} = 111{,}100 \times 1.166 = 129{,}543$$

### Examiner Report

Candidates were expected to calculate Book A ultimate claims for accident year 2015 using the reported development technique, including the age-to-age and cumulative development factors.

Common mistakes included developing an accident year other than 2015, omitting the 48-to-ultimate factor, and computing age-to-age factors from non-adjacent columns of the triangle.

## Part b (0.5 point)

Calculate the Book A ultimate claims for accident year 2016 using the Bornhuetter-Ferguson technique.

### Answer

\$134,394 thousand

### Explanation

Average the 24–36 factors:

$$\frac{112{,}500}{92{,}000} = 1.2230, \qquad \frac{111{,}100}{92{,}600} = 1.1998, \qquad \text{avg} = 1.2114$$

$$\text{CDF}_{24-\text{ult}} = 1.2114 \times 1.166 = 1.412$$

$$\% \text{ unreported} = 1 - \frac{1}{1.412} = 0.292$$

$$\text{Ultimate}_{2016} = 94{,}400 + \left[182{,}800 \times 0.75 \times 0.292\right] = 94{,}400 + 39{,}994 = 134{,}394$$

### Examiner Report

Candidates were expected to calculate accident year 2016 ultimate claims using the Bornhuetter-Ferguson technique, including the percent unreported and the expected claims.

Common mistakes included using an age-to-age factor rather than the cumulative development factor to derive the percent unreported, developing the wrong accident year, using the percent reported instead of the percent unreported, and calculating an expected claim ratio rather than using the 75% given.

## Part c (0.25 point)

Calculate the Book A ultimate claims for accident year 2017 using the expected claims technique.

### Answer

\$138,150 thousand

### Explanation

The expected claims technique ignores reported experience entirely:

$$\text{Ultimate}_{2017} = 0.75 \times 184{,}200 = 138{,}150$$

### Examiner Report

Candidates were expected to calculate ultimate claims using the expected claims technique.

A common error was calculating an expected claim ratio rather than using the given 75%.

## Part d (0.5 point)

Recommend an approach for estimating ultimate claims for Book B in accident year 2015 without performing any calculations. Justify all assumptions.

### Explanation

Book B is small and its development is volatile — the 12–24 factors swing from 2.27 (2014) to 1.23 (2015) to 1.04 (2016), so any technique that relies on Book B's own historical development pattern will produce an unstable and unreliable estimate.

**Recommendation:** apply a Bornhuetter-Ferguson technique to Book B using Book A's development pattern and Book A's expected claims ratio, applied to Book B's earned premium.

**Justification:** Book B is in the same state and the same line of business as Book A, so it is reasonable to assume the two books share a reporting pattern and a similar expected claims ratio. Book A is large enough for its development factors to be stable and credible. B-F is preferable to a straight development technique here because it limits the leverage that a volatile reported-to-date figure would otherwise have on the answer, while still giving weight to Book B's actual experience.

An acceptable alternative is to combine Books A and B into a single triangle, on the same same-state, same-line justification, so that Book B's data gains credibility from the larger volume.

### Examiner Report

Candidates were expected to recognize that Book B is small and volatile, so any development technique relying on Book B's own historical pattern is inappropriate, and to recommend and justify a specific alternative. Where the recommended technique borrowed from Book A, candidates were expected to state why Book A is appropriate — that A and B operate in the same state and line of business.

Common mistakes included recommending a technique built on Book B's own development pattern, giving a recommendation with no justification, using Book A without saying why Book A is appropriate, recommending an "appropriate" expected claims ratio for Book B without saying how it would be selected, and diagnosing a case reserve adequacy change and recommending a Berquist-Sherman adjustment.
