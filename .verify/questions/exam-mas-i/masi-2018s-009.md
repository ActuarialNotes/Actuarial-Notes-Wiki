## [F-001] Explanation says {1,3,5} is not a path set; it is a non-minimal path set
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-10-04T20:47Z/8861
- date: 2026-10-04
- severity: major
- status: open
- locus: Explanation, Statement III paragraph
- claim: Explanation: '{1,3,5} is not a path set at all (it does not connect left to right without 2 or 4), and it contains the path {1,5}, so it cannot be a minimal path set — incorrect.' The paragraph does not discuss {2,3,4} or the 'minimal cut set' half of Statement III.
- evidence: Official figure (CAS MAS-I Spring 2018 Q9, PDF p.13): component 1 runs from the left terminal to the top node, 5 from the top node to the right terminal, 2 left terminal to bottom node, 4 bottom node to right terminal, 3 joins top and bottom nodes. With 1 and 5 working the system works, so {1,3,5} (a superset of {1,5}) IS a path set, just not a minimal one; the clause 'does not connect left to right without 2 or 4' is false, and the same sentence's next clause ('contains the path {1,5}') contradicts it. Rausand, System Reliability Theory ch.3 slides (NTNU v0.1, 2015), p.14: 'Path set: A set of components of a structure that by functioning ensures that the structure is functioning'; p.15 lists non-minimal supersets ({1,2,4}, {1,2,3,5}) as path sets of the bridge. Rausand labels the bridge 1-4 upper, 2-5 lower, 3 bridge; relabelled to the CAS figure his minimal path sets {1,4},{2,5},{1,3,5},{2,3,4} become {1,5},{2,4},{1,3,4},{2,3,5} and his minimal cut sets {1,2},{4,5},{1,3,5},{2,3,4} (p.17) become {1,2},{4,5},{1,3,4},{2,3,5} — the explanation's two lists are right. The cut-set half of III is also left unargued: with 1,3,5 failed the path 2-4 still connects, so {1,3,5} is not a cut set (symmetrically {2,3,4}: 1-5 survives). Final verdict (III incorrect) and key B (= CAS key B) are unaffected.
- source_rank: 1
- proposed_action: Delete the false clause 'is not a path set at all (it does not connect left to right without 2 or 4), and it' (leaving '{1,3,5} contains the path {1,5}, so it cannot be a minimal path set'); a maintainer may add that {2,3,4} likewise contains {2,4}, and that neither set is a cut set because 2-4 (resp. 1-5) survives — the addition is authoring, not applied.
