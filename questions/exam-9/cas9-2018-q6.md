Assume the following:

- Portfolios A, B, and C are well-diversified.
- The market is influenced by just two factors, X and Y.

| Portfolio | Expected Return | $\beta_X$ | $\beta_Y$ |
|---|---|---|---|
| A | 15.0% | 1.0 | 0.50 |
| B | 7.5% | -0.1 | 0.25 |
| C | 13.5% | 0.3 | 0.75 |

## Part a (1.25 points)

Calculate the risk-free rate and risk premiums for factors X and Y.

### Explanation
Each well-diversified portfolio satisfies the two-factor model $E(r) = r_f + \beta_X\,x + \beta_Y\,y$, where $x$ and $y$ are the risk premiums for factors X and Y:

$$15\% = r_f + 1x + 0.5y$$

$$7.5\% = r_f - 0.1x + 0.25y$$

$$13.5\% = r_f + 0.3x + 0.75y$$

Solving algebraically: $r_f = 6\%$, $x = 5\%$, $y = 8\%$.

### Examiner Report
Candidates are expected to provide the factor model equation and correctly solve for the 3
unknowns.
The most common error was making an algebraic/calculation mistake.

## Part b (2.75 points)

Suppose there exists another well-diversified portfolio D with:

- $\beta_X = 0.2$
- $\beta_Y = 0.5$
- Expected return = 12%

Prove that an arbitrage opportunity exists, and construct a strategy to exploit the opportunity that returns \$10,000.

### Explanation
The factor model's expected return for portfolio D:

$$E(r_D) = 0.06 + 0.2(0.05) + 0.5(0.08) = 0.11 < 0.12$$

so an arbitrage opportunity exists.

Let $w_A$, $w_B$ and $w_C$ be the weights invested in A, B and C. To neutralize beta (match D's factor exposures):

$$w_A + w_B + w_C = 1$$

$$w_A - 0.1w_B + 0.3w_C = 0.2$$

$$0.5w_A + 0.25w_B + 0.75w_C = 0.5$$

Solving: $w_A = 1/9$, $w_B = w_C = 4/9$. Construct portfolio P by investing 1/9 in A, 4/9 in B and 4/9 in C:

$$\beta_{P,X} = \tfrac{1}{9}(1.0) + \tfrac{4}{9}(-0.1) + \tfrac{4}{9}(0.3) = 0.2$$

$$\beta_{P,Y} = \tfrac{1}{9}(0.5) + \tfrac{4}{9}(0.25) + \tfrac{4}{9}(0.75) = 0.5$$

$$E(r_P) = \tfrac{1}{9}(0.15) + \tfrac{4}{9}(0.075) + \tfrac{4}{9}(0.135) = 0.11$$

To return 10,000, the investment needed is $10{,}000 / 0.01 = 1\text{M}$. Short sell 1M of portfolio P and use the proceeds to invest in portfolio D, so that

$$\beta_X = -0.2 + 0.2 = 0, \qquad \beta_Y = -0.5 + 0.5 = 0$$

$$\text{Net return} = -0.11 + 0.12 = 0.01$$

Alternatively:

Portfolio D's betas are two-thirds of portfolio C's: $\beta_X = 0.2 = 0.3 \times 2/3$ and $\beta_Y = 0.5 = 0.75 \times 2/3$. Buy portfolio D and short sell a mix of 2/3 portfolio C and 1/3 risk-free:

$$\text{Expected return} = 12\% - \left(\tfrac{2}{3} \times 13.5\% + \tfrac{1}{3} \times 6\%\right) = 1\%$$

For a riskless return of 10,000, invest $10{,}000 / 0.01 = 1\text{M}$ in D, short sell $1\text{M} \times 2/3 = 666{,}667$ of portfolio C and borrow $1\text{M} \times 1/3 = 333{,}333$ at the risk-free rate.

### Examiner Report
Candidates are expected to identify the arbitrage opportunity by recognizing the mismatch between the outputs from the factor model and expected return provided on portfolio D. After that, candidates should create one of the 3 combinations of portfolio A, B and C that neutralize beta from portfolio D. Also, candidates will need to borrow and lend at risk free rate to ensure zero net investment with certain combinations. Lastly, candidates are expected to provide the dollar amount invested in the portfolio that returns \$10000.
Common mistakes included:

- Attempting to trade βx or βy directly
- Failing to create an arbitrage strategy with net zero investment by not borrowing/lending a risk free asset
