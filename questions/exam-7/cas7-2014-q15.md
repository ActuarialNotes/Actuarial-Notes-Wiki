A publicly traded insurer writes three product lines: workers compensation, commercial property, and commercial auto. The following table presents financial data (\$000) for the insurer for 2013.

| | Workers Compensation | Commercial Property | Commercial Auto |
|---|---|---|---|
| Earnings | 636 | 318 | 297 |
| Book Value | 8,350 | 5,860 | 2,210 |

Three peer companies have been selected for each product line. These peer companies are monoline insurers that operate in the associated product line only.

| Workers Compensation Peer | Price-Earnings Ratio |
|---|---|
| Peer 1 | 21.9 |
| Peer 2 | 18.5 |
| Peer 3 | 19.6 |

| Commercial Property Peer | Price-Earnings Ratio |
|---|---|
| Peer 1 | 16.4 |
| Peer 2 | 19.7 |
| Peer 3 | 17.9 |

| Commercial Auto Peer | Price-Earnings Ratio |
|---|---|
| Peer 1 | 13.9 |
| Peer 2 | 17.2 |
| Peer 3 | 14.8 |

Calculate the Price to Book Value ratio for the insurer based on relative valuation using multiples.

### Explanation
Value each product line with its peers' P-E ratio, sum the segments, and divide by the total book value.

**Mean peer P-E ratio by line:**

- WC: $(21.9 + 18.5 + 19.6)/3 = 20.0$
- CP: $(16.4 + 19.7 + 17.9)/3 = 18.0$
- CA: $(13.9 + 17.2 + 14.8)/3 = 15.3$

**Price of each segment** = P-E ratio × latest fiscal year earnings:

| Line | P-E Ratio | Earnings (\$000) | Price (\$000) |
|---|---|---|---|
| WC | 20.0 | 636 | 12,720 |
| CP | 18.0 | 318 | 5,724 |
| CA | 15.3 | 297 | 4,544 |
| Total | | | 22,988 |

Total book value $= 8{,}350 + 5{,}860 + 2{,}210 = 16{,}420$.

$$\text{Price to Book Value} = \frac{22{,}988}{16{,}420} = 1.40$$

Alternatively:

Use the median peer P-E ratio for each line — WC 19.6, CP 17.9, CA 14.8:

$$\text{Price} = 19.6 \times 636 + 17.9 \times 318 + 14.8 \times 297 = 12{,}466 + 5{,}692 + 4{,}396 = 22{,}554$$

$$\text{Price to Book Value} = \frac{22{,}554}{16{,}420} = 1.37$$

### Examiner Report
Candidates performed very well on average. Candidates needed to know how to value the firm using financial information from peer companies. Some candidates calculated the P-BV of each 3
lines separately and then summed them to get to the company P-BV.  A few others had difficulty figuring out how to use the data given (P/E ratios of competitors) to get to the P/BV of the firm.
