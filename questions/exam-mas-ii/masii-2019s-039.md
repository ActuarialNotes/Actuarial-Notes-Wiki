A boosted tree model is defined by:

- $\lambda = 0.2$
- The following four trees:

![Four decision trees. Tree 1 splits on X2 < 1 (left leaf 6.4); its right branch splits on X3 = Y, whose false side is leaf 4.83 and whose true side splits on X1 = Y into leaves 10 (true) and 3.14 (false). Tree 2 splits on X4 < 2.67 (left leaf 4.34); its right branch splits on X3 = Y, false side leaf 4.75, true side splits on X4 < 3 into leaf 6.67 (true) and a split on X7 < 8 giving 3.5 (true) and 8.81 (false). Tree 3 splits on X7 < 6.5; the true side splits on X1 = Y into a further X3 = Y split with leaves 8.1 and 6.3, and leaf 2.81; the false side splits on X3 = Y into an X4 < 2 split with leaves 7.41 and 14.1, and leaf 5.9. Tree 4 splits on X6 < 1 into leaves 0.34 and 5.89](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/masii-2019s-q39-boosted-trees.png)

You are given the following record:

| $X_1$ | $X_2$ | $X_3$ | $X_4$ | $X_5$ | $X_6$ | $X_7$ |
|---|---|---|---|---|---|---|
| N | 6 | Y | 4 | 0.5 | 0.25 | 6 |

Calculate the prediction of the boosted tree model for this record.

- A) Less than 2
- B) At least 2, but less than 5
- C) At least 5, but less than 8
- D) At least 8, but less than 11
- E) At least 11

## Explanation

A boosted model sums the individual trees, each shrunk by the learning rate $\lambda$:

$$
\hat{f}(x) = \lambda \sum_{b=1}^{B} \hat{f}^{\,b}(x)
$$

Drop the record down each tree in turn.

**Tree 1.** $X_2 = 6$, so $X_2 < 1$ is false → right. $X_3 = Y$ is true → left. $X_1 = N$, so $X_1 = Y$ is false → right: **3.14**

**Tree 2.** $X_4 = 4$, so $X_4 < 2.67$ is false → right. $X_3 = Y$ is true → left. $X_4 < 3$ is false → right. $X_7 = 6$, so $X_7 < 8$ is true → left: **3.5**

**Tree 3.** $X_7 = 6$, so $X_7 < 6.5$ is true → left. $X_1 = Y$ is false → right: **2.81**

**Tree 4.** $X_6 = 0.25$, so $X_6 < 1$ is true → left: **0.34**

$$
\begin{align*}
\hat{f}(x) &= 0.2\,(3.14 + 3.5 + 2.81 + 0.34) \\
           &= 0.2\,(9.79) \\
           &= 1.958
\end{align*}
$$

This is less than 2, so the answer is **A**.
