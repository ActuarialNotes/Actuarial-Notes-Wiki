An actuary wants to cluster six workers compensation classes based on excess ratios at two limits: 750,000 and 1,500,000. The actuary decides to use a weighted k-means algorithm with three clusters. Given the following:

| Class | On-Leveled Earned Premium | Normalized Excess Ratio at 750,000 Limit | Normalized Excess Ratio at 1,500,000 Limit | Initial Cluster |
|---|---|---|---|---|
| 1 | 7,000,000 | 0.250 | 0.095 | A |
| 2 | 8,000,000 | 0.200 | 0.080 | B |
| 3 | 7,500,000 | 0.170 | 0.062 | C |
| 4 | 6,000,000 | 0.130 | 0.048 | A |
| 5 | 5,000,000 | 0.450 | 0.217 | A |
| 6 | 8,500,000 | 0.240 | 0.098 | B |

- At the start of the algorithm, the actuary randomly assigned each class to a cluster.
- The actuary has observed that the 750,000 limit is selected by the insured 75% of the time, consistent across all six classes.

Briefly justify which measure to use to calculate the distance between vectors and using that measure, determine the cluster for each class after the first iteration of the weighted k-means algorithm.

### Explanation
**Choosing the measure.** Either measure could be justified.

- Recommend $L^1$: class 5 looks to be an outlier, and $L^2$ will penalize this outlier more; or, the selection of limit being consistent across classes means that $L^1$ can be used. $L^1$ minimizes absolute (or relative) error.
- Recommend $L^2$: class 5 is not enough to be considered an outlier, so it is okay to use $L^2$ (or: the limits are not equally likely to be selected by insureds, so $L^1$ error is not minimized). $L^2$ minimizes the mean square error, or variance between clusters; it is the more traditional approach, the paper finds it makes no significant difference, and it better reflects a skewed distribution.

**Centroids of the initial clusters**, weighting each class by its on-leveled earned premium (in thousands):

$$R_A(750\text{K}) = \frac{7000(0.25) + 6000(0.13) + 5000(0.45)}{7000 + 6000 + 5000} = 0.266 \qquad R_A(1.5\text{M}) = \frac{7000(0.095) + 6000(0.048) + 5000(0.217)}{7000 + 6000 + 5000} = 0.113$$

$$R_B(750\text{K}) = \frac{8000(0.2) + 8500(0.24)}{8000 + 8500} = 0.221 \qquad R_B(1.5\text{M}) = \frac{8000(0.08) + 8500(0.098)}{8000 + 8500} = 0.089$$

$$R_C(750\text{K}) = 0.17 \qquad R_C(1.5\text{M}) = 0.062$$

**Distances and new clusters** using the $L^1$ measure with even weights by limit — for class 1 to $R_A$, $|0.25 - 0.266| + |0.095 - 0.113| = 0.034$. Each class moves to its nearest centroid:

| Class | Distance to $R_A$ | Distance to $R_B$ | Distance to $R_C$ | New Cluster |
|---|---|---|---|---|
| 1 | 0.034 | 0.035 | 0.113 | A |
| 2 | 0.099 | 0.030 | 0.048 | B |
| 3 | 0.147 | 0.078 | 0.000 | C |
| 4 | 0.201 | 0.132 | 0.054 | C |
| 5 | 0.288 | 0.357 | 0.435 | A |
| 6 | 0.041 | 0.028 | 0.106 | B |

Alternatively, using the $L^2$ measure with even weights — for class 1 to $R_A$, $\left[(0.25 - 0.266)^2 + (0.095 - 0.113)^2\right]^{1/2} = 0.024$:

| Class | Distance to $R_A$ | Distance to $R_B$ | Distance to $R_C$ | New Cluster |
|---|---|---|---|---|
| 1 | 0.024 | 0.030 | 0.087 | A |
| 2 | 0.074 | 0.023 | 0.035 | B |
| 3 | 0.109 | 0.058 | 0.000 | C |
| 4 | 0.151 | 0.100 | 0.042 | C |
| 5 | 0.211 | 0.262 | 0.320 | A |
| 6 | 0.030 | 0.021 | 0.079 | B |

The sample answers also weight the two limits 75/25, by how often each is selected — for class 1 to $R_A$, $|0.75(0.25 - 0.266)| + |0.25(0.095 - 0.113)| = 0.016$ under $L^1$ and $\left[0.75(0.25 - 0.266)^2 + 0.25(0.095 - 0.113)^2\right]^{1/2} = 0.016$ under $L^2$. The distances shrink, but every class lands in the same cluster: classes 1 and 5 in A, classes 2 and 6 in B, classes 3 and 4 in C.

### Examiner Report
The candidates were expected to explain which distance measure should be used and how to calculate the means square error and clustering process.

Common mistakes included:

- Not adequately explaining which measure to use
- Not taking the square root for L2
- Explaining the choice to weight with 75/25 rather than explaining the choice of L1 or L2
- Weighting the centroids together and then weighting the distance together:
mathematically this gives the same answer when using L1 measure but does not make sense when using the L2 measure as it is simply the difference in this case
- Using only one limit instead of both limits to measure distance
- Not calculating all classes and not fully explaining how to compare the distances that weren't calculated.
