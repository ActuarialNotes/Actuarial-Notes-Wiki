Given the following information:

| Accident Year | Incremental Paid Loss 0-12 (\$000) | Incremental Paid Loss 12-24 (\$000) | Incremental Paid Loss 24-36 (\$000) | Premium (\$000) |
|---|---|---|---|---|
| 2010 | 1,400 | 650 | 280 | 3,600 |
| 2011 | 1,000 | 850 | | 3,700 |
| 2012 | 1,500 | | | 3,650 |
| Total | 3,900 | 1,500 | 280 | 10,950 |

Assume that there is no further development beyond 36 months.

## Part a (2 points)

Calculate the individual loss ratio claims reserve $R^{\text{ind}}$ for the total of accident years 2010 through 2012.

### Explanation
$$R^{ind} \text{ for total (2010-2012)} = \sum q_i / p_i \times C_i$$

$$m_k = \frac{sum(loss\ @\ dev\ age\ i)}{sum(Premium)}$$

$$m_{0\text{-}12} = \frac{1400+1000+1500}{3600+3700+3650} = 0.356$$

$$m_{12\text{-}24} = \frac{650+850}{3600+3700} = 0.205$$

$$m_{24\text{-}36} = \frac{280}{3600} = 0.078$$

$$p_i = \frac{\sum m_i \text{ to date}}{\sum m_i}$$

$$p_{2010} = \frac{0.356+0.205+0.078}{0.356+0.205+0.078} = 1.000$$

$$p_{2011} = \frac{0.356+0.205}{0.356+0.205+0.078} = 0.878$$

$$p_{2012} = \frac{0.356}{0.356+0.205+0.078} = 0.557$$

$q_i = 1 – p_i$

$q_{2010} = 1 – 1 = 0$

$q_{2011} = 1 – 0.878 = 0.122$

$q_{2012} = 1 – 0.557 = 0.443$

$C_i = \sum$paid losses to date

$C_{2010}$ = 1,400 + 650 + 280 = 2,330

$C_{2011}$ = 1,000 + 850 = 1,850

$C_{2012}$ = 1,500

$R^{ind}_{2010}$ = 0/1 × 2,330 = 0

$R^{ind}_{2011}$ = 0.122/0.878 × 1,850 = 256

$R^{ind}_{2012}$ = 0.443/0.557 × 1,500 = 1,193

$R^{ind}_{Total}$ = 0 + 256 + 1,193 = 1,449

Alternatively:

$$R^{ind} \text{ for total (2010-2012)} = \sum q_i / p_i \times C_i$$

$$m_k = \frac{sum(loss\ @\ dev\ age\ i)}{sum(Premium)}$$

$$m_{0\text{-}12} = \frac{1400+1000+1500}{3600+3700+3650} = 0.356$$

$$m_{12\text{-}24} = \frac{650+850}{3600+3700} = 0.205$$

$$m_{24\text{-}36} = \frac{280}{3600} = 0.078$$

$$p_i = \frac{\sum m_i \text{ to date}}{\sum m_i}$$

$$p_{2010} = \frac{0.356+0.205+0.078}{0.356+0.205+0.078} = 1.000$$

$$p_{2011} = \frac{0.356+0.205}{0.356+0.205+0.078} = 0.878$$

$$p_{2012} = \frac{0.356}{0.356+0.205+0.078} = 0.557$$

$q_i = 1 – p_i$

$q_{2010} = 1 – 1 = 0$

$q_{2011} = 1 – 0.878 = 0.122$

$q_{2012} = 1 – 0.557 = 0.443$

$C_i = \sum$paid losses to date

$C_{2010}$ = 1,400 + 650 + 280 = 2,330

$C_{2011}$ = 1,000 + 850 = 1,850

$C_{2012}$ = 1,500

$R^{ind}_{2010}$ = 2,330 / 1.00 – 2,330 = 0

$R^{ind}_{2011}$ = 1,850 / .878 – 1,850 = 256

$R^{ind}_{2012}$ = 1,500/.557 – 1,500 = 1,193

$R^{ind}_{Total}$ = 0 + 256 + 1,193 = 1,449

### Examiner Report
Several candidates used a standard paid loss development method instead of calculating the individual loss ratio claims reserve Rind as requested.  Another common mistake was miscalculating the mk's using the total earned premium for all accident years.  Another common mistake was candidates misidentifying Rind as Rcoll, and vice versa.  Candidates making these mistakes did not receive full credit.

## Part b (0.75 points)

Calculate the collective loss ratio claims reserve $R^{\text{coll}}$ for the total of accident years 2010 through 2012.

### Explanation
Process variance = $\sigma^2 \sum_i R_i$ = 10000(2032979) (as printed)

Process SD = √(P Variance) = 142,582.56 (as printed)

$R^{coll}$ for total = $q_i \times U^{BC}_i = q_i \times m_{total} \times V_i$

$R^{coll}_1$ = (0 × .639) × 3,600 = 0

$R^{coll}_2$ = (.122 ×.639) × 3,700 = 288

$R^{coll}_3$ = (.443 × .639) × 3,650 = 1,034

$R^{coll}_{Total}$ = 0 + 288 +1034 = 1,322

Alternatively:

$U^{BC}_i$ = Premium × ELR = $V_i \times \sum m_i$

$U^{BC}_{2010}$ = 3,600 × (0.356+0.205+0.078) = 2,302

$U^{BC}_{2011}$ = 3,700 × (0.356+0.205+0.078) = 2,366

$U^{BC}_{2012}$ = 3,650 × (0.356+0.205+0.078) = 2,334

$R^{coll}_1$ = 0 × 2,302 = 0

$R^{coll}_2$ = .122 × 2,366= 288

$R^{coll}_3$ = .443 × 2,334 = 1,034

$R^{coll}_{Total}$ = 0 + 288 +1,034 = 1,322

Alternatively:

$R^{coll}_1$ = 0 = (63.9% - 35.6% - 20.5% -7.8%) × 3,600

$R^{coll}_2$ = 288 = (63.9% - 35.6% - 20.5%) × 3,700

$R^{coll}_3$ = 1,034 = (63.9% - 35.6%) × 3,650

$R^{coll}_{Total}$ = 1,322
