A training data set contains eight observations for two predictor variables, $X_1$ and $X_2$, and a response variable, Y. The response Y has three possible classes P, N, and U.

| i | $X_1$ | $X_2$ | Y | Distance from $(x_{1i}, x_{2i})$ to (3, 2) |
|---|---|---|---|---|
| 1 | 4.1 | 3.0 | P | 1.5 |
| 2 | -2.6 | -3.0 | N | 7.5 |
| 3 | -1.1 | 1.3 | U | 4.2 |
| 4 | 0.0 | 1.2 | U | 3.1 |
| 5 | -3.0 | -5.0 | N | 9.2 |
| 6 | 2.0 | 2.0 | U | 1.0 |
| 7 | -3.1 | -2.0 | N | 7.3 |
| 8 | 3.2 | 3.1 | P | 1.1 |

Three models are constructed using K-Nearest Neighbors and the data set above to predict Y for the two-dimensional space of predictors $X_1$ and $X_2$.

- Model I: K-Nearest Neighbors with K=1.
- Model II: K-Nearest Neighbors with K=3.
- Model III: K-Nearest Neighbors with K=7.

Each model is used to classify the point (3, 2).

Determine the predicted response Y at this point using each of the three models.

- A) Model I: Y = P, Model II: Y = P, Model III: Y = P
- B) Model I: Y = P, Model II: Y = P, Model III: Y = U
- C) Model I: Y = U, Model II: Y = P, Model III: Y = P
- D) Model I: Y = U, Model II: Y = P, Model III: Y = U
- E) The answer is not given by (A), (B), (C), or (D).

## Explanation

K-nearest neighbors classifies the point by majority vote among the $K$ training observations closest to it. The distances to $(3, 2)$ are given, so order the observations by distance:

| Rank | $i$ | Distance | Y |
|---|---|---|---|
| 1 | 6 | 1.0 | U |
| 2 | 8 | 1.1 | P |
| 3 | 1 | 1.5 | P |
| 4 | 4 | 3.1 | U |
| 5 | 3 | 4.2 | U |
| 6 | 7 | 7.3 | N |
| 7 | 2 | 7.5 | N |
| 8 | 5 | 9.2 | N |

**Model I ($K = 1$):** the single nearest point is observation 6, so Y = U.

**Model II ($K = 3$):** the three nearest are U, P, P. P wins 2 to 1, so Y = P.

**Model III ($K = 7$):** every point except observation 5. The votes are U: 3 (observations 6, 4, 3), P: 2 (observations 8, 1) and N: 2 (observations 7, 2), so Y = U.

U, P, U, so the answer is **D**.
