A profile of the investments owned by an agent's clients follows:

- (i) 228 own annuities.
- (ii) 220 own mutual funds.
- (iii) 98 own life insurance and mutual funds.
- (iv) 93 own annuities and mutual funds.
- (v) 16 own annuities, mutual funds, and life insurance.
- (vi) 45 more clients own only life insurance than own only annuities.
- (vii) 290 own only one type of investment (i.e., annuity, mutual fund, or life insurance).

Calculate the agent's total number of clients who own at least one of these three insurance products.

- A) 455
- B) 495
- C) 496
- D) 500
- E) 516

## Explanation

Let: only A = $a$, only M = $m$, only L = $l$, only A\&M = $p_{am}$, only A\&L = $p_{al}$, only L\&M = $p_{lm}$, all = 16.

From (iv): $p_{am} + 16 = 93 \Rightarrow p_{am} = 77$. From (iii): $p_{lm} + 16 = 98 \Rightarrow p_{lm} = 82$.
From (i): $a + 77 + p_{al} + 16 = 228 \Rightarrow a + p_{al} = 135$.
From (ii): $m + 77 + 82 + 16 = 220 \Rightarrow m = 45$.
From (vii): $a + 45 + l = 290 \Rightarrow a + l = 245$.
From (vi): $l - a = 45$.

Solving: $2l = 290 \Rightarrow l = 145$, $a = 100$, $p_{al} = 35$.

$$
\begin{align*}
\text{Total} &= 100 + 45 + 145 + 77 + 35 + 82 + 16 \\
             &= \mathbf{500}
\end{align*}
$$
