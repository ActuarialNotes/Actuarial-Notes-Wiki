Given the following data as of December 31, 2017:

**Cumulative Reported Claims (\$000s) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 3,002 | 3,585 | 3,857 | 4,020 |
| 2015 | 3,440 | 4,107 | 4,522 |  |
| 2016 | 3,427 | 4,109 |  |  |
| 2017 | Not Provided |  |  |  |

**Cumulative Reported Claim Counts as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 940 | 975 | 980 | 980 |
| 2015 | 1,060 | 1,103 | 1,106 |  |
| 2016 | 1,053 | 1,095 |  |  |
| 2017 | 1,085 |  |  |  |

**Reported Claims Age-to-Age Factors**

| Accident Year | 12-24 | 24-36 | 36-48 |
|---|---|---|---|
| 2014 | 1.194 | 1.076 | 1.042 |
| 2015 | 1.194 | 1.101 |  |
| 2016 | 1.199 |  |  |

**Reported Claim Count Age-to-Age Factors**

| Accident Year | 12-24 | 24-36 | 36-48 |
|---|---|---|---|
| 2014 | 1.037 | 1.005 | 1.000 |
| 2015 | 1.041 | 1.003 |  |
| 2016 | 1.040 |  |  |

|  |  |
|---|---|
| 5% | Claim severity trend |
| 30% | Claim severity reduction due to tort reform on claims occuring on or after January 1, 2017 |

- The tort reform has no effect on claim reporting.
- There is no claim development after 48 months.

Estimate ultimate claims for accident year 2017 using a frequency-severity technique.

### Explanation
**Ultimate claim counts.** Simple-average claim count development factors: 12–24 $= (1.037 + 1.041 + 1.040)/3 = 1.0392$; 24–36 $= (1.005 + 1.003)/2 = 1.0039$; 36–48 $= 1.000$; no development after 48 months.

$$\text{AY 2017 ultimate counts} = 1{,}085 \times 1.0392 \times 1.0039 = 1{,}085 \times 1.0433 = 1{,}132.0$$

The tort reform does not affect reporting, so the counts are developed as usual.

**Severities.** Severity = reported claims ÷ reported counts (claims are in thousands):

| AY | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 3,193.6 | 3,676.9 | 3,935.7 | 4,102.0 |
| 2015 | 3,245.3 | 3,723.5 | 4,088.6 | |
| 2016 | 3,254.5 | 3,752.5 | | |

Severity development factors (simple averages): 24–36 $= (1.0704 + 1.0981)/2 = 1.0842$; 36–48 $= 1.0423$. Developing each year and trending at 5% to the 2017 accident year:

| AY | Latest severity | Factor to ultimate | Ultimate severity | Trend to 2017 | Trended severity |
|---|---|---|---|---|---|
| 2014 | 4,102.0 | 1.0000 | 4,102.0 | 1.05³ | 4,748.6 |
| 2015 | 4,088.6 | 1.0423 | 4,261.4 | 1.05² | 4,698.2 |
| 2016 | 3,752.5 | 1.0842 × 1.0423 = 1.1301 | 4,240.5 | 1.05 | 4,452.5 |

Selected 2017 severity before tort reform: the average, 4,633.1. Tort reform cuts severity by 30% for claims occurring on or after January 1, 2017 — all of accident year 2017:

$$4{,}633.1 \times (1 - 0.30) = 3{,}243.2$$

**Ultimate claims.**

$$\text{AY 2017 ultimate claims} = 1{,}132.0 \times 3{,}243.2 = 3{,}671{,}000$$

That is about 3,671 in the triangle's \$000s.

### Examiner Report
Candidates were expected to apply a frequency-severity technique by developing claim counts and severities, applying trend, and accounting for changes due to tort reform

Common errors for claim counts included:

- Applying age-to-age factors instead of age-to-ultimate factors.
- Using average claim counts from prior years.
Common errors for severities included:

- Using reported claims triangle factors instead of severity factors or backing into severity from ultimate claims and ultimate claim counts. Using this severity and multiplying back ultimate counts returns the reported development technique and is not actually a frequency severity technique.
- Only developing a single year rather than all periods.
Other common errors included:

- Applying trend factors in the triangles rather than to developed severities.
- Not applying tort reform factors or applying them incorrectly.
- Basing ultimate claims on calculations that were not frequency-severity or using undeveloped claim counts.
