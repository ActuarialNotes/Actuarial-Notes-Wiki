An actuary has a dataset with one dependent variable, Y, and five independent variables $(X_1, X_2, X_3, X_4, X_5)$. She is trying to determine which subset of the predictors best fits the data, and is using a Forward Stepwise Selection procedure with no stopping rule. Below is a subset of the potential models:

| Model | Dependent variable | RSS | Independent variable | p-value |
|:-:|:-:|:-:|:-:|:-:|
| 1 | Y | 9,823 | $X_1$ | 0.0430 |
| | | | $X_2$ | 0.0096 |
| 2 | Y | 7,070 | $X_1$ | 0.0464 |
| | | | $X_2$ | 0.0183 |
| | | | $X_3$ | 0.0456 |
| 3 | Y | 6,678 | $X_1$ | 0.0412 |
| | | | $X_2$ | 0.0138 |
| | | | $X_4$ | 0.0254 |
| 4 | Y | 4,800 | $X_1$ | 0.0444 |
| | | | $X_2$ | 0.0548 |
| | | | $X_5$ | 0.0254 |
| 5 | Y | 3,475 | $X_1$ | 0.0333 |
| | | | $X_2$ | 0.0214 |
| | | | $X_3$ | 0.0098 |
| | | | $X_4$ | 0.0274 |
| | | | $X_5$ | 0.0076 |

The procedure just selected Model 1 as the new candidate model.

Determine which of the following independent variable(s) will be added to the model in the next iteration of this procedure.

- A) No variables will be added
- B) $X_3$ only
- C) $X_4$ only
- D) $X_5$ only
- E) $X_3$, $X_4$ and $X_5$

## Explanation

Forward stepwise selection grows the model one variable at a time. From the current model it fits every model that adds one of the unused predictors and keeps the one that fits best. Those candidates all have the same size, so best means the lowest RSS. The p-values play no part in the choice, and with no stopping rule the procedure keeps going until every predictor is in.

The current model is Model 1, with $X_1$ and $X_2$. The candidates that add exactly one variable are:

- Model 2, adding $X_3$: RSS 7,070
- Model 3, adding $X_4$: RSS 6,678
- Model 4, adding $X_5$: RSS 4,800

Model 5 adds three variables at once, so it is not a candidate for the next step.

Model 4 has the lowest RSS, so $X_5$ is added next. It does not matter that $X_2$'s p-value in Model 4 is 0.0548, above 5%, because significance does not enter the forward step. The answer is **D**.
