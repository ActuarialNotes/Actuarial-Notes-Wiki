When a commercial building's policy began, its limit was exactly 80% of the building's value, with an 80% coinsurance clause. Construction costs then rose 10% before a partial fire loss in the tenth month. Which statement about the coinsurance clause is correct?

- A) A penalty applies, because the requirement uses the value at the time of loss
- B) No penalty applies, because the requirement was met when the policy began
- C) No penalty applies, because an 80% clause never penalizes a partial loss
- D) A penalty applies only if the loss is larger than the limit of insurance

## Explanation

The coinsurance requirement is tested against the property's value at the time of the loss. With costs up 10%, 80% of the current value exceeds the limit, so the insurer pays only the share of each partial loss that the limit bears to the requirement. An inflation guard option or an agreed value would have avoided it. The answer is **A**.

**Why not the others**

- **B** — value at inception is not the test.
- **C** — the penalty matters precisely for partial losses; on a total loss the insurer pays the limit either way.
- **D** — reverses the logic: a loss above the limit is capped by the limit whatever the coinsurance result.
