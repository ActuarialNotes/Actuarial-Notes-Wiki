## [F-001] Governance claim says "reproduced" where the sources say "understand" or "assess"
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-10-10T21:00Z/dv01
- date: 2026-10-10
- severity: minor
- status: open
- locus: Standards bullet
- claim: '[[Model Governance|model governance]] frameworks require the data behind a model to be documented well enough that the model can be reproduced'
- evidence: SR 11-7 (sha256:0046c0e4eb705830d43312da000271655000beb2a349e1cc3802815638c62cc0) asks for 'rigorous assessment of data quality and relevance, and appropriate documentation' and documentation 'sufficiently detailed so that parties unfamiliar with a model can understand how the model operates, its limitations, and its key assumptions'; ASOP No. 56 §3.7 (sha256:f3e159300fde3ff3f9db4198eb6b0a660f182875b2cc47a2da92c2567b7bd799, PDF p.15) asks for documentation 'in a form such that another actuary qualified in the same practice area could assess the reasonableness of the actuary's work'. Neither requires that the model can be reproduced, and 'reproduce' does not occur in ASOP 56.
- source_rank: 3
- proposed_action: Replace 'well enough that the model can be reproduced' with the sources' standard: understood by someone unfamiliar with the model (SR 11-7) / assessed by another qualified actuary (ASOP 56 §3.7).
- applied: false
