Given the following for a policy:

- Basic Limit = 100,000
- Expected Basic Limit Indemnity = 65,000
- Allocated Loss Adjustment Expense (ALAE) = 20% of Indemnity
- Unallocated Loss Adjustment Expense = 1.5% of Indemnity and ALAE
- All other expenses are variable and are 15% of the premium
- Risk load = 0%
- Profit load = 2.5%
- The following table shows Indemnity-only limited expected severity:

| Limit L | E[X; L] |
|---|---|
| 100,000 | 58,750 |
| 200,000 | 100,000 |
| 500,000 | 156,250 |
| 1,000,000 | 218,750 |

Calculate the premium for this policy with a 500,000 limit over a 500,000 deductible.

### Explanation
The layer 500,000 excess of 500,000 is the difference between the 1,000,000 and 500,000 increased limits factors:

$$ILF(500\text{K}) = \frac{156{,}250}{58{,}750} = 2.6596 \qquad ILF(1\text{M}) = \frac{218{,}750}{58{,}750} = 3.7234$$

$$\text{Expected losses} = 65{,}000 \times (3.7234 - 2.6596) = 69{,}149$$

Load ALAE (20%) and ULAE (1.5% of indemnity and ALAE), and gross up for the variable expenses and the profit load:

$$\text{Premium} = \frac{69{,}146 \times 1.2 \times 1.015}{1 - 0.15 - 0.025} = 102{,}089$$

(69,146 as printed; the line above gives 69,149)

Alternatively, since the question does not say the profit load is a percentage of premium, it can be taken as proportional to loss and LAE. The basic limit premium is then

$$\frac{65{,}000 \times 1.2 \times 1.015 \times 1.025}{1 - 0.15} = 95{,}470$$

and the layer premium is $95{,}470 \times (3.723 - 2.660) = 101{,}564$.

The report also accepted treating ALAE and ULAE as a percent of ground-up losses: $\text{ALAE} = 20\% \times 65\text{k} \times 218{,}750/58{,}750 = 48{,}404$, $\text{ULAE} = 1.5\% \times [65\text{k} \times 218{,}750/58{,}750 \times (1 + 20\%)] = 4{,}356$, and

$$\text{Premium} = \frac{69{,}149 + 48{,}404 + 4{,}356}{1 - 15\% - 2.5\%} = 147{,}769$$

### Examiner Report
Candidates were expected to calculate ILFs using the correct expected severity from the given table and use the other information to calculate the premium of the policy.
As the question did not specify the profit as a percentage of premium, candidates assuming the profit as a percentage of loss also received credit. Candidates also received credit by assuming the ALAE and ULAE were a percent of ground-up losses.

Common mistakes included:

- Mistaking layer severity as layer loss cost
- Calculating ULAE as percentage of loss instead of loss and ALAE.
