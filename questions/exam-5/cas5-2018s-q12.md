Given the following information for an insurance company:

| Class | Earned Exposures | Reported Loss and ALAE | Number of Claims | Current Relativity | True Relativity |
|---|---|---|---|---|---|
| A | 15,271 | \$864,000 | 924 | 1.00 | 1.00 |
| B | 7,250 | \$732,000 | 623 | 1.10 | 1.73 |
| C | 10,532 | \$505,000 | 185 | 1.80 | 0.72 |

|  |  |
|---|---|
| 18,000 | Full credibility standard for number of earned exposures |

- Partial credibility is determined based on the square root rule.
- Complement of credibility is equal to normalized current class relativities.
- Class A remains the base class.

## Part a (2 points)

Calculate the indicated rate change for each class to achieve a revenue-neutral overall change.

### Explanation
**Pure premiums and indicated relativities.** Each class's pure premium is compared with the all-class pure premium:

$$\text{All classes: } \frac{2{,}101{,}000}{33{,}053} = 63.56$$

| Class | Pure premium | Indicated relativity (to total) |
|---|---|---|
| A | 864,000 / 15,271 = 56.58 | 0.8901 |
| B | 732,000 / 7,250 = 100.97 | 1.5884 |
| C | 505,000 / 10,532 = 47.95 | 0.7543 |

**Complement: normalized current relativities.** The exposure-weighted average current relativity is $(15{,}271 \times 1.00 + 7{,}250 \times 1.10 + 10{,}532 \times 1.80) / 33{,}053 = 1.2768$, so the normalized current relativities are A 0.7832, B 0.8615, C 1.4097.

**Credibility** by the square root rule, $Z = \sqrt{E/18{,}000}$:

| Class | $Z$ | Credibility-weighted relativity | Rebased to A |
|---|---|---|---|
| A | $\sqrt{15{,}271/18{,}000} = 0.9211$ | 0.9211 × 0.8901 + 0.0789 × 0.7832 = 0.8816 | 1.0000 |
| B | $\sqrt{7{,}250/18{,}000} = 0.6346$ | 0.6346 × 1.5884 + 0.3654 × 0.8615 = 1.3228 | 1.5004 |
| C | $\sqrt{10{,}532/18{,}000} = 0.7649$ | 0.7649 × 0.7543 + 0.2351 × 1.4097 = 0.9084 | 1.0303 |

**Revenue-neutral rate changes.** Changing relativities alone would change total premium, so an off-balance factor restores it:

$$\text{Off-balance} = \frac{\sum E \times \text{current}}{\sum E \times \text{proposed}} = \frac{42{,}203.6}{15{,}271 \times 1.0000 + 7{,}250 \times 1.5004 + 10{,}532 \times 1.0303} = \frac{42{,}203.6}{37{,}000.5} = 1.1406$$

$$\text{Rate change} = \frac{\text{proposed relativity}}{\text{current relativity}} \times 1.1406 - 1$$

| Class | Rate change |
|---|---|
| A | 1.0000 / 1.00 × 1.1406 - 1 = +14.1% |
| B | 1.5004 / 1.10 × 1.1406 - 1 = +55.6% |
| C | 1.0303 / 1.80 × 1.1406 - 1 = -34.7% |

### Examiner Report
Candidates were expected to perform the pure premium method for class relativities. The mechanics associated with this method and the underlying assumptions were key to being able to execute the calculation and explain the limitations and adjustments.

Candidates were expected to calculate the indicated rate change for each class that achieves a revenue neutral overall change. This included calculating the pure premium, calculating and using the correct credibility formula and off-balance to obtain the percentage rate changes or rate change factors by class.

Common errors included:

- Using severity instead of pure premium.
- Using claim count instead of earned exposures.
- Not normalizing the relativities.
- Calculating the wrong off-balance factor.

## Part b (0.25 points)

Briefly describe one possible reason why the indicated relativities do not match the true relativities.

### Explanation
The pure premium method assumes the exposures in each class are uniformly distributed across the other rating variables. If they are not — for example, if class C is concentrated in low-risk territories — the class's pure premium also reflects the effect of those other variables, so the indicated relativities double-count it (distributional bias) and do not match the true relativities.

### Examiner Report
Candidates were expected to understand that the pure premium approach assumes a uniform distribution across all other rating variables which could result in a distributional bias. Candidates were expected to describe a reason why the indicated relativities may not match the true relativities..

A common error was not answering the question asked and instead describing a reason why the actuary may select or choose relativities different than what was indicated, such as:

- Using competitive environment as the reason.
- Using regulatory environment as the reason.
- Mentioning the actuary calculated the indicated relativity wrong.
- Using industry data as the credibility complement.

## Part c (0.25 points)

Briefly explain an adjustment to the univariate pure premium method to improve its result.

### Explanation
Use the **adjusted pure premium** approach: divide each class's losses by exposures adjusted by the exposure-weighted average relativity of the other rating variables, rather than by raw exposures. This removes much of the distributional bias that arises when exposures are unevenly spread across the other variables.

### Examiner Report
Candidates were expected to know that the pure premium method can be performed using exposures adjusted by the exposure weighted average relativity of the other rating variables.

Common errors included:

- Using the GLM, Multivariate, or loss ratio method (while appropriate methods, this does not answer the question).
