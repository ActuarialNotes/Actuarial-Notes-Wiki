## Part a (3 points)

Using a 95% confidence threshold, test the null hypothesis that the triangle does not display significant calendar year effects.

### Explanation
Mack's calendar-year test. In each development column, mark each factor S (smaller than the column median), L (larger) or * (equal to the median, ignored):

| AY | 12-24 | 24-36 | 36-48 | 48-60 | 60-72 | 72-84 |
|---|---|---|---|---|---|---|
| 2008 | L | * | L | * | L | * |
| 2009 | S | L | S | L | S | |
| 2010 | S | S | L | S | | |
| 2011 | S | L | S | | | |
| 2012 | L | S | | | | |
| 2013 | L | | | | | |
| Median | 6.50 | 2.55 | 1.55 | 1.30 | 1.15 | 1.05 |

For each diagonal $j$ (ignoring $j = 1$, which has one element): $S_j$ and $L_j$ are its counts of S and L, $n = S_j + L_j$, $m = \lfloor (n-1)/2 \rfloor$ and $Z_j = \min(S_j, L_j)$, with

$$E[Z_n] = \frac{n}{2} - \binom{n-1}{m}\frac{n}{2^n}$$

$$\text{Var}[Z_n] = \frac{n(n-1)}{4} - \binom{n-1}{m}\frac{n(n-1)}{2^n} + E[Z_n] - E[Z_n]^2$$

| $j$ | S | L | $n$ | $m$ | $Z$ | $E[Z_n]$ | $\text{Var}[Z_n]$ |
|---|---|---|---|---|---|---|---|
| 2 | 1 | 0 | 0 | 0 | 0 | 0 | 0 |
| 3 | 1 | 2 | 3 | 1 | 1 | 0.750 | 0.188 |
| 4 | 3 | 0 | 3 | 1 | 0 | 0.750 | 0.188 |
| 5 | 0 | 5 | 5 | 2 | 0 | 1.563 | 0.371 |
| 6 | 4 | 1 | 5 | 2 | 1 | 1.563 | 0.371 |
| Total | | | | | 2 | 4.625 | 1.117 |

($n = 0$ for $j = 2$ as printed in the examiner's report; the report's second sample takes $n = 1$ there, with the same $E[Z] = 0$ and $\text{Var}[Z] = 0$.)

For example, for $n = 3$: $Z = 0$ in 2 of the 8 arrangements and $Z = 1$ in 6, so $E[Z] = 0.75$ and $\text{Var}[Z] = 0.75 - 0.75^2 = 0.1875$. For $n = 5$: $E[Z] = (10 \times 1 + 20 \times 2)/32 = 1.5625$ and $\text{Var}[Z] = 2.8125 - 1.5625^2 = 0.371$.

$$Z = \sum Z_j = 2 \qquad E[Z] = 4.625 \qquad \text{Var}[Z] = 1.117$$

95% interval: $4.625 \pm 1.96\sqrt{1.117} = (2.554,\ 6.696)$.

$Z = 2$ lies outside the interval, so reject $H_0$: the triangle displays significant calendar year effects.

## Part b (0.5 points)

Provide two examples of calendar years effects that may cause loss development data not to be independent by accident year.

### Explanation
Any two of:

- A change in claims department processes or the claims handling system (e.g. a reserve strengthening that makes one diagonal unusually strong).
- A court ruling or legislative change affecting benefit levels, which applies to claims from all accident years at once.
- High or changing inflation.
- Changes in payment processes.

### Examiner Report
A common response was the single word 'inflation'. This did not receive credit because it is changes in inflation that cause calendar year effects. However, 'high inflation' was accepted because it implied that inflation was increasing.
