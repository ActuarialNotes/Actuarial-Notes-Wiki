A hands-on primer that teaches the principles and practice of data visualization. Princeton University Press says it covers what makes some graphs succeed and others fail, how to make reproducible, high-quality figures in R using ggplot2, and how to visualize data honestly. Worked examples build from summaries of single variables to more complex graphics, including small multiples, layered information, maps and output from statistical models, using the tidyverse tools and a library of datasets, code and functions.
