Given the following information:

| Vehicle Type | Vehicle Use | State A Exposures | State A Losses (\$) | Countrywide Exposures | Countrywide Losses (\$) |
|---|---|---|---|---|---|
| Car | Pleasure | 2,500 | 500,000 | 30,000 | 6,600,000 |
| Car | Work | 1,000 | 500,000 | 25,000 | 16,250,000 |
| Truck | Pleasure | 0 | 0 | 40,000 | 14,400,000 |
| Truck | Work | 3,000 | 300,000 | 50,000 | 8,500,000 |

- An actuary is developing a pure premium estimate for trucks used for work in state A.
- The actuary is using experience from all other states as a complement of credibility.

## Part a (1.25 points)

Calculate the complement of credibility using Harwayne's Method.

### Answer
\$130.79

### Explanation
Harwayne's method builds a complement from another group's experience after removing the distortion caused by the two groups having **different exposure mixes**. It has three steps.

**Step 1 — strip State A out of the countrywide data.** The complement is "all other states", so State A's own exposures and losses must be subtracted from the countrywide totals first. Otherwise the complement partly repeats the very data it is meant to supplement.

| Class | Other-states Exposures | Other-states Losses (\$) | Other-states Pure Premium |
|---|---|---|---|
| Car / Pleasure | $30{,}000 - 2{,}500 = 27{,}500$ | $6{,}600{,}000 - 500{,}000 = 6{,}100{,}000$ | \$221.82 |
| Car / Work | $25{,}000 - 1{,}000 = 24{,}000$ | $16{,}250{,}000 - 500{,}000 = 15{,}750{,}000$ | \$656.25 |
| Truck / Pleasure | $40{,}000 - 0 = 40{,}000$ | $14{,}400{,}000 - 0 = 14{,}400{,}000$ | \$360.00 |
| Truck / Work | $50{,}000 - 3{,}000 = 47{,}000$ | $8{,}500{,}000 - 300{,}000 = 8{,}200{,}000$ | \$174.47 |

**Step 2 — re-weight the other states to State A's exposure distribution.** Compute what the other states' overall pure premium *would be* if their business were distributed the way State A's is. This uses **State A's** exposures as weights, applied to the whole table — not just the truck rows:

$$\frac{221.82(2{,}500) + 656.25(1{,}000) + 360.00(0) + 174.47(3{,}000)}{2{,}500 + 1{,}000 + 0 + 3{,}000} = \frac{1{,}734{,}200}{6{,}500} = \$266.80$$

State A's own overall pure premium, on the same exposure base:

$$\frac{500{,}000 + 500{,}000 + 0 + 300{,}000}{6{,}500} = \frac{1{,}300{,}000}{6{,}500} = \$200.00$$

**Step 3 — adjustment factor and complement.** The ratio of the two measures how much cheaper State A runs than the other states once mix is held constant:

$$\text{Adjustment factor} = \frac{200.00}{266.80} = 0.7496$$

Apply it to the other states' Truck/Work pure premium:

$$\text{Complement} = 0.7496 \times \$174.47 = \$130.79$$

### Examiner Report
Candidates were expected to understand and correctly apply Harwayne's Method to determine a complement of credibility for given data.

Candidates were expected to use the given table of data and calculate all the necessary steps of the Harwayne's Method to determine the complement of credibility to be used for Work Trucks.

Common mistakes included:

- Not subtracting State A exposures and losses from the Countrywide data before calculating the Countrywide Pure Premiums.
- Not weighting the individual Countrywide Pure Premiums (i.e. Car/Work, Car/Pleasure, Truck/Work, Truck/Pleasure) with State A's exposure distribution, but instead using the Countrywide distribution.
- Reversing the numerator and denominator of the Adjustment Factor (i.e. calculating 1/Adj. Factor)
- Only using a subset of the data given (e.g. using only Truck data, or just the Work data) instead of the entire data table of data.

## Part b (0.5 points)

Briefly describe two advantages of using the current rate as a complement of credibility instead of calculating the complement with Harwayne's method.

### Explanation
**Advantage 1 — it is far simpler to compute.** The current rate is already known; using it as the complement requires at most trending it forward, whereas Harwayne's method requires stripping the subject state out of the countrywide data, computing a pure premium for every class, re-weighting them to the subject state's exposure distribution, and forming an adjustment factor. The current rate saves substantial time and offers fewer opportunities for error.

**Advantage 2 — it has a clear, direct logical relationship to the subject experience, so it is easier to explain.** The current rate applies to exactly the risks being priced, so its relevance is self-evident to management and to regulators. Harwayne's complement is built from *other states'* experience adjusted by a mix-correction factor, and that indirect chain of reasoning is considerably harder to justify to a non-technical audience.

### Examiner Report
Candidates were expected to know the 2 advantages of using the Current Rate Method to determine a complement as opposed to using Harwayne's Method.

Common mistakes included:

- Stating availability of the data as an advantage. Both methods have available data, so this is not an advantage.
- Stating that the Current Rate was easier to explain but not stating why.
- Stating that Current Rate method would minimize disruption.
