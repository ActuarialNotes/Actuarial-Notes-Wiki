Determine which of the following statements are true.

- I. If $N$ is the number of claims a policy produces in a year, then $P(N \le 3) - P(N < 3) = P(N = 3)$.
- II. Because a density function gives probabilities, the density of a continuous claim-size random variable can never exceed 1.
- III. A random variable whose possible values fill an interval need not be a continuous random variable.

- A) I only
- B) I and II only
- C) I and III only
- D) II and III only
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

**I is true.** $N$ is a discrete random variable, so $P(N \le 3) = P(N < 3) + P(N = 3)$. The endpoint carries probability $p(3)$, which is why $\le$ and $<$ give different answers for a count. (For a continuous random variable the difference would be 0.)

**II is false.** A density is a rate, not a probability: probability is the *area* under it. A density only has to be nonnegative and integrate to 1, so it can exceed 1. A claim size uniform on $(0, 0.5)$ has density 2 on that interval.

**III is true.** Taking a continuum of values doesn't make a random variable continuous; it must also put probability 0 on every single value. A payment under a deductible, $(X - d)^+$ with $X$ continuous, takes every value in an interval yet has $P(\text{payment} = 0) = P(X \le d) > 0$. It is a mixed random variable.

I and III are true, so the answer is **C**.

**Why not the others**

- **A** rejects III, treating "takes a continuum of values" as the definition of continuous and forgetting mixed random variables.
- **B** and **D** accept II, reading a density value as a probability.
- **E** would require a combination the other options don't list, such as all three statements true, or II or III alone.
