Given the following loss ratio triangle:

| Accident Year | Cumulative Reported Loss Ratio: 12 Months | 24 Months | 36 Months | 48 Months | 60 Months |
|---|---|---|---|---|---|
| 2010 | 3.0% | 10.0% | 15.7% | 37.0% | 37.0% |
| 2011 | 5.1% | 5.1% | 25.0% | 44.2% | 48.0% |
| 2012 | 2.5% | 3.0% | 40.0% | 57.0% | 59.2% |
| 2013 | 1.6% | 15.7% | 22.2% | 21.0% | |
| 2014 | 0.0% | 7.8% | 16.7% | | |
| 2015 | 6.3% | 12.4% | | | |
| 2016 | 4.7% | | | | |

- Assume a tail factor of 1.15 from 60 months to ultimate.

Calculate the accident year 2014 ultimate loss ratio using the least squares method.

### Explanation
Ultimate loss ratios for AY 2010–2012 are the 60-month loss ratios times the 1.15 tail. First fit AY 2013 (48 months → ultimate) on AY 2010–2012:

$$\bar{X} = \tfrac{1}{3}(0.37 + 0.442 + 0.57) = 0.4607$$

$$\bar{Y} = \tfrac{1}{3} \times 1.15 \times (0.37 + 0.48 + 0.592) = 0.5528$$

$$\overline{XY} = \tfrac{1}{3}(0.37 \times 1.15 \times 0.37 + \dots) = 0.2632 \qquad \overline{X^2} = \tfrac{1}{3}(0.37^2 + \dots) = 0.2191$$

$$b = \frac{\overline{XY} - \bar{X}\,\bar{Y}}{\overline{X^2} - \bar{X}^2} = 1.2435 \qquad a = \bar{Y} - b\,\bar{X} = -0.0201$$

Since $a < 0$, use the link ratio (chain ladder) method instead:

$$\text{AY 2013 ultimate} = 0.21 \times 1.15 \times \frac{0.37 + 0.48 + 0.592}{0.37 + 0.442 + 0.57} = 0.2520$$

Then fit AY 2014 (36 months → ultimate) on AY 2010–2013:

$$\bar{X} = \tfrac{1}{4}(0.157 + 0.25 + 0.4 + 0.222) = 0.2573$$

$$\bar{Y} = \tfrac{1}{4}(0.37 \times 1.15 + 0.48 \times 1.15 + 0.592 \times 1.15 + 0.2520) = 0.4776$$

$$\overline{XY} = \tfrac{1}{4}(0.157 \times 0.37 \times 1.15 + \dots) = 0.1333 \qquad \overline{X^2} = \tfrac{1}{4}(0.157^2 + \dots) = 0.0741$$

$$b = 1.3187 \qquad a = \bar{Y} - b\,\bar{X} = 0.1383$$

$$\text{AY 2014 ultimate loss ratio} = a + b \times 0.167 = 0.359$$

Alternatively:

Keep least squares for AY 2013 despite the negative $a$ (noting that a negative $a$ can give impractical values and chain ladder may be more appropriate). Ultimate loss ratios: AY 2010 $0.37 \times 1.15 = 0.4255$, AY 2011 $0.48 \times 1.15 = 0.552$, AY 2012 $0.592 \times 1.15 = 0.6808$.

AY 2013: $\bar{X} = (1.37 + 0.442 + 0.57)/3 = 0.4607$ (as printed in the examiner's report), $\bar{Y} = (0.4255 + \dots + 0.6808)/3 = 0.5528$, $\overline{XY} = (0.37 \times 0.4255 + \dots + 0.57 \times 0.6808)/3 = 0.2632$, $\overline{X^2} = (0.37^2 + \dots + 0.57^2)/3 = 0.2191$, so $b = 1.244$, $a = -0.02$:

$$\text{AY 2013 ult L/R} = 1.244 \times 0.21 - 0.02 = 0.2412$$

AY 2014: $\bar{X} = (0.157 + \dots + 0.222)/4 = 0.2573$, $\bar{Y} = (0.4255 + \dots + 0.2412)/4 = 0.4749$, $\overline{XY} = (0.157 \times 0.4255 + \dots)/4 = 0.1327$, $\overline{X^2} = (0.157^2 + \dots + 0.222^2)/4 = 0.0741$:

$$\text{AY 2014 ult L/R} = 1.3307 \times 0.167 + 0.1325 = 0.335$$

### Examiner Report
Candidates were expected to be aware that they cannot use a negative «a» parameter, because this could result in negative loss ratio.
Common errors include:

- Using a negative «a» parameter, without mentioning that the chain ladder method should be used instead.
- Not using as much data as possible in the calculation. This includes the 2013 data at 48
months.
