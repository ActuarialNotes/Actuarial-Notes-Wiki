You are given multiple different Bayesian linear models. To make a better prediction, you would like to consider all the provided models. To accomplish this, you are given the following options to evaluate:

- I. Average the predictions of the multiple models
- II. Average the parameter values of the multiple models
- III. Discard and do not report on any but the best-performing model

Determine which of the above options are valid.

- A) Option I only
- B) Option II only
- C) Option III only
- D) Options I, II and III
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

To use every model rather than pick one, you average what the models *predict*, usually weighting each model by its estimated out-of-sample accuracy (for example Akaike or WAIC weights). This is model averaging.

**I is valid.** Averaging the predictions, or more precisely mixing the models' posterior predictive distributions, is exactly what model averaging is. The prediction carries the uncertainty about which model is right.

**II is not valid.** A parameter means something different in each model. A slope on $x$ in a model that also includes $z$ is not the same quantity as the slope on $x$ in a model without $z$, and some parameters don't exist in some models at all. Averaging the parameter values produces a model nobody fitted.

**III is not valid.** Keeping only the best-performing model is model *selection*, not a way of considering all the models. It throws away the information about how much better the best model actually is, and so overstates confidence in it.

Only option I, so the answer is **A**.
