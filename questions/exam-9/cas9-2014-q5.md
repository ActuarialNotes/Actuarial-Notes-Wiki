Given the following information for constructing an investment portfolio:

| Asset | Expected Return | Standard Deviation |
|---|---|---|
| A | 8% | 20% |
| B | 10% | 25% |

- The risk-free rate is 2%.
- The correlation coefficient between assets A and B is -0.4.
- The investor has a risk aversion coefficient of 5.

Calculate the expected rate of return and standard deviation of the optimal complete portfolio.

### Explanation
Sample 1:

$$W_A = \frac{E(R_A)\sigma_B^2 - E(R_B)Cov(AB)}{E(R_A)\sigma_B^2 + E(R_B)\sigma_A^2 - [E(R_A) + E(R_B)]Cov(AB)}$$

$E(R) = E(r) - r_f$, $Cov(AB) = \rho_{AB}\,\sigma_A\,\sigma_B$

$$W_A = \frac{.06(.28^2) - .08(-.4)(.2)(.25)}{.06(.28^2) + .08(.2^2) - (.06 + .08)(-.4)(.2)(.25)} = .5487$$

(the $.28^2$, for $\sigma_B^2 = .25^2$, as printed)

$W_B = 1 - W_A = .4513$

$$E(r_p) = W_A E(r_A) + W_B E(r_B) = .5487(.08) + .4513(.1) = .089$$

$$\sigma_p^2 = W_A^2\sigma_A^2 + W_B^2\sigma_B^2 + 2W_A W_B Cov(AB) = .5487^2(.2^2) + .4513^2(.25^2) + 2(.5987)(.4513)(-.4)(.2)(.25) = .01487$$

(the $.5987$, for $W_A = .5487$, as printed)

If $u = E(r_c) - \frac{1}{2}A\sigma_c^2$:

$$y^* = \frac{E(r_P) - r_f}{A\sigma_p^2} = \frac{.089 - .02}{5(.01487)} = .9282$$

$$E(r_c) = y^*E(r_p) + (1 - y^*)r_f = .9282(.089) + (1 - .9282)(.02) = .084$$

$$\sigma_c = y^*\sigma_p = .9282\sqrt{.01487} = .1132$$

Sample 2:

$R_f = 2\%$, $Cor(A,B) = -.04$ (as printed; the stem gives $-0.4$), $A = 5$

**1. First derive the optimal risky portfolio.** Covariance of A, B is

$$Cov(A,B) = -\text{correlation} \times \sigma_A \times \sigma_B = -0.4 \times 0.2 \times 0.25 = -0.02$$

(the leading minus as printed). Proportion of asset A in the optimal risky portfolio:

$$W_A^* = \frac{E(R_A)\sigma_B^2 - E(R_B)Cov(A,B)}{E(R_A)\sigma_B^2 + E(R_B)\sigma_A^2 - [E(R_A) + E(R_B)]Cov(A,B)}$$

$$= \frac{(8\% - 2\%) \times 25\%^2 - (10\% - 2\%) \times (-0.02)}{6\% \times 25\%^2 + 8\% \times 20\%^2 - (6\% + 8\%) \times (-0.02)} = \frac{0.00535}{0.00975} = 54.87\%$$

Proportion of asset B $W_B^* = 1 - 54.87\% = 45.13\%$

$$E(r_P) = W_A^* E(r_A) + W_B^* E(R_B) = 54.87\% \times 8\% + 45.13\% \times 10\% = 8.90\%$$

$$\sigma_p^2 = W_A^{*2}\sigma_A^2 + W_B^{*2}\sigma_B^2 + 2W_A^* W_B^* Cov(A,B)$$

$$= 54.87\%^2 \times 0.2^2 + 45.13\%^2 \times 0.25^2 + 2 \times 54.87\% \times 45.13\% \times (-0.02) = 0.014867$$

**2.** Assume Utility $U = E(r) - \frac{1}{2}A\sigma^2$. Proportion is risky assets

$$y^* = \frac{E(r_p) - r_f}{A\sigma_p^2} = \frac{8.9\% - 2\%}{5 \times 0.014867} = 92.86\%$$

**3. Expected return of optimal complete portfolio**

$$E(r_c) = y^*E(r_p) + (1 - y^*) - r_f \text{ (as printed)}$$

$$= 92.86\% \times 8.90\% + (1 - 92.86\%) \times 2\% = 8.41\%$$

s.d. $\sigma_c = y^*\sigma_p = 92.86\% \times \sqrt{0.014867} = 92.86\% \times 0.12193 = 0.1132$
