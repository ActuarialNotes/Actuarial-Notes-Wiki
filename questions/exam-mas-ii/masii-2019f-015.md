You are given the following statements about a Linear Mixed Model and Marginal Model implied by that Linear Mixed Model:

I. When scoring the observations in the modeling dataset, both models will yield the same conditional predicted values.
II. Even if the variance-covariance matrix for the marginal residual errors in the Implied Marginal Model is nonpositive-definite, you may still be able to fit the Linear Mixed Model directly.
III. The interpretation of the covariance parameters is the same between both models.

Determine which of the proceeding statements are true.

- A) None of I, II, or III is true
- B) I and II only
- C) I and III only
- D) II and III only
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

**I is false.** The marginal model has integrated the random effects out, so it has no subject-specific effects to condition on and can only produce *marginal* (population-averaged) predictions. The two models agree on the marginal predicted values — that is what "implied" means — but only the linear mixed model can produce conditional ones.

**II is false.** The implication runs the other way. Because a linear mixed model builds its marginal covariance as $\mathbf{Z}\mathbf{D}\mathbf{Z}' + \mathbf{R}$, that matrix is positive-definite by construction. A marginal model, by contrast, can be specified directly with a covariance structure the mixed model could never generate — for instance a negative within-subject correlation, which a random intercept cannot produce. So a marginal model may be fittable where the corresponding mixed model is not, not the reverse.

**III is false.** In the linear mixed model the covariance parameters are **variance components**: they decompose variability into between-subject and within-subject sources, and each has its own interpretation. In the marginal model the same numbers describe the total covariance of the responses directly, with no such decomposition available.

None of the three is true, so the answer is **A**.
