## [F-001] Keyed 3.67 needs a random-type mixture the stem does not state; as written SD = 3.63, not an option
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-27T19:59Z/bfa2
- date: 2026-09-28
- severity: critical
- status: open
- locus: stem, first paragraph; ## Explanation
- claim: Stem: 'A company has 100 insureds. 60% have probability 0.20 of filing a claim in a year; 40% have probability 0.10'. Explanation adds Var(E[N_i|T_i]) = 0.0024 per insured, Var(N) = 13.44, SD = 3.67 (C).
- evidence: Read as written the portfolio is 60 insureds with p = 0.20 and 40 with p = 0.10, so N = N1 + N2 with N1 ~ Binomial(60, 0.20) and N2 ~ Binomial(40, 0.10) independent. Binomial variance mq(1-q) (SOA Tables for Exam C, App. B.2.1.3, PDF p.15) and V(X+Y) = V(X) + V(Y) for independent X, Y (Grinstead & Snell Thm 6.8, PDF p.267) give Var(N) = 60(0.2)(0.8) + 40(0.1)(0.9) = 9.6 + 3.6 = 13.2, SD = 3.633, which is not among the options (A 3.41, B 3.56, C 3.67, D 3.76, E 3.87; nearest is C). The explanation treats each insured type T_i as random and adds Var(E[N_i|T_i]) = 0.60(0.04) + 0.40(0.01) - 0.16^2 = 0.0024 per insured, giving 13.44 = 100(0.16)(0.84), SD 3.666 = C. That between-type term exists only if each insured is independently of the high-risk type with probability 0.60 (a mixture, as in the conditional variance formula of SOA Q388 solution p.108); for a known 60/40 portfolio the types are not random and the term is zero. A student following the explanation learns to add between-group variance to a fixed portfolio. Blind recomputation (13.2, 3.633) was done before reading the key.
- source_rank: 5
- proposed_action: Human decision: either (a) reword the stem so type is random (e.g. each insured independently has probability 0.60 of being a high-risk insured with claim probability 0.20, otherwise 0.10), which keeps key C = 3.67 and the explanation; or (b) keep the fixed 60/40 portfolio, make 3.63 an option and replace the explanation with Var(N) = 60(0.2)(0.8) + 40(0.1)(0.9) = 13.2.
