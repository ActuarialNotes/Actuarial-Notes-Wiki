An insurer's homeowners rates assume that the risks in each rating class have about the class's average expected loss. A new agent starts sending the insurer many older homes with deferred maintenance, which the rates for their class did not contemplate, and the underwriters accept them all at the class rate. What is the most likely effect?

- A) The class's loss ratio stays on target, because the rate already includes a profit provision
- B) Expected losses in the class rise above what its rates assume, so its loss ratio worsens
- C) Premiums in the class rise automatically, because the class rate follows the risks written
- D) Nothing changes until the next rate filing, because underwriting affects only new classes

## Explanation

Pricing assumes an average risk in each class, and underwriting is what keeps the risks written close to that average. Accepting worse-than-average risks at the class rate is adverse selection: expected losses in the class rise while the premium per risk does not, so the class's loss ratio rises. The answer is **B**.

**Why not the others**

- **A** — The profit provision is a margin for an *average* risk. Writing below-average risks erodes it rather than absorbing them.
- **C** — A class rate is filed and charged per exposure. It does not adjust by itself to the quality of the risks written.
- **D** — The effect shows up in the class's losses as soon as the policies are written and earned, not only at the next filing.
