Given the following output (\$000) from a paid chain-ladder generalized linear model:

| Accident Year | Mean Unpaid | Standard Error | Coefficient Of Variation |
|---|---|---|---|
| 2008 | \$63 | \$35 | 0.556 |
| 2009 | 632 | 260 | 0.411 |
| 2010 | 2,130 | 641 | 0.301 |
| 2011 | 4,721 | 1,265 | 0.268 |
| 2012 | 7,011 | 2,825 | 0.403 |
| Total | 14,557 | 4,024 | 0.276 |

Use four diagnostic tests to evaluate the model for reasonableness.

### Explanation
The report accepted any four of these diagnostics, each applied to the output:

- **Standard error should increase from the oldest to the most recent accident year**, because reserves are larger for the more recent years. It does — this is reasonable.
- **The coefficient of variation should decrease from the oldest to the most recent accident year**, because the variability is measured against a higher mean. It does through 2011. The 2012 CV (0.403) rises again; this can be accepted as parameter uncertainty overpowering process uncertainty in the latest year, or read as a failed test (0.403 > 0.268) — both readings were accepted.
- **The total standard error should be larger than the standard error of any individual year.** It is.
- **The total CV should be less than the CV of any individual year.** It is not — 0.276 exceeds the 0.268 for 2011 — so this should be investigated.
- **The mean unpaid should increase from the oldest to the most recent accident year.** It does, so the model passes.

### Examiner Report
The candidate was expected to know the diagnostic tests, then apply them to the data.
Relatively few candidates received full credit.  Common errors fell into the following four buckets

- Diagnostic tests that weren't accepted as valid response, some common ones:

o The total standard error should be less than the sum of the individual standard errors: this is expected to be true of the output of the model, but it will also be true of the output of an unreasonable model.
o Similar responses to prior bullet, but discussing coefficient of variation or sum of squared errors, were also not accepted o There were several variations of the following response: " compare the standard deviation to the mean, in general we want the mean to be at least two times the standard deviation."  However, a symmetric normal distribution may not be a good approximation to the true distribution of the reserves.  This diagnostic would only assess whether the distribution of reserves in the model can be reasonably described as normal, not assess the reasonableness of the model itself.
- No assessment of a correctly described diagnostic test
- Incorrect assessment of a correctly described diagnostic test: one surprising example was related to accepted response 5.  The correct diagnostic was described, but failure of AY 2011 not noted
- Diagnostic tests not appropriately described: most common for Accepted Response3: "CV should be high in early accident years and latest year"  this response did not describe whether the expectation is to have a decreasing or increasing CV This question was challenging from the standpoint of synthesizing the tests and applying it to the data, in addition to clearly stating what the diagnostic tests were.
