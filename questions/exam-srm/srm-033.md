The regression tree shown below was produced from a dataset of auto claim payments. Age Category (agecat: 1, 2, 3, 4, 5, 6) and Vehicle Age (veh_age: 1, 2, 3, 4, ...) are both predictor variables, and log of claim amount (LCA) is the dependent variable.

![Regression tree. The root splits on agecat: agecat < 1.5 goes right to a leaf with predicted value 8.146 (n=246); agecat >= 1.5 goes left to a split on veh_age. There, veh_age < 2.5 goes to a leaf 7.877 (n=720); veh_age >= 2.5 goes to a split on agecat. There, agecat < 4.5 goes to a leaf 7.995 (n=801); agecat >= 4.5 goes to a split on veh_age. There, veh_age < 3.5 goes to a leaf 7.771 (n=127) and veh_age >= 3.5 goes to a leaf 8.028 (n=106).](https://raw.githubusercontent.com/ActuarialNotes/Actuarial-Notes-Wiki/main/Media/Attachments/srm-q33-regression-tree.png)

Consider three autos I, II, III:

I: An Auto in Age Category 1 and Vehicle Age 4

II: An Auto in Age Category 5 and Vehicle Age 5

III: An Auto in Age Category 5 and Vehicle Age 3

Rank the estimated LCA of Autos I, II, and III.

- A) LCA(I) < LCA(II) < LCA(III)
- B) LCA(I) < LCA(III) < LCA(II)
- C) LCA(II) < LCA(I) < LCA(III)
- D) LCA(II) < LCA(III) < LCA(I)
- E) LCA(III) < LCA(II) < LCA(I)

## Explanation

Run each auto down the tree. At each split the labelled condition leads to the left branch and its complement to the right.

- **Auto I** (agecat 1, veh_age 4): agecat < 1.5, so take the right branch from the root, which ends at the leaf LCA(I) = 8.146.
- **Auto II** (agecat 5, veh_age 5): agecat ≥ 1.5 (left); veh_age ≥ 2.5 (right); agecat ≥ 4.5 (left); veh_age ≥ 3.5 (right). LCA(II) = 8.028.
- **Auto III** (agecat 5, veh_age 3): agecat ≥ 1.5 (left); veh_age ≥ 2.5 (right); agecat ≥ 4.5 (left); veh_age < 3.5 (left). LCA(III) = 7.771.

So $7.771 < 8.028 < 8.146$, that is, LCA(III) < LCA(II) < LCA(I).
