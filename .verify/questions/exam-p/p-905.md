## [F-001] No Poisson distribution has F(0) = 0.45 and F(1) = 0.90
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-27T19:59Z/bfa2
- date: 2026-09-28
- severity: critical
- status: open
- locus: stem, givens F(0) and F(1)
- claim: F(0) = 0.45 and F(1) = 0.90
- evidence: SOA Tables for Exam C, Appendix B Poisson–λ (PDF p.14): p0 = e^{−λ}, pk = e^{−λ}λ^k/k!, E[N] = Var[N] = λ. F(0) = 0.45 forces λ = −ln 0.45 = 0.7985, and then F(1) = 0.45(1.7985) = 0.809, not 0.90. F(1)/F(0) = 2 forces 1+λ = 2, λ = 1, and then F(0) = e^{−1} = 0.368, not 0.45. No λ satisfies both, so the question is unanswerable as posed and each reading lands on a different option: ratio → λ = 1, E[N^2] = λ+λ^2 = 2.00 (D, the key); F(0) alone → 0.7985 + 0.6376 = 1.436, nearest C (1.45); F(1) alone → e^{−λ}(1+λ) = 0.90 at λ ≈ 0.532, E[N^2] ≈ 0.815, nearest A (0.90). The explanation writes e^{−λ} = 0.45 and in the next line concludes λ = 1, which contradict each other. Not a near-copy of SOA Q342 (questions PDF p.140, image read): only the opening clause is shared; SOA gives the ratio F(2)/F(1) = 2.6 and asks E(X), options 3.2/4.0/4.2/5.0/5.2, no number in common.

- proposed_action: Author decision: make the givens consistent while keeping λ = 1 and key D, e.g. state the ratio F(1)/F(0) = 2 (or P[N=1] = P[N=0]) in the style of SOA Q342, or give F(0) = e^{−1} ≈ 0.368 and F(1) = 2e^{−1} ≈ 0.736; then correct the explanation's first line to match.
