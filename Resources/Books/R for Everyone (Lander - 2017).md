![[R for Everyone (Lander - 2017) - Cover.svg]]

A tutorial introduction to the open source R language for people new to statistical programming and modeling, including non-statisticians. Its publisher says it focuses on the 20 percent of R functionality needed to accomplish 80 percent of modern data tasks, with self-contained chapters that start with the absolute basics: installing R, the R environment, program control, data import, manipulation and visualization, essential tests, linear, generalized linear and nonlinear models, and some data mining. It closes with making code reproducible with LaTeX, RMarkdown and Shiny.

> [!info] On the syllabus
> - [[Exam PA (SOA)|Exam PA]] — Chapters 1-10, 14, 26 and 28.
