Given the following information:

| Current Rate Review | |
|---|---|
| Number of Exposures | 20,000 |
| Indicated Rate Change before credibility | 7.9% |
| Projected Frequency | 3.0% |
| Annual Loss Trend | -1.0% |
| Annual Premium Trend | 1.5% |
| Target Effective Date | January 1, 2019 |

| Prior Rate Review | |
|---|---|
| Indicated Rate Change | 8.0% |
| Implemented Rate Change | 3.5% |
| Effective Date | January 1, 2017 |

| Normal Distribution Table | |
|---|---|
| p | z(p) |
| 0.800 | 0.842 |
| 0.850 | 1.036 |
| 0.900 | 1.282 |
| 0.950 | 1.645 |
| 0.975 | 1.960 |
| 0.990 | 2.326 |

- The loss experience is considered fully credible if there is a 90% probability that the observed experience is within 2.5% of its expected value.

## Part a (2.25 points)

Calculate the credibility-weighted indicated rate change using the classical credibility approach and trended present rates as the complement of credibility.

### Answer
2.48%

### Explanation
**Step 1 — full credibility standard.** The requirement is a 90% probability of falling within $k = 2.5\%$ of the expected value. This is a two-sided interval, so the relevant z-score is the one leaving 5% in each tail — $z(0.950) = 1.645$ from the table, **not** $z(0.900) = 1.282$:

$$n_{\text{full}} = \left(\frac{z}{k}\right)^2 = \left(\frac{1.645}{0.025}\right)^2 = 4{,}329.64 \text{ claims}$$

**Step 2 — credibility of the experience.** The data is given in exposures, so convert to expected claims using the projected frequency:

$$\text{Expected claims} = 20{,}000 \times 3.0\% = 600$$

Under classical (limited fluctuation) credibility with the square-root rule:

$$Z = \sqrt{\frac{600}{4{,}329.64}} = \sqrt{0.13857} = 0.372$$

Equivalently, convert the standard to exposures first — $4{,}329.64 / 0.03 = 144{,}321$ exposures — and $Z = \sqrt{20{,}000 / 144{,}321} = 0.372$.

**Step 3 — the complement: trended present rates.** This complement asks what rate change is still needed given that the prior review's indication was only partially implemented, adjusted for net trend over the intervening period. The trend period runs from the prior rates' effective date to the target effective date:

$$1/1/2017 \longrightarrow 1/1/2019 = 2 \text{ years}$$

The *residual* indication left unimplemented from the prior review is

$$\frac{1 + 0.080}{1 + 0.035} = \frac{1.08}{1.035} = 1.043478$$

and the net trend — loss trend outpacing premium trend — compounded over two years is

$$\left(\frac{1 + (-0.010)}{1 + 0.015}\right)^{2} = \left(\frac{0.99}{1.015}\right)^{2} = 0.951346$$

so the complement is

$$C = 0.951346 \times 1.043478 = 0.99271 \quad \Longrightarrow \quad -0.73\%$$

**Step 4 — credibility weighting.** Weight the indicated change (as a factor, $1.079$) against the complement:

$$0.372(1.079) + (1 - 0.372)(0.99271) = 0.40139 + 0.62344 = 1.02483$$

$$\text{Credibility-weighted indicated rate change} = +2.48\%$$

### Examiner Report
Candidates were expected to understand a credibility weighted indication and how to calculate credibility and the complement of credibility. Candidates generally struggled with the calculation of credibility; that is, not knowing how to use the data given to calculate credibility.

Candidates were expected to calculate the credibility of the given data, calculate the complement of credibility, and, given the results of those answers and the indicated change before credibility, calculate the final credibility weighted indication.

Common mistakes included:

- Not using the correct z-score from the given normal distribution table
- Not getting the correct number of claims for full credibility
- Not getting the correct number of exposures for full credibility
- Not getting the correct credibility
- Assuming a credibility percentage instead of calculating one
- Not getting the correct trend period
- Not getting the correct residual indication
- Not getting the correct net trend
- Not getting the correct trended present rate indication
- Not applying the credibility and/or the complement to the correct numbers

## Part b (0.75 points)

Identify three other complements of credibility appropriate for first dollar ratemaking.

### Explanation
Any three of the complements used for first dollar ratemaking:

- **Loss costs of a larger related group** — for example the company's own countrywide or regional experience for the same line.
- **Rate change of a larger related group** — applying the broader group's indicated or implemented rate change to the segment's present rates.
- **Harwayne's method** — the larger group's loss costs adjusted for differences in the distribution of exposures between the group and the subject segment.
- **Competitors' rates** — the rate level implied by competitors' filed rates.
- **Industry benchmarks** — published industry or bureau loss costs.

### Examiner Report
Candidates were expected to list three alternative methods for calculating a complement of credibility for first dollar ratemaking.

A common mistake was not listing three applicable methods.
