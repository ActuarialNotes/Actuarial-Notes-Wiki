Given the following information for the past year for an insurance company:

| Item | (\$000) | % Fixed |
|---|---|---|
| Written Premium | 25,000 | — |
| Earned Premium | 20,000 | — |
| Agent Commission | 3,000 | 0% |
| Other Acquisition Cost | 300 | 100% |
| Premium Tax & Licensing Fees | 1,000 | 0% |
| General Expense | 2,500 | 100% |
| Loss Adjustment Expenses | 1,200 | 0% |

- Underwriting profit provision = 5%.

## Part a (0.75 points)

Calculate the underwriting expense ratio using the premium-based projection method.

### Answer
29.7%

### Explanation
Under the premium-based projection method the **premium base depends on when the expense is incurred**, not on whether it is fixed or variable. Acquisition-type expenses — commission, other acquisition, premium tax and licensing — are incurred when the policy is *written*, so they are ratioed to **written premium**. General expenses are incurred throughout the policy term, so they are ratioed to **earned premium**.

| Expense | Base | Ratio | Fixed / Variable |
|---|---|---|---|
| Agent Commission | $3{,}000 / 25{,}000$ | 12.0% | Variable |
| Other Acquisition Cost | $300 / 25{,}000$ | 1.2% | Fixed |
| Premium Tax & Licensing | $1{,}000 / 25{,}000$ | 4.0% | Variable |
| General Expense | $2{,}500 / 20{,}000$ | 12.5% | Fixed |

$$\text{Variable} = 12.0\% + 4.0\% = 16.0\%, \qquad \text{Fixed} = 1.2\% + 12.5\% = 13.7\%$$

$$\text{Underwriting expense ratio} = 16.0\% + 13.7\% = 29.7\%$$

Loss adjustment expense is excluded — it is a claims expense, not an underwriting expense.

### Examiner Report
Candidates were expected to calculate the underwriting expense, operating, and total permissible loss ratios using the correct premium base and to calculate the indicated rate change using the premium-based projection method.

Multiple solutions were allowed, including:

1. Using LAE as a variable expense (as opposed to a loss expense) in the permissible loss ratio and indicated rate change calculations in parts c and d.
2. Excluding LAE in the calculation of the indicated rate change in part d.

Candidates were expected to calculate the agent commission, other acquisition cost, and premium tax & licensing fee ratios using written premium and the general expense ratio using earned premium and to calculate the underwriting expense ratio including all 4 expenses.

Common errors included:

- Using the wrong premium base to calculate one or more of the expense ratios without an appropriate assumption.
- Excluding one or more of the expenses in the total underwriting expense ratio calculation.

## Part b (0.25 points)

Calculate the operating expense ratio using the premium-based projection method.

### Answer
35.7%

### Explanation
The operating expense ratio adds loss adjustment expense to the underwriting expenses. LAE is a claims-related cost incurred as coverage is provided, so it is ratioed to **earned** premium:

$$\text{LAE ratio} = \frac{1{,}200}{20{,}000} = 6.0\%$$

$$\text{Operating expense ratio} = 29.7\% + 6.0\% = 35.7\%$$

### Examiner Report
Candidates were expected to calculate the operating expense including all underwriting expenses as well as the LAE ratio to earned premium.

Common errors included:

- Using the written premium to calculate the LAE ratio.
- Excluding one or more of the expenses in the operating ratio calculation.
- Including profit in the operating ratio instead of the LAE ratio.

## Part c (0.25 points)

Calculate the total permissible loss ratio.

### Answer
65.3%

### Explanation
The total permissible loss ratio is the share of each premium dollar left over for claims once expenses and the profit provision are taken out:

$$TPLR = 1 - \text{Underwriting expense ratio} - \text{Profit} = 1 - 0.297 - 0.05 = 0.653$$

This 65.3% is the room available for **losses and LAE together**, because LAE was not deducted as an expense.

If instead LAE is treated as an operating expense rather than a loss expense, it comes out of the denominator side and the permissible ratio covers losses alone:

$$TPLR = 1 - \text{Operating expense ratio} - \text{Profit} = 1 - 0.357 - 0.05 = 0.593$$

Either is correct provided LAE is treated consistently through the rest of the question.

### Examiner Report
Candidates were expected to calculate the total permissible loss ratio. The calculation could or could not include LAE in the total permissible loss ratio depending on how LAE was treated throughout the problem.

Common errors included:

- Calculating the variable permissible loss ratio instead of the total permissible loss ratio.
- Not subtracting out profit from the total permissible loss ratio.

## Part d (0.75 points)

Calculate the indicated rate change using a projected loss ratio of 65% (excluding loss adjustment expenses).

### Answer
+7.2%

### Explanation
The premium-based projection method separates fixed from variable expenses, so the indication is

$$\text{Indicated change} = \frac{L + \text{LAE ratio} + F}{1 - V - Q} - 1$$

The given 65% loss ratio **excludes** LAE, so the 6.0% LAE ratio has to be added back into the numerator alongside the fixed expense provision:

$$= \frac{0.65 + 0.06 + 0.137}{1 - 0.16 - 0.05} = \frac{0.847}{0.79} = 1.0722$$

$$\text{Indicated rate change} = +7.2\%$$

Treating LAE as a variable expense instead moves it to the denominator, giving

$$\frac{0.65 + 0.137}{1 - 0.22 - 0.05} - 1 = \frac{0.787}{0.73} - 1 = +7.8\%$$

Both treatments were accepted, as was excluding LAE from this part altogether.

### Examiner Report
Candidates were expected to calculate the indicated rate change as either a factor or percentage of premium. Candidates were also expected to know that the premium-based projection method was appropriate given the information in the problem.

Common errors included:

- Using the all-variable expense method.
- Using the wrong premium bases to calculate the fixed and variable expense ratios.
- Multiplying the given loss ratio by 1+LAE/EP instead of adding the LAE/EP ratio.
- Mixing up which expenses were fixed vs. which were variable.
- Excluding the profit provision.
