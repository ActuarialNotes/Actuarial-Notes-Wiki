Given the following data for a Cape Cod reserve analysis:

| Accident Year | Actual Incremental Reported Losses (\$000) at 12 Months | 24 Months | 36 Months |
|---|---|---|---|
| 2010 | 100 | 255 | 180 |
| 2011 | 120 | 280 | |
| 2012 | 120 | | |

| Accident Year | Expected Incremental Reported Losses (\$000) at 12 Months | 24 Months | 36 Months |
|---|---|---|---|
| 2010 | 80 | 300 | 200 |
| 2011 | 80 | 320 | |
| 2012 | 100 | | |

The parameters of the loglogistic growth curve ($\omega$ and $\theta$) and the expected loss ratio (ELR) were previously estimated, resulting in a total estimated reserve of \$1,500,000. The parameter standard deviation of the total estimated reserve is \$350,000.

Calculate the standard deviation of the reserve due to parameter and process variance combined.

### Explanation
Clark's scale parameter is estimated from the incremental triangle:

$$\sigma^2 = \frac{1}{n - p}\sum \frac{(\text{Actual} - \text{Expected})^2}{\text{Expected}}$$

with $n = 6$ data points and $p = 3$ parameters ($\omega$, $\theta$ and the ELR). Each cell's contribution $(\text{Actual} - \text{Expected})^2 / \text{Expected}$ is:

| AY | 12 | 24 | 36 |
|---|---|---|---|
| 2010 | 5 | 6.75 | 2 |
| 2011 | 20 | 5 | |
| 2012 | 4 | | |

e.g. $(100 - 80)^2/80 = 5$ and $(180 - 200)^2/200 = 2$. The total is 42.75, so

$$\sigma^2 = \frac{1}{6 - 3} \times 42.75 = 14.25$$

The triangles are in \$000, so $\sigma^2 = 14.25 \times 1{,}000 = 14{,}250$ in dollars.

$$\text{Process variance} = \sigma^2 \times \text{Reserve} = 14{,}250 \times 1{,}500{,}000 = 2.1375 \times 10^{10}$$

$$\text{Total SD} = \sqrt{2.1375 \times 10^{10} + 350{,}000^2} = 379{,}309$$

### Examiner Report
Candidates generally performed well with the most common deduction for not reflecting the 1000's in the triangles. Some candidates used erroneous formulas for σ2 or did not calculate the inputs correctly.
