Given the following information as of December 31, 2015:

Case Outstanding (\$) as of (months)

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 3,970 | 4,115 | 2,730 | 1,347 |
| 2013 | 3,680 | 3,760 | 4,560 | |
| 2014 | 3,690 | 7,380 | | |
| 2015 | 6,230 | | | |

Paid Claims (\$) as of (months)

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 3,680 | 7,360 | 11,040 | 13,800 |
| 2013 | 3,520 | 7,040 | 10,560 | |
| 2014 | 3,360 | 6,720 | | |
| 2015 | 3,520 | | | |

Open Claim Counts as of (months)

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 238 | 245 | 171 | 63 |
| 2013 | 222 | 230 | 179 | |
| 2014 | 220 | 255 | | |
| 2015 | 270 | | | |

| Calendar Year | Written Premium |
|---|---|
| 2014 | \$34,500 |
| 2015 | \$37,500 |

- Annual severity trend = 10.0%.
- Claims are fully developed by 48 months.
- Accident year 2015 initial expected claim ratio = 65.0%.
- Policies are annual, and are written uniformly throughout the year.
- There have been no rate changes since 2013.
- There is no premium trend.

Calculate the unpaid claims for accident year 2015 using the reported Bornhuetter-Ferguson technique adjusting for the change in case reserve adequacy.

### Answer
Approximately \$17,841.

### Explanation
The instruction to "adjust for the change in case reserve adequacy" is the signal for a **Berquist-Sherman case outstanding adjustment**: restate the historical case reserves to the adequacy level of the most recent diagonal, rebuild the reported triangle, and take the development pattern off *that* triangle instead of the raw one.

**Step 1 — average case outstanding, to see the change.** Divide case outstanding by open claim counts:

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 16.68 | 16.80 | 15.96 | 21.38 |
| 2013 | 16.58 | 16.35 | 25.47 | |
| 2014 | 16.77 | 28.94 | | |
| 2015 | 23.07 | | | |

The interior of the triangle sits near 16-17 at every maturity, while the latest diagonal (21.38, 25.47, 28.94, 23.07) is far above it. Case reserves were strengthened during calendar year 2015, so the raw reported triangle mixes two different reserving bases and its link ratios are not usable.

**Step 2 — restate the triangle at the latest diagonal's adequacy.** Hold the latest diagonal fixed and *detrend* it back through each column at the 10% severity trend, one year per diagonal:

$$\text{Adjusted avg case}_{AY,\,age} = \frac{\text{latest diagonal value at that age}}{(1.10)^{n}}$$

where $n$ is the number of years back from the diagonal.

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 17.34 | 23.92 | 23.16 | 21.38 |
| 2013 | 19.07 | 26.31 | 25.47 | |
| 2014 | 20.98 | 28.94 | | |
| 2015 | 23.07 | | | |

For example $23.07/1.10^{3} = 17.34$ at 12 months for 2012, and $28.94/1.10^{2} = 23.92$ at 24 months for 2012. It is the **average** case outstanding that is detrended, not total case outstanding — the counts carry the volume.

**Step 3 — rebuild the reported triangle.**

$$\text{Adjusted reported} = \text{adjusted avg case} \times \text{open counts} + \text{paid claims}$$

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2012 | 7,806 | 13,220 | 15,000 | 15,147 |
| 2013 | 7,753 | 13,091 | 15,120 | |
| 2014 | 7,975 | 14,100 | | |
| 2015 | 9,750 | | | |

The latest diagonal is untouched by construction, so accident year 2015 at 12 months is just the actual reported figure, $6{,}230 + 3{,}520 = 9{,}750$.

**Step 4 — development pattern off the adjusted triangle.**

| Accident Year | 12-24 | 24-36 | 36-48 |
|---|---|---|---|
| 2012 | 1.694 | 1.135 | 1.010 |
| 2013 | 1.688 | 1.155 | |
| 2014 | 1.768 | | |
| Straight average | 1.717 | 1.145 | 1.010 |

Claims are fully developed at 48 months, so the tail factor is 1.000.

$$\text{CDF}_{36} = 1.010,\qquad \text{CDF}_{24} = 1.145 \times 1.010 = 1.156,\qquad \text{CDF}_{12} = 1.717 \times 1.156 = 1.985$$

$$\%\text{ reported at }12 = \frac{1}{1.985} = 0.504,\qquad \%\text{ unreported} = 0.496$$

**Step 5 — calendar year 2015 earned premium.** The Bornhuetter-Ferguson expected claims need *earned* premium, and only written premium is given. With annual policies written uniformly, half of each year's writings are earned in the year written and half in the following year:

$$\text{CY 2015 EP} = 0.5(34{,}500) + 0.5(37{,}500) = \$36{,}000$$

Equivalently, through the unearned premium reserve: $\text{UEPR}_{1/1/2015} = 0.5(34{,}500) = 17{,}250$ and $\text{UEPR}_{1/1/2016} = 0.5(37{,}500) = 18{,}750$, so

$$\text{EP} = 37{,}500 - (18{,}750 - 17{,}250) = \$36{,}000$$

**Step 6 — Bornhuetter-Ferguson ultimate.**

$$\text{Expected claims} = 0.65 \times 36{,}000 = \$23{,}400$$

$$\text{BF ultimate} = \text{reported} + \text{expected} \times \%\text{unreported} = 9{,}750 + 23{,}400(0.496) = \$21{,}361$$

**Step 7 — unpaid claims.** Unpaid is ultimate less **paid**, not less reported:

$$\text{Unpaid} = 21{,}361 - 3{,}520 = \mathbf{\$17{,}841}$$

Equivalently, the BF IBNR plus the actual case reserve carried on the books:

$$\text{IBNR} = 23{,}400\left(1 - \frac{1}{1.985}\right) = 11{,}612,\qquad \text{Unpaid} = 11{,}612 + 6{,}230 = \$17{,}842$$

The two differ only by rounding in the reported percentage.

### Examiner Report
Candidates were expected to read "adjust for the change in case reserve adequacy" as a call for a Berquist-Sherman case outstanding adjustment, use the resulting adjusted reported triangle to derive a development pattern more appropriate than the unadjusted chain ladder, derive calendar year 2015 earned premium from the written premium given, and finish with a reported Bornhuetter-Ferguson estimate of accident year 2015 unpaid claims.

Common errors included detrending total case outstanding rather than *average* case outstanding; using calendar year 2015 written premium directly in the Bornhuetter-Ferguson expected claims instead of deriving earned premium; substituting the reported development (chain ladder) ultimate for the Bornhuetter-Ferguson ultimate when computing unpaid; and stopping at the expected unreported amount (IBNR), forgetting to add the accident year 2015 case outstanding.
