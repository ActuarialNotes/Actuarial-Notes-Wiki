Given the following information as of December 31, 2017:

**Cumulative Paid Claims Only (\$) as of (months)**

| Accident Year | 12 | 24 | 36 |
|---|---|---|---|
| 2014 | 172,000 | 464,400 | 626,900 |
| 2015 | 168,000 | 453,600 | |
| 2016 | 170,000 | | |

| Accident Year | Calendar Year 2017 Paid Claims Only (\$) |
|---|---|
| 2014 | 75,200 |
| 2015 | 158,800 |
| 2016 | 289,000 |
| 2017 | 172,000 |

**Cumulative Paid ALAE (\$) as of (months)**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 5,500 | 27,000 | 40,000 | 55,000 |
| 2015 | 5,600 | 26,000 | 39,000 | |
| 2016 | 5,700 | 26,000 | | |
| 2017 | 5,600 | | | |

- There is no development beyond 48 months.

## Part a (0.25 point)

Calculate the last diagonal of the Cumulative Paid Claims Only triangle as of December 31, 2017.

### Answer

AY 2014: \$702,100; AY 2015: \$612,400; AY 2016: \$459,000; AY 2017: \$172,000

### Explanation

Add each accident year's calendar year 2017 payments to its prior cumulative total:

| AY | Prior Cumulative | CY 2017 Paid | 12/31/2017 Cumulative | Age |
|---|---|---|---|---|
| 2014 | 626,900 | 75,200 | 702,100 | 48 |
| 2015 | 453,600 | 158,800 | 612,400 | 36 |
| 2016 | 170,000 | 289,000 | 459,000 | 24 |
| 2017 | 0 | 172,000 | 172,000 | 12 |

### Examiner Report

Candidates were expected to calculate the December 31, 2017 paid claim diagonal from the prior diagonal and the calendar year 2017 payments.

A common mistake was adding the calendar year payments to the wrong accident year of the prior diagonal.

## Part b (1.75 points)

Estimate ultimate ALAE for Accident Year 2017 using an additive ratio approach.

### Answer

Approximately \$54,769

### Explanation

**Step 1 — Paid ALAE to paid claims ratio triangle:**

| Accident Year | 12 | 24 | 36 | 48 |
|---|---|---|---|---|
| 2014 | 0.032 | 0.058 | 0.064 | 0.078 |
| 2015 | 0.033 | 0.057 | 0.064 | |
| 2016 | 0.034 | 0.057 | | |
| 2017 | 0.033 | | | |

**Step 2 — Additive development.** Under the additive approach the development factors are *differences* between successive ratios, not quotients:

| | 12–24 | 24–36 | 36–48 |
|---|---|---|---|
| 2014 | 0.026 | 0.006 | 0.014 |
| 2015 | 0.024 | 0.007 | |
| 2016 | 0.023 | | |
| Selected | 0.024 | 0.007 | 0.014 |

Cumulating (again by addition), with no development beyond 48 months:

$$\text{12-to-ultimate additive factor} = 0.024 + 0.007 + 0.014 = 0.045$$

$$\text{Ultimate ALAE-to-paid ratio}_{2017} = 0.033 + 0.045 = 0.078$$

**Step 3 — Ultimate paid claims for AY 2017**, from the paid claims triangle:

| | 12–24 | 24–36 | 36–48 |
|---|---|---|---|
| 2014 | 2.700 | 1.350 | 1.120 |
| 2015 | 2.700 | 1.350 | |
| 2016 | 2.700 | | |
| Selected | 2.700 | 1.350 | 1.120 |

$$\text{CDF}_{12-\text{ult}} = 2.700 \times 1.350 \times 1.120 = 4.0824$$

$$\text{Ultimate Paid Claims}_{2017} = 172{,}000 \times 4.0824 = 702{,}173$$

**Step 4 — Ultimate ALAE:**

$$702{,}173 \times 0.078 = 54{,}769$$

### Examiner Report

Candidates were expected to estimate ultimate ALAE using the additive ratio approach: construct the paid ALAE to paid claims triangle, develop it by addition, cumulate the selected additive factors, and apply the 12-to-ultimate ratio to the 2017 ultimate loss (itself derived from the development method on the paid claims triangle).

Common mistakes included giving only the ALAE ratio rather than an ultimate ALAE estimate, applying the ratio to 2017 *paid* claims rather than to ultimate claims, and using the development method directly on the ALAE triangle instead of the ratio approach.

## Part c (0.25 point)

Identify one disadvantage of using a ratio technique to estimate ALAE.

### Explanation

The ALAE estimate is only as good as the claim estimate it rides on — any error in the ultimate claims flows straight through into the ultimate ALAE, compounding the uncertainty.

The ratio also breaks down when ALAE and claims do not move together. Claims closed without payment can carry substantial defence costs, so a book with many such claims incurs ALAE with no corresponding paid claim in the denominator, and the ratio understates ALAE.

### Examiner Report

Candidates were expected to describe a disadvantage of the additive ratio approach.

Common mistakes included describing an advantage of the approach, or describing an assumption of it rather than a disadvantage.
