Given the following information for accident year 2011 as of December 31, 2011:

- Accident year 2011 paid loss: \$700,000
- 2011 earned premium: \$3,000,000
- Initial expected loss ratio: 62.5%
- 12-24 month paid link ratio: 1.50
- 12-ultimate cumulative paid LDF: 2.50

## Part a (1.25 points)

Calculate accident year 2011 ultimate loss estimates as of December 31, 2011 using each of the following three methods:

- i. Chain ladder
- ii. Bornhuetter-Ferguson
- iii. Benktander

### Explanation
$$\text{Chain ladder: } U_{CL} = \text{Paid} \times LDF_{12\text{-ult}} = 700{,}000 \times 2.5 = 1{,}750{,}000$$

$$\text{BF: } U_{BF} = \text{Paid} + \text{Expected ultimate} \times \%\text{ unpaid} = 700{,}000 + (3{,}000{,}000 \times 0.625) \times \left(1 - \tfrac{1}{2.5}\right) = 1{,}825{,}000$$

$$\text{Benktander: } U_{GB} = \text{Paid} + U_{BF} \times \%\text{ unpaid} = 700{,}000 + 1{,}825{,}000 \times \left(1 - \tfrac{1}{2.5}\right) = 1{,}795{,}000$$

The 24-ultimate factor, needed for part b, is $2.5 / 1.5 = 1.667$.

Alternatively:

With $p_k = 1/2.5 = 0.4$ and $q_k = 1 - 0.4 = 0.6$, the Benktander estimate is a credibility weighting of the prior expected ultimate and the chain-ladder ultimate:

$$U_{GB} = q_k^2 \, U_0 + (1 - q_k^2) \, U_{CL} = (0.6^2)(3{,}000\text{k})(0.625) + (1 - 0.6^2)(1.75\text{M}) = 675 + 1{,}120 = 1{,}795\text{k}$$

### Examiner Report
The a. part of this question was fairly straightforward. Common errors were arithmetic errors and errors in the formulas for each method.

## Part b (1.5 points)

Determine the accident year 2011 incremental paid loss in 2012 that would result in the Benktander ultimate loss estimate being \$50,000 greater than the Bornhuetter-Ferguson ultimate loss estimate for accident year 2011, as of December 31, 2012. Assume all selected development factors remain the same.

### Explanation
Let $x$ be the 2012 incremental paid loss. At December 31, 2012 the AY 2011 paid loss is $700{,}000 + x$ and the 24-ultimate factor is $1.667$, so the percent unpaid is $1 - 1/1.667 = 0.4$.

$$U_{BF} = (700{,}000 + x) + (3{,}000{,}000 \times 0.625) \times 0.4 = 700{,}000 + x + 750{,}000 = 1{,}450{,}000 + x$$

$$U_{GB} = (700{,}000 + x) + U_{BF} \times 0.4 = 700{,}000 + x + (1{,}450{,}000 + x)(0.4) = 1{,}280{,}000 + 1.4x$$

Setting the Benktander ultimate \$50,000 above the BF ultimate:

$$1{,}280{,}000 + 1.4x = 1{,}450{,}000 + x + 50{,}000 = 1{,}500{,}000 + x$$

$$0.4x = 220{,}000 \;\Rightarrow\; x = 550{,}000$$

Alternatively:

With the 24-ultimate LDF $= 2.5/1.5 = 5/3$, $p_{24} = 0.6$ and $q_{24} = 0.4$. Let $x$ here be the *cumulative* paid loss at 24 months. Since both methods start from the same paid loss,

$$U_{Benk} - U_{BF} = R_{Benk} - R_{BF} = q_k U_{BF} - q_k U_0 = 50{,}000$$

$$(0.4)\left[x + 0.4(3{,}000\text{k})(0.625)\right] - (0.4)(3{,}000\text{k})(0.625) = 50\text{k}$$

$$x - (0.6)(3{,}000\text{k})(0.625) = 125\text{k} \;\Rightarrow\; x = 1{,}250\text{k}$$

The 2012 incremental paid loss is $1{,}250\text{k} - 700\text{k} = 550\text{k}$.

### Examiner Report
The b. part involved setup of both the Bornheutter-Ferguson and the Benktander methods and solving a system of equations to determine the incremental paid loss. Common errors were in calculating qk, errors in recognizing that part b is a different time (12/31/2012) period than part a (12/31/2011), errors in the setup of the problem, and other calculation errors.
