You fit a model using MCMC and reviewed the results. You are presented with three potential problems and plausible solutions for those potential problems.

I. **Potential Problem:** Effective sample size is small as a result of autocorrelation of samples.
   **Plausible Solution:** Increase the number of iterations and thin the chain.
II. **Potential Problem:** The sampling algorithm has not adapted.
   **Plausible Solution:** Reduce the number of warmup iterations per chain.
III. **Potential Problem:** Your chain has converged but you are not certain that it converged in the correct region of the parameter space.
   **Plausible Solution:** Increase the number of iterations.

Determine which of the preceding represents both a potential problem and an appropriate plausible solution to that problem.

- A) I only
- B) II only
- C) III only
- D) I, II and III
- E) The answer is not given by (A), (B), (C), or (D)

## Explanation

**I is a matched problem and solution.** A small effective sample size means consecutive draws carry redundant information. Running longer produces more raw draws, and thinning keeps every $k^{th}$ one so the retained sample is less autocorrelated. Both parts address the stated problem.

**II is mismatched.** Adaptation happens *during* warmup — that is when the sampler tunes its step size and mass matrix. If it has not adapted, the fix is to **increase** the warmup iterations, not reduce them. Reducing warmup makes the problem worse.

**III is mismatched.** The concern here is a chain stuck in the wrong region — a local mode, or an unrepresentative part of the parameter space. Running the same chain longer does not help: it has already converged, and it will simply keep sampling the same wrong region. The remedy is to run **multiple chains from dispersed starting values** and compare them, which is exactly what the Gelman-Rubin diagnostic is for.

Only statement I, so the answer is **A**.
