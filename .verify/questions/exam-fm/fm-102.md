## [F-001] Opening sentence misstates the Macaulay duration formula

- author: agent:validate-v1

- severity: minor

- locus: Explanation, first sentence (line 38)
- claim: 'For a perpetuity-due, the Macaulay duration is $\ddot{a}_{\overline{\infty}|}/\text{PV}$ weighted by time.'
- evidence: As written the expression is ä∞/PV, and ä∞ is the PV, so it equals 1. SOA solutions PDF p.29 (image) gives MacD = Σ n v^n / Σ v^n = (Ia)∞/ä∞ = [1/(di)]/(1/d) = [(1+i)/i²]/[(1+i)/i] = 1/i — i.e. the time-weighted PV divided by the PV. The vault's own display immediately below states this correctly, so the key (C, 29.032) is unaffected; only the prose lead-in is wrong.
- source_rank: 1
