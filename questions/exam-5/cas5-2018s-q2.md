Given the following information:

**Current Rate Review**

|  |  |
|---|---|
| Number of Observations | 100 |
| Indicated Average Premium before credibility | \$750 |
| Expected Value of Process Variance | 7.5 |
| Variance of Hypothetical Means | 0.45 |
| Annual Loss Trend | 3% |
| Target Effective Date | July 1, 2018 |
| Current Average Premium at Present Rates | \$600 |

**Prior Rate Review**

|  |  |
|---|---|
| Indicated Rate Change | 20% |
| Implemented Rate Change | 9% |
| Effective Date of Indication | July 1, 2016 |
| Actual Effective Date | September 1, 2016 |

- The complement of credibility is trended present rates.

Calculate the credibility-weighted indicated premium using Buhlmann credibility.

### Explanation
**Bühlmann credibility.**

$$K = \frac{\text{EPV}}{\text{VHM}} = \frac{7.5}{0.45} = 16.667 \qquad Z = \frac{N}{N + K} = \frac{100}{100 + 16.667} = 0.8571$$

**Complement: trended present rates.** The present average premium is trended from the original target effective date of the current rates (the prior review's target, July 1, 2016) to the target effective date of the new rates (July 1, 2018), a 2-year trend period. Because the prior review's indicated change (20%) was only partly implemented (9%), the residual indication is also applied:

$$C = 600 \times 1.03^{2} \times \frac{1.20}{1.09} = 600 \times 1.0609 \times 1.1009 = 700.78$$

**Credibility-weighted indicated premium.**

$$0.8571 \times 750 + (1 - 0.8571) \times 700.78 = 742.97$$

The credibility-weighted indicated average premium is about \$743.

### Examiner Report
Candidates were expected to calculate the Buhlmann Credibility, the complement of credibility and the credibility-weighted indicated premium.

Common errors included:

- Using the wrong formulas for Z and/or K .
- Using the incorrect trend period or applying trend incorrectly.
- Incorrectly calculating the residual indication.
