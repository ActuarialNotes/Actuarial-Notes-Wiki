You are provided with the following select information from an insurance company's December 31, 2015 P&C-1. All amounts are in thousands of dollars (\$000s).

| Assets | Current Year | Prior Year |
|---|---|---|
| Total Investments | 400,000 | 380,000 |
| Recoverable from Reinsurers: Unearned Premiums | 50,000 | 40,000 |
| Recoverable from Reinsurers: Unpaid Claims and Adjustment Expenses | 150,000 | 135,000 |
| **Total Assets** | 700,000 | 670,000 |

| Liabilities | Current Year | Prior Year |
|---|---|---|
| Payables: Agents and Brokers | 2,500 | 1,500 |
| Payables: Policyholders | 1,000 | 1,000 |
| Payables: Other Insurers | 10,000 | 9,000 |
| Unearned Premiums | 100,000 | 80,000 |
| Unpaid Claims and Adjustment Expenses | 400,000 | 350,000 |
| Unearned Commissions | 4,000 | 3,000 |
| **Total Liabilities** | 600,000 | 550,000 |

| Statement of Income | Current Year | Prior Year |
|---|---|---|
| Premiums Written: Direct | 250,000 | 170,000 |
| Premiums Written: Reinsurance Assumed | 150,000 | 130,000 |
| Premiums Written: Reinsurance Ceded | 100,000 | 80,000 |
| Underwriting Income (Loss) | (120,000) | (100,000) |
| Net Investment Income | 105,000 | 80,000 |
| Total Income Taxes | (5,000) | (5,000) |
| Net Income (Loss) for the Year | (20,000) | (25,000) |

The company has no income from subsidiaries or any investment income gains.

## Part a (1 point)

Calculate the following key financial indicators as of December 31, 2015:

- i. Return on Equity
- ii. Return on Revenue
- iii. Net Loss Reserves to Equity
- iv. Return on Assets

### Explanation
(i) Return on equity = Net Income / Equity

$$= \frac{-20{,}000}{700{,}000 - 600{,}000} = -20\%$$

Or, Return on equity = Net Income / Average Equity

$$= \frac{-20{,}000 \times 2}{700{,}000 - 600{,}000 + 670{,}000 - 550{,}000} = -18.18\%$$

(ii) Return on revenue = (Underwriting Income + Investment Income) / Gross Premiums

$$= \frac{-120{,}000 + 105{,}000}{250{,}000 + 150{,}000} = -3.75\%$$

(iii) Net loss reserves to equity = Net loss reserves / Equity

$$= \frac{400{,}000 - 150{,}000}{700{,}000 - 600{,}000} = 250\%$$

(iv) Return on assets = Net Income / Average Assets

$$= \frac{-20{,}000 \times 2}{700{,}000 + 670{,}000} = -2.92\%$$

### Examiner Report
- The candidates were expected to know:
  - How to analyze financial statements
  - How to calculate various financial health ratios
- Candidates needed to calculate all components of the ratio correctly.
- Common errors made by candidates:
  - Calculation errors
  - Using net premiums instead of gross premiums in part (iii)
  - Using gross reserves instead of net reserves in part (iii)
  - Not using an average in part (iv)

## Part b (1.25 points)

Based on the indicators calculated in part a. above, comment on the company's financial health.

### Explanation
| Ratio | Comment |
|---|---|
| Return on equity | Ratio is below threshold of 5.4% (unfavorable) |
| Return on revenue | Ratio is below threshold of 6.2% (unfavorable) |
| Net reserves to equity | Ratio is above threshold of 200% (unfavorable) |
| Return on assets | Ratio is below threshold of 2.6% (unfavorable) |

All ratios indicate unfavorable results for the company. The company had significant underwriting loss and net losses in the last two years. Overall the financial health is poor.

### Examiner Report
- The candidates were expected to know:
  - Recommended thresholds for financial health ratios
  - Comment on the calculated ratios
- To obtain full credit, candidates needed to state 4 thresholds and comment on whether these thresholds were met.
- Common errors made by candidates:
  - Mixing up some of the thresholds
  - Not stating the threshold
  - Not stating an overall conclusion
