Given the following information:

| Accident Year | Cumulative Paid Loss 12 (\$000) | Cumulative Paid Loss 24 (\$000) | Cumulative Paid Loss 36 (\$000) | Cumulative Paid Loss 48 (\$000) |
|---|---|---|---|---|
| 2009 | 5,751 | 10,640 | 11,491 | 12,181 |
| 2010 | 5,528 | 9,287 | 10,680 | |
| 2011 | 4,120 | 7,004 | | |
| 2012 | 5,304 | | | |

Calculated Ultimate Loss (\$000)

| Accident Year | Bornhuetter-Ferguson Ultimate | Benktander Ultimate |
|---|---|---|
| 2009 | 12,181 | 12,181 |
| 2010 | 11,246 | 11,316 |
| 2011 | 8,428 | 8,204 |
| 2012 | 10,403 | 10,609 |

## Part a (1.5 points)

Calculate the 24-month-to-ultimate cumulative development factor that would result in the ultimate loss estimates shown above.

### Explanation
The Benktander reserve is the BF ultimate times the unreported proportion, $R_{GB} = q_k \times U_{BF}$. For AY 2011:

$$(8{,}204 - 7{,}004) = \left(1 - \frac{1}{\text{LDF}_{24\text{-ult}}}\right) \times 8{,}428$$

$$\frac{1{,}200}{8{,}428} = 1 - \frac{1}{\text{LDF}_{24\text{-ult}}}$$

$$\text{LDF}_{24\text{-ult}} = 1.1660$$

Alternatively:

For AY 2011, $U_{BF} = 8{,}428 = 7{,}004 + q_i \times U_0$ and $U_{GB} = 8{,}204 = 7{,}004 + q_i \times 8{,}428$, so $q_i = 0.1424$.

$$p_i = \%\text{ reported} = 1 - q_i = 0.8576$$

$$\text{LDF}_{24\text{-ult}} = \frac{1}{0.8576} = 1.166$$

### Examiner Report
The majority of candidates received full credit for part a). Errors, if any, were generally due to calculation/arithmetic errors. The critical component of the solution was the relationship between the Benktander and Bornhuetter Ferguson method.

## Part b (0.5 points)

For accident year 2011, suppose that the Bornhuetter-Ferguson method is performed over multiple iterations. Deduce the ultimate loss estimate that will be produced as the number of iterations approaches infinity.

### Explanation
As you iterate on the BF method to infinity, the result will approach the chain ladder estimate.

Alternatively:

Write each iteration as a credibility weighting of the chain-ladder and prior ultimates:

$$U_{BF} = U_{CL}(1 - q_i) + U_0\,q_i \quad \text{(1st iteration)}$$

$$U_{GB} = U_{CL}(1 - q_i^2) + U_0\,q_i^2 \quad \text{(2nd iteration)}$$

The 3rd iteration is

$$U_{CL}(1 - q_i) + q_i\left[U_{CL}(1 - q_i^2) + U_0\,q_i^2\right] = U_{CL}(1 - q_i)\left[1 + q_i - q_i^2\right] + U_0\,q_i^3 = \dots = U_{CL}(1 - q_i^3) + U_0\,q_i^3$$

As the number of iterations approaches infinity this becomes $U_{CL}(1 - q_i^{\infty}) + U_0\,q_i^{\infty}$, where $\lim_{t \to \infty} q_i^t = 0$, so the estimate becomes $U_{CL}(1 - 0) + U_0 \times 0 = U_{CL}$:

$$U_{CL} = 7{,}004 \times \text{LDF}_{24\text{-ult}} = 7{,}004 \times 1.166 = 8{,}167$$

### Examiner Report
The question in part b) did not explicitly state that candidates needed to estimate the value, so full credit was given to candidates that mentioned chain-ladder ultimate without explicitly calculating the value of the chain-ladder ultimate.

A few candidates used a cumulative development factor inconsistent with their calculated cumulative development factor in part a).  Partial credit was given to candidates with this response.

Some candidates derived the estimate showing iterations to infinity.  These candidates received full credit if their derivation was correct.

Partial credit was given to candidates that calculated the value of the chain-ladder estimate, without explicitly stating that it is the chain-ladder estimate, or showing a derivation.
