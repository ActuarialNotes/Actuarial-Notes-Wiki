You are fitting a boosted regression tree with shrinkage parameter $\lambda = 0.08$. There is a single numeric predictor variable, x, and the target variable is y. Each tree is to have a single split. The first tree, built using all the training data has the following split:

- If x < 17.5, then the predicted value of y is 125.4.
- If x ≥ 17.5, then the predicted value of y is 350.5.

The following are three observations from the training set:

| Observation | x | y |
|---|---|---|
| 1 | 15.2 | 139 |
| 2 | 12.9 | 156 |
| 3 | 23.6 | 289 |

Calculate the updated predictions for these three observations $(\hat{f}(x_1), \hat{f}(x_2), \hat{f}(x_3))$.

- A) (–406.1, –389.1, –31.1)
- B) (–211.4, –194.4, 163.6)
- C) (10.0, 10.0, 28.0)
- D) (111.0, 128.0, 279.0)
- E) (129.0, 146.0, 261.0)

## Explanation

The initial fitted values are all zero. They are updated by adding $\lambda$ times the prediction from the tree, $\hat{f}(x) \leftarrow \hat{f}(x) + \lambda \hat{f}^{1}(x)$. Observations 1 and 2 have $x < 17.5$, so the tree predicts 125.4 for them; observation 3 has $x \geq 17.5$, so the tree predicts 350.5. The updated predictions are

$$
\begin{align*}
\hat{f}(x_1) &= 0 + 0.08(125.4) \\
             &= 10.0 \\
\hat{f}(x_2) &= 0 + 0.08(125.4) \\
             &= 10.0 \\
\hat{f}(x_3) &= 0 + 0.08(350.5) \\
             &= 28.0
\end{align*}
$$
