Given the following data:

Policy Year Ultimate Loss (\$000)

| Line of Business | 2008 | 2009 | 2010 | 2011 | 2012 |
|---|---|---|---|---|---|
| Personal Auto | 900 | 1,150 | 6,000 | 850 | 1,100 |
| Homeowners | 340 | 200 | 1,060 | 150 | 250 |

## Part a (1 point)

Calculate the Pearson product-moment correlation between the personal auto loss data and the homeowners loss data.

### Explanation
$$\text{Pearson } \rho = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2}\sqrt{\sum (Y_i - \bar{Y})^2}}$$

| PA ($X$) | HOME ($Y$) | $X_i - \bar{X}$ | $Y_i - \bar{Y}$ |
|---|---|---|---|
| 900 | 340 | -1,100 | -60 |
| 1,150 | 200 | -850 | -200 |
| 6,000 | 1,060 | 4,000 | 660 |
| 850 | 150 | -1,150 | -250 |
| 1,100 | 250 | -900 | -150 |
| $\bar{X} = 2{,}000$ | $\bar{Y} = 400$ | | |

$$\sum (X_i - \bar{X})(Y_i - \bar{Y}) = 3{,}298{,}500 \qquad \sum (X_i - \bar{X})^2 = 20{,}065{,}000 \qquad \sum (Y_i - \bar{Y})^2 = 564{,}200$$

$$\rho = \frac{3{,}298{,}500}{\sqrt{20{,}065{,}000 \times 564{,}200}} = 0.98035$$

Alternatively:

$$\rho = \frac{E(XY) - E(X)E(Y)}{\sigma_X \sigma_Y} = \frac{1{,}459{,}700 - 2{,}000 \times 400}{(2{,}003.25)(335.92)} = 0.98$$

with $E(X) = 2{,}000$, $E(Y) = 400$, $E(XY) = 1{,}459{,}700$, $\sigma_X = 2{,}003.25$ and $\sigma_Y = 335.92$.

### Examiner Report
Part a), this is an application of the formulas for Pearson's correlation. The syllabus material
provides two approaches to calculate the correlation using the provided data. Common errors include arithmetic errors and mixing two formulas together.

## Part b (1 point)

Calculate the Spearman rank correlation between the personal auto loss data and the homeowners loss data.

### Explanation
Rank each line's losses and sum the squared rank differences:

| $X$ | $Y$ | Rank $X$ | Rank $Y$ | Diff² |
|---|---|---|---|---|
| 900 | 340 | 2 | 4 | 4 |
| 1,150 | 200 | 4 | 2 | 4 |
| 6,000 | 1,060 | 5 | 5 | 0 |
| 850 | 150 | 1 | 1 | 0 |
| 1,100 | 250 | 3 | 3 | 0 |
| Total | | | | 8 |

$$\rho = 1 - \frac{6 \times \sum d_j^2}{N(N^2 - 1)} = 1 - \frac{8}{5(5^2 - 1)/6} = 0.60$$

### Examiner Report
Part b), this is an application of the formulas for Spearman's rank correlation.  The syllabus
material provides a formula and approach for estimating the correlation using the provided data.
Common errors include arithmetic errors and memorizing the incorrect formula.

## Part c (0.75 points)

Explain the difference between these two measures of correlation as applied to this data set.

### Explanation
Pearson's correlation is calculated based on values, while Spearman's correlation is based on ranks. Thus, Pearson's correlation can be impacted by large outliner amounts. This impact can be seen here, where the 2010 year is largely influencing the correlation factor in the Pearson calculation. The use of ranks in Spearman's calculation is not impacted by this, so while it shows some positive correlation with 0.6, it is not nearly as high as the Pearson result.

Alternatively:

Pearson is a cardinal measure & is driven by the magnitude of the values. It will be highly leveraged by points far away from the mean. This occurs in 2010 which both Auto & HO have losses above the mean. This point drives the high correlation factor of 0.98.
Spearman is an ordinal measure, weighted equally among all 5 years.

### Examiner Report
Part c), common errors include only give generic statements of difference without tying back to
the data given in the question.
