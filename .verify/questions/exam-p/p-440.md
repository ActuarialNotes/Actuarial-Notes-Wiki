## [F-001] Explanation asserts mean = median only for symmetric distributions
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-27T19:59Z/bfa2
- date: 2026-09-28
- severity: minor
- status: open
- locus: explanation, closing paragraph
- claim: choice (A), 400, would set them equal, which happens only for a symmetric distribution.
- evidence: The clause states that mean = median happens only for a symmetric distribution. That is false as a general statement: X taking values -2, 0, 1 with probabilities 0.2, 0.4, 0.4 has mean -0.4+0+0.4 = 0 and median 0 (P(X<=0)=0.6, P(X>=0)=0.8), yet is not symmetric. Symmetry implies mean = median, not the converse. The SOA solution (solutions PDF p.123) makes no such claim; it only computes lambda = 577.08. The rest of the explanation, and the answer E, are correct. Falsified by own counterexample (rank 5 can falsify).
- source_rank: 5
- proposed_action: Reword to say a symmetric distribution would have mean = median (symmetry implies equality, not the converse), or drop the clause after 'would set them equal'.
- applied: false
