Determine which one of the following statements about Principal Component Regression (PCR) is FALSE.

- A) When performing PCR it is recommended that the modeler standardize each predictor prior to generating the principal components.
- B) PCR is useful for performing feature selection.
- C) PCR assumes that the directions in which features show the most variation are the directions that are associated with the target.
- D) PCR can reduce overfitting.
- E) The first principal component direction of the data is that along which the observations vary the most.

## Explanation

Principal component regression replaces the $p$ predictors with the first $M$ principal components, $Z_1, \ldots, Z_M$, and regresses the response on those.

**A is true.** Principal components chase variance, so a predictor measured on a larger scale would dominate the leading components. Standardizing first is the usual recommendation.

**B is false.** Every principal component is a linear combination of *all* $p$ original features. Dropping later components shrinks the number of inputs, but no original feature is removed from the model, so PCR is a dimension-reduction method, not a feature-selection method (ISLR makes exactly this point, noting that PCR behaves more like ridge regression than the lasso).

**C is true.** PCR picks its directions without looking at the response, so it implicitly assumes that the directions in which the predictors vary most are the ones associated with the target. That assumption is not guaranteed, which is PCR's main weakness.

**D is true.** Regressing on $M < p$ components estimates fewer coefficients, trading a little bias for a potentially large drop in variance, which reduces overfitting.

**E is true.** This is the definition of the first principal component.

The false statement is B, so the answer is **B**.
