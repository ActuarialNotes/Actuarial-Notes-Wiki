Given the following information about investment options:

- $U = E(r_c) - 0.5A\sigma_c^2$
- The risk-free rate of return is 3%.
- The risk premium on the risky portfolio is 5%.
- The reward-to-volatility ratio of the risky portfolio is 0.25.
- The risk aversion parameter is 2.

## Part a (0.75 points)

Calculate the certainty equivalent rate of the risky portfolio.

### Explanation
With $r_f = 0.03$, the expected return on the risky portfolio is its risk premium plus the risk-free rate:

$$E(r_p) = 0.05 + 0.03 = 0.08$$

The reward-to-volatility (Sharpe) ratio gives the risky portfolio's standard deviation:

$$S = \frac{E(r_p) - r_f}{\sigma_p} \;\Rightarrow\; 0.25 = \frac{0.08 - 0.03}{\sigma_p} \;\Rightarrow\; \sigma_p = 0.20$$

The utility of the risky portfolio is

$$U_p = 0.08 - 0.5(2)(0.2)^2 = 0.04$$

The certainty equivalent rate is the risk-free rate that produces the same utility as the risky portfolio. A risk-free asset has no variance, so

$$U_{ce} = 0.04 = E(r_{ce}) - 0$$

and the certainty equivalent rate is $0.04$ (4%).

### Examiner Report
The majority of candidates did well on this part, earning full points. Common errors included the following:

1. Solving for the risky rate of return that would give the same utility as the risk-free asset
2. Simply selecting the risk-free rate of return as the certainty equivalent rate
3. Simply selecting the expected return of the risky portfolio as the certainty equivalent rate.
4. Solving for the certainty equivalent rate of the wrong portfolio. In some cases, the candidate calculated the certainty equivalent for the "complete" portfolio given in part (b); in other cases the candidate solved for the optimal "complete" portfolio (part (c)) and used the expected return and volatility of that portfolio to calculate the certainty equivalent rate in part (a).
5. Mistaking the risk premium on the risky portfolio for the expected return on the risky portfolio
6. Mistakes in applying the reward-to-volatility ratio

## Part b (0.5 points)

Given that 40% of the available assets are invested in the risky portfolio and the rest in the risk-free asset, calculate the expected return and standard deviation of the complete portfolio.

### Explanation
$$E(r_c) = 0.4E(r_p) + 0.6r_f = 0.4(0.08) + 0.6(0.03) = 0.05$$

The complete portfolio lies on the capital allocation line, so it has the risky portfolio's reward-to-volatility ratio:

$$S = \frac{r_c - r_f}{\sigma_c} = \frac{0.08 - 0.03}{\sigma_c} = 0.25 \;\Rightarrow\; \sigma_c = 0.08$$

(the numerator $0.08 - 0.03$ is as printed).

Alternatively:

With $w_p = 0.4$ and $w_{r_f} = 1 - w_p = 0.6$, and a risk-free asset with no variance:

$$\sigma_c^2 = w_p^2\sigma_p^2 + w_{r_f}^2\sigma_{r_f}^2 + 2w_pw_{r_f}\,Cov(p, r_f) = 0.4^2(0.2^2) + 0.6^2(0)^2 + 2(0.4)(0.6)(0) = 0.0604$$

(as printed), so $E(r_c) = 0.05$ and $\sigma_c = 0.08$.

### Examiner Report
The vast majority of candidates scored full points on this part. Those who didn't get full credit typically made one of the following common errors:

1. Reversing the weights applied to the risky portfolio and risk-free asset.
2. Calculating only one of the values required by the question – either the expected return without the standard deviation, or vice versa.
3. Mistakes in applying the information given in the problem (return-to-volatility ratio, risk premium, etc.)

## Part c (0.25 points)

Calculate the percentage of available assets to invest in the risky portfolio to maximize utility.

### Explanation
Choose the weight $y$ in the risky portfolio to maximise the utility of the complete portfolio:

$$U = E(r_c) - 0.5A\sigma_c^2 = yE(r_p) + (1 - y)r_f - 0.5Ay^2\sigma_p^2$$

$$\frac{dU}{dy} = E(r_p) - r_f - 0.5(A)(2)\sigma_p^2y = 0 \;\Rightarrow\; E(r_p) - r_f = A\sigma_p^2y$$

$$y^* = \frac{E(r_p) - r_f}{A\sigma_p^2} = \frac{0.08 - 0.03}{2(0.2)^2} = 0.625$$

Invest 62.5% of available assets in the risky portfolio.

### Examiner Report
Again, almost all candidates received full credit for this part. Those who didn't generally made an error in the calculation or in substituting a value for a variable in the formula to calculate the optimal weight to give the risky portfolio.

A note on notation: many candidates used notation that was incorrect, inconsistent with the text, or inconsistent within the candidate's response, in a few primary categories:

1. Identifying a portfolio's return, expected return, or risk premium,
2. Volatility/standard deviation versus variance
3. Identifying which portfolio a given statistic refers to.

Although we did not deduct any points directly for using inconsistent notation, it appeared that in some cases inconsistency in notation tripped up candidates, causing mistakes in the calculations.
