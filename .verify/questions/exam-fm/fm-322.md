## [F-001] Explanation's solving equation has 63i where it should be 63
- entry_type: finding
- author: agent:validate-v1
- run_id: 2026-09-28T14:47Z/aa33
- date: 2026-09-28
- severity: major
- status: open
- locus: Explanation, lines 48-49
- claim: After substituting i = 63/X the explanation writes 7[(1+i)^45 - 1] = 63i and 7(1+i)^45 = 7 + 63i, then says solving numerically gives i = 0.0525.
- evidence: 7 s_45 = X with X = 75.60/(1.2i) = 63/i gives 7[(1+i)^45 - 1]/i = 63/i, i.e. 7[(1+i)^45 - 1] = 63 (no factor i). SOA solution (solutions PDF p.85, image) prints '7(1+i)^45 - 7 = 63, (1+i)^45 = 10, i = 0.0525, X = 7 s_45|0.0525 = 1200'. The vault's equation 7(1+i)^45 = 7 + 63i is not satisfied at i = 0.0525 (LHS 70.00, RHS 10.31) and has no positive root (at small i the LHS grows like 7 + 315i), so a student following it cannot reach i = 0.0525. Recomputation: i = 10^(1/45) - 1 = 0.052500, X = 63/i = 1199.99. Key C unaffected.
